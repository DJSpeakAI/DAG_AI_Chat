# 修复连线旋转中心错误 — 0.107

> 归属版本：v0.1 内部迭代

## 一、根因

ArkUI `.rotate()` 的 `centerX/centerY` 参数：

> **单位为 vp**（虚拟像素），字符串格式支持百分比（如 `'50%'`）
> 默认值：`{ centerX: '50%', centerY: '50%' }`
> 中心点 `(0, 0)` 代表组件左上角

0.106 中使用 `centerX: 0.5, centerY: 0.5`，实际含义是 **0.5vp**（几乎在左上角），不是 50%。

```
期望旋转中心 = 元素中心 (midX, midY)
实际旋转中心 = 元素左上角 + (0.5vp, 0.5vp) ≈ 左上角
→ 旋转后线段位置完全错位
```

## 二、修复方案

回到 HEAD 版本验证过的模式：

```
线段从父圆心 → 子圆心（全长，不扣半径）
气泡实心背景覆盖线段两端 → 视觉上仅显示边沿到边沿
旋转中心 (0, 1)vp = position(parentCX, parentCY - 1) + (0, 1) = (parentCX, parentCY) = 父圆心
```

### 改动

| 项目 | 0.106（错误） | 0.107（修复） |
|------|-------------|-------------|
| 线段长度 | centerLen - 60 | centerLen（全长） |
| 线段位置 | (midX - L/2, midY - 1) | (parentCX, parentCY - 1) |
| 旋转中心 | centerX: 0.5, centerY: 0.5 | centerX: 0, centerY: 1 |
| 半径扣除 | getEdgeLength 减 60 | 不扣，气泡覆盖 |

### 为什么 (0, 1)vp 对齐父圆心

```
position.y = parentCY - 1    （vp）
centerY = 1                  （vp）
旋转中心 Y = position.y + centerY = parentCY - 1 + 1 = parentCY  ✓
```

与缩放无关，始终精确对齐父圆心。
