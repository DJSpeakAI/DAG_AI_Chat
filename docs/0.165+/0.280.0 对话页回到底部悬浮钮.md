# 0.280.0 对话页「回到底部」悬浮钮

## 需求（用户口述）
气泡聊天页面：用户往上滑看历史内容、视口未到最后一行时，出现一个圆形向下箭头悬浮钮（样式参考用户截图：圆底+下箭头）；点击滚到最底部。注意 UI 观感。

## 方案
1. **检测**：消息 List 挂 `onScrollIndex((start, end) => ...)`——`end < currentMessages.length - 1` 即未到底 → `@Local showScrollToBottom = true`；滚回底部（发送新消息后 `scrollEdge(Edge.Bottom)`、onScrollIndex 回调 end=lastIndex）自动 false。
2. **点击**：`this.scroller.scrollEdge(Edge.Bottom)`（复用现有 Scroller，与发送消息自动滚底同款）。
3. **挂点结构**：消息区 if/else（空态 Column + List）外包 `Stack({ alignContent: Alignment.BottomEnd })`，layoutWeight(1) 移到 Stack，内层 List/空态改 `height('100%')`（参照已定高 Stack，安全；非 0.279.19 未定容器反向测量雷）。悬浮钮随消息区自适应、天然避开输入区。
4. **UI**：36vp 圆钮 = surfaceNode 底 + 0.5 strokeCard 描边 + shadowColorSoft 软阴影（照 TokenInfoChip 浮层定式）；内 18vp `arrow_down.svg`（华为细线 1.5/圆帽/65%，base 深墨+dark 白，照 mic.svg 定式双主题）；margin right 14 / bottom 12；出现/消失 150ms OPACITY transition。
5. **边界**：内容不满一屏 end==lastIndex 不出现；空对话 List 不渲染；分支切换重滚底自动隐藏。

## 风险
低：Stack 包 List 与输入卡 Stack 包 TextArea（0.279.18 验证）同族；onScrollIndex 为 List 原生回调。注意保持 List 原属性链完整、缩进不重排（最小 diff）。

## 验收
1. 长对话上滑 → 图标出现于消息区右下；2. 点击 → 滚到底且图标消失；3. 发送新消息自动滚底 → 图标不出现；4. 内容不满一屏/空对话 → 不出现；5. 三端（PC/Pad/手机）+ 深浅主题图标均正常。
