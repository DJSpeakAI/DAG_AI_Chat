# 0.299.0 每日复习提醒（后台代理提醒预埋）

## 一、需求与产品定位
用户当日未完成复习时，每天固定时间由系统通知提醒（如「今天有约 N 条记忆等你复习」）。
核心诉求：**app 被杀死/退后台也要天天响**——用户可能十几天不打开 app，提醒是逼其养成
复习习惯的敲门砖（多邻国 streak 同款机制；不舍得关通知=有需求，卸载才算流失）。

华为合规实锤（官方 AI 客服确认）：
- 代理提醒开放场景点名「学习类提醒（**背单词提醒**）」，教育类应用在可申请范围——完全匹配。
- 手机/平板/PC 已管控：须 AGC「项目设置→开放能力管理→代理提醒」申请权益（8 个工作日）。
- 权益通过后两步缺一不可：①勾选能力开关+保存 ②重新生成 Profile+手动签名。
- 未获批时 publishReminder 报 1700002；权限 PUBLISH_AGENT_REMINDER 为 normal+system_grant
  （声明即生效无弹窗）；复用已有通知授权链路；周期提醒发布一次长期有效，占 1/30 配额。
- SDK 前提：权益在 HarmonyOS 5.1.1(19) 及之前不生效——本项目 targetSdkVersion 26.0.0 无忧。

## 二、方案决策（关键取舍）
1. **周期闹钟（ReminderRequestAlarm daysOfWeek 全选）而非华为建议的滚动单日日历**：
   滚动方案（完成当日 cancel+publish 明天单日）在用户连续多日不开 app 时**断档**
   （单日提醒响完即止）——违背「天天被提醒」初衷。周期闹钟永续兜底。
2. **「完成当日静默」改为文案双态**：周期提醒无法只取消当天单次（cancel 即全周期）。
   完成当日复习后提醒文案转正反馈（「今日复习已完成，好习惯 +1」）——骚扰感消失，
   streak 庆祝通知同款产品效果。
3. **文案动态性边界**：待复习数 N 只在进程活着时能算（代理提醒文案发布时静态）。
   刷新四时机：⚙ 开关/时段变更、完成复习、退后台（主时机）。用户不开 app 期间显示
   陈旧 N 仍近似准确（词库未变；跨日新到期只低估不高报，「约 N 条」兜底）。
4. **默认关**：权益未获批前开关无效（静默），默认 off 用户自开；开关偏好照常落盘。
5. **点击通知**：wantAgent 拉起本应用 EntryAbility（华为限制仅本应用；页面级路由
   wantAgent 不支持带参——v1 拉起即首页，直达复习页留待权益生效后真机验证）。

## 四、风险与遗留
- **权益未获批前功能静默待激活**（1700002 全 catch）——用户拿桌面手册去 AGC 申请，
  通过后代码侧零改动自动生效；新 Profile+手动签名须用户人工（signing/ 红线）。
- wantAgent 直达复习页未实现（华为 wantAgent 仅 UIAbility 级）。
- 'review-reminder-v1' 待补录 config.autofix.redlineKeys（testing/ 红线区不动）。
- 提醒时刻仅四档整点（19~22）；自由分钟级时间选择器留后续（TextPicker/TimePicker）。

## 五、验收标准
1. 编译通过（✅ BUILD SUCCESSFUL）。
2. 权益前：⚙ 开关可开可关、时段可切、无任何报错弹窗（静默降级）。
3. 权益后（新 Profile 包）：开启开关→系统时间调至提醒时刻前 1 分钟→通知弹出
   （文案含 N 或完成态）；点通知拉起 app；关开关后次日不再提醒。
4. 桌面手册：《代理提醒权益申请-手把手操作手册.txt》。
