# 0.311.0 外观通知开关与复习完成态修复

日期：2026-10-24　用户口述实测反馈（直接开工，未走方案审批）

## 需求（用户原意）

1. 首启「选择外观」页在「加入体验改进计划」下方新增「是否允许通知」开关（用于背单词 / 识字卡片学习提醒），UI 与体验改进计划同款，默认关。
2. 登录引导文案：不在对话页弹「使用 AI 对话功能需先登录」太突兀，改为「消耗 SP 的功能（如 AI 对话）需先登录华为账号」。
3. 卡片复习：完成今日队列 →「完成」回画布后，再点「卡片复习」不应自动开新一批；应落在完成/鼓励页，只有用户主动点「继续复习」才继续入队。
4. 新手任务奖励弹窗标题：完成单个 2 万任务时误显示「恭喜！新手任务全部完成」，应只在完赛奖真正发放时显示全部完成；金额行语义固定为「+N SP 已入嘉奖池」。
5. 画布右上角新手任务入口图标与左侧同排图标 Y 轴未对齐，修正为垂直居中。
6. 新用户首次登录 + 云同步就绪后，应看到 200 万礼包 + 第 1 天签到（此前登录时 gate 未就绪，签到引导被跳过且之后无入口补弹）。

## 改动文件

- `components/ThemeChooseDialog.ets`：新增「允许通知」行；`isNotificationEnabled` 回显真值；开= `requestEnableNotification`，关=回弹真值 + toast 指路系统设置（应用无权静默撤销通知授权）。
- `pages/Index.ets`：AI 登录引导文案改 SP 口径；礼包「开心收下」关闭后接力补弹首日签到。
- `components/ReviewPage.ets`：`buildQueue(force=false)` 增加「当日已完成→完成页」闸；「继续复习」与兜底重建走 `force=true`，并把未学新卡追加到继续复习队列。
- `common/RookieTask.ets`：奖励标题判据从「本次总额≥2万」改为「完赛奖哨兵已发」。
- `common/ChatModel.ets`：新增 `maybeShowSignInAfterGateReady()`，首拉开闸后补弹签到（礼包弹窗优先，礼包关闭后由 Index 再回调）。
- `components/BBTreeCanvas.ets`：任务入口外层 Stack 垂直居中 + 内层 34×34 角标层，修正 Y 轴 3vp 错位。
- `components/GlobalSettingsDialog.ets` / `AppScope/app.json5`：版本号 0.311.0 / versionCode 1000468。

## 风险点

- 通知开关受系统授权控制：应用无法静默关闭，关闭动作只回弹真值并提示去系统设置。
- 签到补弹挂在首拉开闸后：若礼包弹窗同时出现，签到延后到礼包关闭；每日去重由 `autoShownDate` 保证。
- 完成态闸以 `review-daily-v1` 的当日日期为准；「继续复习」显式入口保留新卡/未来卡可达性，避免 0.200.1 新卡被挡问题在显式路径复发。

## 验收标准

1. 重置为新用户资产（云同步真实就绪）→ 重开登录 → 200 万礼包弹窗 → 关闭后第 1 天签到弹窗。
2. 完成 10 张卡片 → 完成回画布 → 再进卡片复习 = 完成/鼓励页（不自动开新批）；点继续复习才入队。
3. 单个 2 万新手任务到账标题为「新手任务奖励已到账」；7 条全完并发放完赛奖时才显示「恭喜！新手任务全部完成」。
4. 画布右上角任务图标与左侧分段控件 Y 轴居中。
5. 登录引导弹窗文案为 SP 消耗口径。
6. 外观页可开通知授权（系统弹窗），拒绝后开关回落关闭。
