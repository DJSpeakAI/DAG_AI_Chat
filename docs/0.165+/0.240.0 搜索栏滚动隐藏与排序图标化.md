## 一、需求（已拍板三项）

| # | 决策项 | 拍板结论 |
|---|---|---|
| 1 | 手机端搜索栏 | 滚动隐藏：上滑累计超 10vp 收起、下滑超 10vp 滑回；只收搜索行，标题/顶栏按钮常驻；滚回顶部强制显示；搜索词不清空 |
| 2 | 排序按钮 | 图标化：新增 sort.svg，紫底文字按钮换 28×28 图标按钮；弹层当前项紫字+紫底高亮 |

## 二、实现方案

### 改动一：搜索栏滚动隐藏（两库同款）
- 新增 `@Local searchBarVisible: boolean = true` + 滚动防抖状态（lastOffset/accum/lastDir）；
- List 挂 `onDidScroll`：上滑累计 >10vp 收起、下滑累计 >10vp 呼回、方向反转重置、offset≤0 强制显示；
- 收放仅 `!this.isTablet` 分支执行；宽屏强制 true；
- 搜索 Row 条件渲染 + `TransitionEffect.opacity().combine(TransitionEffect.translate({y:-8}))`（复用 0.222.7/0.222.8 抽屉范式；**禁 animateTo 闭包赋值**——畅享90pro 实锤 UI 不刷新）。

### 改动二：排序图标化（两库同款）
- 新增 `entry/src/main/resources/base/media/sort.svg`（18×18 家族画风：stroke 65% 白、1.5 宽、round cap/join；三横线递减+小箭头）；
- 按钮：`Button(sortText)` → `Row{Image(sort)}` 28×28 / RADIUS_CONTROL / 透明底 / margin right 4——与 grid/设置齿轮同规格；bindPopup 配置原样保留；
- sortMenuBuilder 当前项补 `backgroundColor(SURFACE_HOVER)` + `borderRadius(8)`；
- `sortText()` 删净（删前全查引用）。

## 四、风险点
- onDidScroll 回调高频——防抖逻辑必须纯轻量计算，禁在回调内做重活；
- 条件渲染摘除搜索栏会使列表内容区上移（布局跳动）——transition 平滑；@Local 状态挂载防真机不刷新；
- 删 sortText 前全查引用；带参 @Builder 传参雷；import 置顶。
