## 二、设计

### 2.1 新原语（server.js）

1. **loginStateHome(serial)**：三端通用登录态判定——首页 dump 含「华为账号已登录」=已登录（Index.ets:548，三端首页同款）；含「登录华为账号」=未登录（Index.ets:589 账号卡按钮）。取代手机上恒 miss 的 dumpCountText('已登录')（"已登录"文本只在边栏/抽屉账号行，手机抽屉默认关）。
2. **ensureLoginFlow(ctx, dev)**：统一登录引导——coldStart→agreeDialogIfAny→点首页「登录华为账号」（exact，三端首页账号卡）→若再弹协议模态再同意（手机未同意路径：pendingAction 续跑）→checkpoint 人工仅华为授权（detect=华为账号已登录）→收尾关 30 天试用等弹窗。PC（uiDump=false）走 pcClickText 通道。
3. **acceptSyncAsk(serial, log, clickText)**：登录后云同步询问**主动开启**——循环点「开启云同步」（exact）+「知道了」（30 天试用）+系统权限「允许」（'附近的设备'，取最后命中）。与 dismissLoginDialogs（暂不开启=测试隔离用）互补。
4. **openPhoneDrawer(serial, log)**：手机画布抽屉唤出——左下角按钮（BBTreeCanvas:1532 `!isTablet` 时渲染，40×40 sidebar.svg，position x=14,y=viewH-68；dump 启发式=左下角区域 x<30%W、y>70%H 的 50~130px Image）→点击→验证（dump 出现「单词库」/「知识库」文本=抽屉开）。幂等（「单词库」已在=开）。
5. **ensureCanvas(serial, log)**：进画布——首页点「进入气泡树」主按钮（0.179 三端首页同款）；已在画布（信息条特征「N 个气泡」）跳过。
6. **navToM(serial, text, log)**：手机版导航=ensureCanvas→openPhoneDrawer→点目标（「单词库」/「知识库」/「气泡树」）。与 navTo（Pad 常驻边栏+0.220.0 折叠适配）分流：flowPrep 内按设备 uiDump+屏宽分流，统一封装 navAnywhere(dev, text)。
7. **pcClickText(serial, keyword, opts)**：PC 多屏注入（0.229.25 实证通道固化）——dumpAuditNodes(serial, disp)（disp=caps.auditDisplay=15，miss 再试 0）→找文本→`uitest uiInput click x y <disp>`。BOOT-LOGIN 的 PC 引导用；失败如实 fail（不静默人工），checkpoint 兜底文案如实标注。
8. **flowPrep(ctx, opts)**：加 `opts.prefer`（设备 id）——指定且 canUiDump 则为操作端；缺省维持现状（第一台 canUiDump=Pad）。操作端登录改用 ensureLoginFlow（手机首页路径替代边栏头像路径）。

### 2.2 新套件 sync-boot（三端从零引导；套件顺序置于 sync 之前）

1. **BOOT-AGREE**（each，全自动）：fresh 装机首启协议引导——coldStart→有协议模态=自动勾选+同意+「暂不加入」体验改进→断言协议已同意（重 dump 无「同意并继续」）+未登录基线（首页「登录华为账号」在场/PC 用 huawei-account 探测）。fresh 必弹；不弹=warn 如实（非 fresh 装机或已同意）。
2. **BOOT-LOGIN**（each，semi）：全自动登录+开同步——ensureLoginFlow→acceptSyncAsk（开云同步+系统权限允许）→断言三件套：①UI 登录态「华为账号已登录」（UI 设备）②RDB cloud_data>0（同步活）③cloud-sync-switch 落盘 true（12s 轮询重试，PersistenceV2 flush 延迟容忍，同 LOGIN-SYNC）。**唯一人工=华为授权页**（checkpoint 自动探测，静默授权零点击）。
3. **BOOT-CONVERGE**（cross，全自动）：三端收敛——settle 轮询各端 cloud_data 总行数两两相等（180s；fresh 三端并发拉云端存量有先后）→四域行数三端一致（复用 SYNC-DOMAIN 域表）→键集 md5 签名一致。收敛完成=三端从零引导收官，后续 sync/syncflow 可直接跑。

### 2.3 syncflow 套件扩展（手机操作端）

- **SYNC-FLOW-WORD-M**：手机建词→其余端收敛（flowPrep prefer:'phone'；导航 navToM 抽屉→单词库→+→「新建单词」→hint「单词（必填）」注入→保存→操作端 +1→各断言端 settle 基线+1）。用例结构与 SYNC-FLOW-WORD 同构。
- **SYNC-FLOW-NODE-M**：手机建气泡→其余端收敛（ensureCanvas→顶栏「+」→node+tab 联合断言）。
- 现有 4 条 SYNC-FLOW（Pad 操作端）不动：勾选三台时手机/PC 自动成为断言端（手机下行链路由此覆盖）。
- CARD 与 WORD 同构、DELETE 与 NODE 同构——手机端抽代表 2 条，避免用例矩阵翻倍。

## 四、风险点

1. **手机抽屉按钮 dump 启发式**（左下角 Image 无文字）——首轮真机 /api/dump 盯屏校准（0.229.24 工作法）；校准偏差不阻塞：navToM 失败如实 fail，日志带 dump 特征供迭代。
2. **PC 多屏注入**（displayId 15）首版固化——0.229.25 手工实证过，代码化为原语后需真机校准；窗口所在屏漂移（15↔0）双屏尝试兜底。
3. **三台 fresh 后 PC 登录**依赖 pcClickText 通道成功；失败如实红（PC 通道二期固化），不静默人工顶替。
4. 手机 WiFi（192.168.2.14:38611）掉线风险——autoConnectTcpDevices 自动 tconn 兜底；连不上按全局约束#6 先问用户。
5. **登录态检测基准变更**（'已登录'→'华为账号已登录'/「退出账号」）影响 login 套件存量断言——逐条核对替换，防假绿（'华为账号已登录'含子串'已登录'，dumpCountText('已登录') 对 Pad 依然命中=向后兼容）。
