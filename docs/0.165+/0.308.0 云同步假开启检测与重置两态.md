# 0.308.0 云同步假开启检测与重置两态

> 2026-10-24 · 用户手机（畅享90 Pro / 180 测试号）实测三问题驱动的修复

## 一、需求与根因（用户口述三问题）

1. **重置按钮被"云同步未就绪"阻断**：未开云同步时点「重置为新用户资产」报错——用户拍板"随时随地可用"（调试工具，上架前删除）。
2. **华为有无检测系统云空间开关的 API**：实查结论=**无**（cloudData 模块只有策略配置；cloudSync() 在系统开关未开时**静默 resolve 不报错**）。
3. **假开启乱发 SP（最严重）**：手机实测链路——登录→app 自动开云同步+权限允许，但系统「设置→云空间→应用数据同步」未放行本应用 → cloudSync 静默返回 → 空表 reconcile 无缺片照常开闸（rowInitDone=true）→ 门卫五条件被骗 → 切后台再切回弹出"第一天签到 2000SP"→ doSignIn 同样被骗 → 假账入本地。**云端案底：SpLedger 手机 CHZ-AL00 welcome 2000000（ts=1792816302，即用户实测当天）。**

端侧无法区分「云端空表（真新用户）」与「假开启」——两者 0 行下行 0 报错 0 dataChange 同形。

## 二、方案（用户拍板 A+B 全上：检测实锤+弹引导直跳系统云空间）

### 证据链（零误拦原则）
- **本地标记 `sp-cloud-seen-v1`（SpCloudSeenStore.spRow）**：本机历史任一 reconcile 真下行收到过 cfg:siyi-points 行（只可能由真下行置位=零误拦）。有标记而本轮拉不到=假开启实锤。
- **云函数探针 `spAdminProbe`**（走 AGC callFunction 独立通道）：sp-admin 新 action `probe` 查 default zone **SpMirror+SpLedger 双表**「他设备」痕迹（他设备报过=云端大概率有 SP 行）。本机拉不到 SP 行 + 探针 yes = 实锤。
  - 双表原因：SpMirror 同主键 upsert 会被最后上报设备覆盖（实测 180 镜像被手机覆盖）；SpLedger 追加不覆盖（PC 12 条流水都在）——冒烟实测三视角全绿。
  - **云空间容器 dag_chat_cloud 服务端不可读**：cloud-server database({zoneName}) 报 2057 Zone invalid（本地直连冒烟实锤）——云空间与云数据库是隔离存储面，真值探针只能用 default zone 资产痕迹代理。
- **fail-open 纪律**：探针 'no'（无他设备痕迹=真新用户）/'err'（未部署/无网）一律放行——不因旁路服务不可用冻死主链。

### 实锤动作与解除
- 实锤：`SiyiGateStore.cloudBlocked=true`（siyi-gate 会话级）→ `siyiGateReady()` 第⑤条件拦截一切 SP 增耗（签到/礼包/AI 消耗/IAP）→ 弹引导 r=4（每会话首实锤一次）。
- 解除：用户在系统设置放行 → onForeground forceCloudSyncNow → 真下行 cfg:siyi-points 到达 → reconcile 证真分支清 cloudBlocked+落 spRow 标记。
- **礼包判定收口**：maybeGrantWelcomeAfterFirstPull 移入 `afterFirstPullGateOpen` 裁决链——有 SP 行直判；无行走本地标记/探针裁决，实锤不发（堵当天手机 200 万路径），fail-open 才发。
- 探针节流 60s；节流期内不重复问也不裁决（在途回调统一处理，防反复 reconcile 重开窗口）。

### 已知边界（一期接受）
- 全新装机+假开启首签 2000 本地挂账：探针无他设备痕迹 fail-open 放行——真开启后上行=新账号首签合法值，不构成乱账。
- 单设备老账号关系统开关（SpMirror/Ledger 均无他设备痕迹）：探针判不出，仅 signDates 幂等保护（重复签到金额不受保护）——待 SpMirror 数据面随各端 report 链充实后自然缓解。
- cloudBlocked 只锁 SP 增耗门卫，不回锁 rowInitDone（内容上行合法，假账源头=SP 写操作已被门卫断）。

## 四、验收标准

1. 手机假开启态（系统云空间未放行）冷启/切前台：不弹签到；点任意 SP 功能弹「云同步未真正生效」引导 → 点按钮跳系统云空间。
2. 系统设置放行后回 app：SP 行下行 → 引导消失 → 签到/礼包正常。
3. 未开云同步点「重置为新用户资产」：直接成功清零+登出+退出（无"云同步未就绪"报错）。
4. 云同步就绪态重置：本地+云端两行均清零。
5. 新用户（无他设备痕迹）首开云同步：礼包照发（fail-open）。
