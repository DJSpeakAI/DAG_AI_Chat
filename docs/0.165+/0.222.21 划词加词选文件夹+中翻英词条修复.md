# 0.222.21 划词加词选文件夹 + 中翻英词条方向修复

> 版本：0.222.21（承接 0.222.20 / versionCode 1000223 → 本版 1000224）
> 日期：2026-10-11
> 类型：功能迭代 + bug 修复（改码主战场 ChatPage.ets + ApiClient.ets）

## 一、需求（用户口述拍板）

### 需求 1：划词翻译加词时选择目标文件夹

- 现状：对话页划词 → 点「翻译」→ AI 查词浮窗 → 点「加入单词库」→ **直接落入默认根目录**（`new WordItem(...)` 漏传 folderId，0.222.20 同款根因的另一个漏点）。
- 用户需求：单词库已有文件夹体系（0.222.19，用户按「四级单词 / 数学英语 / 计算机英语」等分类），加词时**必须让用户选择归入哪个文件夹**。
- **UI 铁律：弹窗界面与单词库现有「移动/复制」弹窗（folderPickerDialog）完全一致**——树形层级+竖直连接线+├/└ 拐角+折叠小三角+行高 32/字号 13/RADIUS_NAV/宽 isTablet?520:'86%'，根目录行显示单词总数，点行即确认、点取消/遮罩关闭。用户原话「你先跟他一样之后的话，我们到时候会去改」。

### 需求 2（bug）：划中文时词条方向错乱（英翻英）

- 现状（ApiClient.ets `buildWordQueryZhPrompt`，0.155 设计）：划中文 → AI 返回 `word=英文词组, explain=英文词组（与 word 相同）` → 入库后 **word 与 explain 都是英文**。用户实测反馈：「我划的是中文，他还是给我英文放到单词（word 字段），那我就是英翻英，英翻英就没必要，内容跟单词变成了一样的了」。
- 修复方向（用户拍板）：**中翻英就是中翻英**——划中文 → 词条 `word=划选的中文原文`、`explain=英文翻译`、`usPhonetic=英文词组音标`；划英文 → 维持现状 `word=英文原文`、`explain=中文释义`（英翻中）。
- **检测规则（用户原话）：以划词文本的第 1 个字符是中文还是英文来判定方向**（首字符中文=中翻英，否则英翻中；替换现有「任一字符含中文」检测）。
- 联动：翻译浮窗发音逻辑同步换首字符检测（首字符中文 → 播英文译文 explain，原行为语义保留）。

## 二、方案

### A. 加词选文件夹（ChatPage.ets）

1. 新增状态：`@Local wordFolderPickerVisible`（弹窗可见）+ `@Local wordPickerCollapsedFolderIds: string[]`（折叠态，**string[] 替换引用触发重渲染**——0.222.2 铁律）。
2. `addCurrentWordToBank()` 改为打开选择弹窗（不再直接入库）；埋点挪到真正入库时。
3. 新增 `confirmAddWordToFolder(folderId)`：`new WordItem(r.word, r.fullName, r.usPhonetic, r.explain, '', 0, 0, 0, 0, 0, folderId)` **显式传第 11 参 folderId**（0.222.20 教训：构造尾部可省参数=最容易漏）→ `addWordToBank` → 按钮转「已加入」→ 关弹窗。
4. 复刻单词库弹窗四件套方法：`wordPickerTreeItems()`（DFS+isLast/ancestorIds/ancestorHasNext 连接线字段，加词场景无排除项）/ `wordPickerHasChildren()` / `isWordPickerCollapsed()` / `toggleWordPickerCollapse()`。
5. 新增无参 `@Builder wordFolderPickerDialog()`（0.190.1 铁律：无参直读状态）——结构与样式逐行复刻 WordBankPage.folderPickerDialog，标题「加入单词到…」。
6. build 渲染在翻译浮窗 if 块之后（层级在上）；`handleBack()` 在 wordPopupVisible 之前加弹窗拦截（返回键先关选择器）。
7. TREE_CELL=14 常量在 import 区全部结束后新增（arkts-no-misplaced-imports 雷规避）。

### B. 中翻英词条修复（ApiClient.ets + ChatPage.ets）

1. 新增 `startsWithChinese()`（首字符 CJK 0x4E00-0x9FFF 检测），`queryWord()` 的 prompt 分流改用它；旧 `containsChinese` 引用清零后删除（project_rule 清理铁律）。
2. `buildWordQueryZhPrompt` 改字段规则：`word=用户划选的原文（一字不改原样返回）`、`explain=翻译后的完整英文词组`、`usPhonetic=英文词组音标`。
3. ChatPage `wordPopupSpeakText()` 检测换 `startsWithChinese`（import 同步替换）。

## 四、风险点

- WordItem 构造第 5~10 参占位（id/createTime 等默认值）须逐个显式传 ''/0 才能传到第 11 参 folderId——漏一个即字段错位。
- 弹窗必须渲染在翻译浮窗**之后**（同层 Stack 后绘制在上），否则被浮窗遮罩挡住点不到。
- 混合文本（如「AI学习」）按首字符判英文走英翻中 prompt——与旧「任一字符中文」行为不同，属用户拍板的方向性变更。
- ArkTS 雷规避清单：@Builder 无参化 ✓ / @Local string[] 替换引用 ✓ / import 区后插常量 ✓ / 照搬代码核对 import（WordFolder/WordFolderTreeItem）✓。

## 五、验收标准

1. 划中文（如「你好」）→ 翻译 → 浮窗显示原文+音标+英文 → 加入单词库 → 词条 word=「你好」、explain=英文，**二者不同**。
2. 划英文（如「hello」）→ 词条 word=「hello」、explain=中文释义（现状不回归）。
3. 点「加入单词库」→ 弹文件夹选择弹窗，UI 与单词库移动/复制弹窗一致；选「四级单词」文件夹 → 单词库该文件夹下出现新词条；选根目录 → 落根目录。
4. 弹窗内折叠三角、树形连接线、返回键/取消/遮罩关闭全部可用；加词成功后浮窗按钮转「已加入」防重复。
5. 装机后 bm dump 实锤 versionCode=1000224 + 界面版本号显示 v0.222.21。
