# 0.282.0 回复模式两档与输入区工具行重构（DeepSeek 式）

> 版本：0.282.0 / versionCode 1000393
> 日期：2026-10-21
> 需求来源：用户口述 + DeepSeek 输入区参考截图（用户外出前直接下令开工）

## 一、需求

1. **播客模式入口下线**：所有对话都走正常对话；「正常对话｜播客模式」标签整组不出现。播客模式用户尚未想清楚，想清楚后再加回。
2. **短回复并入中回复**：取消「短 / 中 / 长」三档手动标签。用户明确短回复的真实使用场景=
   - 封闭性问题（只需回答是不是 / 对不对 / 能不能）；
   - 单一问题 + 封闭情况 → 超短回复；
   - 用户一次问多个「是不是」类问题 → 可以逐一回答、也可补充。
   核心诉求：**让 AI 自己理解用户提问需要多深的回答**，而不是靠用户手动选档。
3. **深度思考开关替代长回复标签**：默认不打开=中回复；打开=长回复。布局参考 DeepSeek：
   - 输入大框内下层工具行；
   - 左：加号（添加图片）；
   - 左：深度思考开关（类似 DeepSeek 深度思考胶囊，图标不用和对方一样，先加进去）；
   - 右（原箭头位置、右下角）：发送按钮。
4. 改完编译、三台（PC/Pad/手机）覆盖安装、GitHub 上传。

## 二、方案

### 2.1 回复模式（内部仍是两档）

- `replyLengthMode` 保留，值域收敛为 `'medium' | 'long'`（`'short'` 下线；默认 `'medium'`，仅内存态、重启回到中回复）。
- 深度思考开关 = `replyLengthMode === 'long'`：
  - 关（默认）→ `MEDIUM_REPLY_PROMPT`
  - 开 → `LONG_REPLY_PROMPT`（长回复原有能力全保留：恒 high 思考、`##` 分节、密度锚点、折叠、伴读两段式编排）
- `SHORT_REPLY_PROMPT` 删除；其「一句话结论」能力并入 `MEDIUM_REPLY_PROMPT`：
  - 封闭性问题 / 单一事实询问 → 1~2 句直接给结论，禁止展开、分点、补充无关内容；
  - 一个问题含多个小问 → 可逐一回答并适当补充；
  - 其余 → 简洁完整。
  - 保留 0.279.0「禁确认 / 复述指令」负向约束（防 prompt 泄漏）。
- `resolveThinkingFor` 的 `short` 分支保留作防御（存量内存态/未来回滚），不删逻辑。

### 2.2 播客模式

- 删除 `@Local sendMode` 及标签层入口、发送埋点的 mode 来源改为回复模式。
- 发送恒为正常对话；不再注入 `PODCAST_PROMPT`。
- **数据兼容**：`ChatMessage.isPodcastMode` 字段（Schema 尾部字段）保留，历史播客消息仍按原样式渲染；其重生成仍按 `isPodcastMode` 追加播客 prompt（历史数据语义不变）。
- `sendMode` 相关埋点 `podcast_mode` 入口一并消失（历史事件保留在云端）。

### 2.3 输入区工具行（仅聚焦态，与 0.281.4「默认三件」一致）

- 删除：短/中/长三档标签、正常对话/播客模式标签、聚焦态输入行右侧发送按钮。
- 新增下层工具行：
  - `+`（`plus.svg`）→ `selectImages()`
  - `深度思考`胶囊（`timer.svg` + 文字，选中=品牌紫底白字）
  - `Blank()`
  - 发送圆形向上箭头（`arrow_up.svg`，右下角，isLoading 半透明禁点）
- 未聚焦态保持 0.281.4 定案：左树杈（新建气泡）/ 中间占位提示 / 右屏幕圈注。

## 四、风险点

1. **prompt 行为变化**：中回复现在会主动压缩简单问题；复杂问题不受影响（仍是「简洁完整」）。需要真机试几条封闭性问题确认不再啰嗦。
2. **深度思考开关可见性**：工具行只在聚焦态出现（沿用 0.281.4），未聚焦时看不到当前档位；发送后的 waitingView 会显示「· 深度思考」作为状态提示。
3. **历史播客消息**：数据字段保留、渲染兼容；只是不能再新建播客消息。
4. **hypium 既有 failure=7**：与本次改动无关（0.281.5 时期同基线），本次未改 ChatModel 逻辑。

## 五、验收

1. 输入框聚焦 → 下层出现 `[+] [深度思考]`，右下角出现发送箭头；无「短中长」「正常对话/播客」。
2. 点深度思考 → 紫底高亮；发送后 waitingView 显示「· 深度思考」，回复为长回复形态（分节/锚点/折叠等按设置生效）。
3. 关闭深度思考 → 发「这个说法对吗」类封闭问题 → 回复 1~2 句。
4. 播客入口在三端彻底不可见；历史播客消息仍正常显示。
5. 三端覆盖安装版本号 1000393。
