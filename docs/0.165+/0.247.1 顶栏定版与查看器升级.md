## 一、四条需求（用户原话拍板）

1. **顶栏文字固定死**：不跟 API 配置的模型别名走；API 配置里 4 个模型供应商的「模型别名」输入框全部删除（机制下线）；文案加「仅供参考」（前面加点）；手机顶栏那组文字加宽（截图实测 45% 截断成"内容..."），PC/Pad 横屏无此问题。
2. **PC 端去掉对话右滑删除**：鼠标右滑（按下拖动）是划词手势，被滑动删除抢走；现 PC 鼠标要长按 500ms 才划词，不符合习惯。手机/Pad 保留滑动删除。
3. **司忆区正面缩略图左对齐**：现在挂在标题行尾=右对齐，应放行首；翻译弹窗、入知识库弹窗（圈注入库同款）、气泡底部复习区三处统一。
4. **图片查看器升级**：①手机/Pad 双指捏合放大太快不丝滑→降速；②手机/Pad 长按放大的图片无保存按钮→补长按菜单；③PC 滚轮不能缩放→补；④PC 右击保存菜单 UI 难看→重设计；⑤UI_GUIDELINES 无图片放大规范→新增写入。

## 二、改动方案

### 2.1 顶栏（ChatPage.ets topBarModelText / topBarTitle）
- 模型名固定=`apiConfig.model` 原名（删别名链）；文案=`{模型名} · 内容由 AI 生成 · 仅供参考`。
- maxWidth 45%→60%。
- 删 aliasStore 引用与 import（ModelAliasStore 类本体与 ApiConfig.modelAlias 字段保留=Schema 铁律，仅消费点全清）。

### 2.2 别名机制下线（GlobalSettingsDialog.ets）
- 删：editAlias/aliasStore 两状态、开弹窗回显+搭救回灌段、保存赋值、五处「跟随模型带出」、预设/自定义两处「模型别名」输入框 UI、import。
- 保留：ApiConfig.modelAlias 字段（持久化 Schema 禁删）、ChatModel ModelAliasStore 类（存量 key 'model-alias-v1' 不动）。

### 2.3 PC 判定与滑动删除（ChatPage.ets）
- 新增 `@Local hasMouse`：aboutToAppear 走 `inputDevice.getDeviceList`→`getDevice(id)` 查 sources 含 'mouse'/'touchpad'（d.ts 已核实 API 签名；PC 必有鼠标/触控板，Pad/手机无）。
- 消息 ListItem swipeAction：`start: this.hasMouse ? undefined : builder`——PC 不挂删除面板，鼠标拖动回归划词；手机/Pad 原样。

### 2.4 司忆缩略图左对齐（ChatPage.ets 三处 4700/5485/5946）
- Image 从标题行尾（Scroll 后）移到 FoldChevron 后、Scroll 前（行首），margin left:6→right:6。

### 2.5 图片查看器升级（ChatPage.ets）
- 捏合降速：`scale 增量 ×0.5`（`1+(event.scale-1)*0.5`，对齐 0.214.2 滚轮降速先例）。
- PC 滚轮缩放：Image 挂 `PanGesture(direction: Vertical)`，onActionUpdate 判 `sourceTool===MOUSE/TOUCHPAD`（d.ts 已核实 GestureEvent.sourceTool since 9）→ `viewerScale × (1-offsetY/600)`；Finger 源忽略（不干扰触摸）。
- 长按保存（触摸）：Image 挂 LongPressGesture(500ms)→底部弹出「保存图片」菜单卡（@Local viewerMenuVisible），点项保存/点外收起。
- 菜单 UI 重设计（PC 右键 viewerSaveMenu 与触摸长按菜单同款）：深色卡（SURFACE_NODE+描边+阴影）、保存图标+14fp 白字、圆角 RADIUS_CONTROL——替换原素底紫字丑版。
- UI_GUIDELINES 新增「图片查看器」组件规范章节（缩放范围/双击/捏合速率/滚轮/长按保存/退出冗余）。
