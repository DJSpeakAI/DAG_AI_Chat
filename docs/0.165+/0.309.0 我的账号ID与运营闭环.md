# 0.309.0 我的账号 ID + 看板运营闭环

> 2026-10-24 · 用户三问驱动的运营链基建（发奖/扣费/客服场景的"人↔账号ID"桥）

## 一、需求（用户口述）

未来运营场景（bug 补偿/活动发奖/扣充能 SP）都需要拿用户账号 ID，但：
1. 华为隐私设计：个人开发者拿不到账号手机号 → 手机号↔账号 ID 映射只能运营手工绑
2. app 无账号 ID 展示 → 用户不知道自己 ID → 运营拿不到 → 链路断点
3. 看板缺"最近上报账号"入口（用户记忆的"刷新 ID"曾被误删）

## 二、改动

| 端 | 文件 | 改动 |
|---|---|---|
| app | GlobalSettingsDialog.ets | 云同步 Tab 新增「我的账号 ID」卡：脱敏显示（前 8…后 4）+「复制」按钮；复制模板=`账号 ID：{完整}\n我的手机号（请填写…）：`（手机号占位用户自填——app 拿不到手机号）；未登录=「登录华为账号后可查看」 |
| 看板 | dashboard-v2/index.html | SP 数据台查询按钮旁加「最近上报的账号」（调既有 `__recent__` 接口列 50 行，每行自带填入/绑手机号/下指令按钮——比被删的原版更强） |

## 三、合规依据（用户问华为官方）

OpenID/UnionID 是华为账号登录标准标识符，客户端/服务端均可获取（官方 FAQ faqs-account-22/6 明示）；展示给用户本人+用户主动复制上报=用户自身数据的主动行为，无手机号等敏感个人信息采集，合规。

## 四、运营闭环全景（定稿认知）

1. **自动**：用户开 app+SP 变动 → SpMirror 镜像自动上报 → 看板「最近上报的账号」可见
2. **人↔ID 桥**：用户 app 内复制 ID（含手机号占位）→ 邮件/客服发给运营 → 运营看板查 → 卡片「绑定手机号」→ 此后手机号直查/直下指令
3. **下指令**：grant/deduct(_perm) → pending → 目标账号任一设备开 app/回前台拉取执行 → done（claimed 10 分钟未 confirm 自动回收重派）

## 五、验收

1. 设置→云同步：已登录见脱敏 ID，复制后剪贴板含完整 ID+手机号占位行 ✓
2. 看板 SP 数据台：点「最近上报的账号」列出镜像行，可点可绑 ✓
3. 四台热装 1000464 ✓
