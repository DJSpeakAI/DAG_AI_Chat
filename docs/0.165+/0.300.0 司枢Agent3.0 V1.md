## 关键实现决策（落码 AI 拍板）

- **异步等待替代状态机**：反问/御史用 async/await Promise 化（sendMessage 本就 async），闭包环境完整保留，杜绝状态机重建；aboutToDisappear/新消息重入统一 resolve(null) 兜底。
- **落账抽闭包**：startStream 的 onDone 落账段抽 finalizeStream——交付型「执笔→御史→打回重写→终审」全链 token 累加一次性落账（军令延续）。
- **契约不进 ChatMessage Schema**：会话级 Map（contractByMsg）承载交付卡渲染依据，刷新后退化为普通气泡（正文不丢，纠偏钮消失可接受）。
- **联网胶囊两态**：webMode boolean→'auto'（默认，枢机恒挂 tools 自主+单段关键词预路由）/ 'force'（强制挂）；预路由关键词表宽匹配（宁可多挂）。
- **creative V1 归并 deliverable**（多样本 V2）。
