## 三、技术方案

### 3.1 词库形态：编译期常量（否决 rawfile 方案）

- 项目内**无运行时读 rawfile 先例**，TextDecoder API 无既定模式可抄 → 直接生成 `utils/SensitiveWords.ets` 常量数组（17.6KB），同步可用、零 IO、零解码 API 风险、无异步加载时序问题。

### 3.2 匹配算法：DFA 前缀树（`utils/ContentFilter.ets` 新文件）

- Trie 节点 = `Map<string, TrieNode>` + endCats（类别串）；文本沿树走，非逐词正则，千级词库毫秒级。
- **normalize 防绕过**：全角→半角（0xFF01-0xFF5E → -0xFEE0）+ 小写化 + 去空白类字符（空格/Tab/换行/全角空格，防"法 轮 功"式分隔绕过）；词表入树时同款 normalize。
- **双 Trie 分域**：INPUT=三表全量；OUTPUT=政治+色情两表（buildTrie(includeWeapons) 开关）。
- **输出侧流式扫描（WordScanner 工厂）**：闭包维护 tail 缓冲，保留"最长词长-1"字符跨 chunk 拼接，杜绝 chunk 边界切词漏检（如"法轮"+"功"分两片到达）。

### 3.3 接入点（ChatPage.ets 四处）

| # | 位置 | 行为 |
|---|---|---|
| 1 | import 区 | 引入 ContentFilter/FilterHit |
| 2 | sendMessage guard 区（空输入守卫后、send 埋点前） | checkInput 命中 → 埋点 filter_input_hit（只报类别不报词，隐私红线）→ toast「消息包含违规内容，已停止发送，请修改后重试」→ return（不出网） |
| 3 | sendMessage streamChat 前 + onChunk 内 | 创建输出扫描器；命中 → 埋点 filter_output_hit → streamController.cancel() → 该条 AI 气泡文案替换为「（回复包含违规内容，已被安全机制拦截，请重新提问）」→ 状态复位 + 写穿 + 落盘 + toast「回复包含违规内容，已拦截」 |
| 4 | regenerateMessage 同款 | 与 3 口径一致（重新生成同属 AI 输出） |

### 3.4 关键安全论证

- **cancel 后回调静默**（ApiClient.ets 实锤：cancelled 三处守卫 334/386/457 行 `if (cancelled) return`）→ onChunk 内设的安全文案**不会被 onError 的 classifyStreamError 覆盖**。
- 输入拦截置于 send_message 埋点之前 → 违规输入不计发送统计（统计纯净）。
- 输出侧不收涉枪涉爆表 → AI 科普诺贝尔/化学史不误杀。

## 附录：词库再生成脚本（node，词表更新时用）

来源文件：github.com/fwwdn/sensitive-stop-words（下载后取 政治类.txt / 色情类.txt / 涉枪涉爆违法信息关键词.txt）。清洗：`tr -d '\r'` → 去行尾标点 → trim → 去空行 → `awk 'length($0)>=2'` → `sort -u`。然后跑：

```js
// genwords.js（node 运行，工作目录=项目根）
const fs = require('fs');
function load(p) {
  const ws = [];
  for (const line of fs.readFileSync(p, 'utf-8').split('\n')) {
    const w = line.trim();
    if (w.length >= 2 && !ws.includes(w)) ws.push(w);
  }
  return ws;
}
const esc = s => s.replace(/\\/g, '\\\\').replace(/'/g, "\\'");
const arr = ws => {
  let out = '';
  for (let i = 0; i < ws.length; i += 8)
    out += '  ' + ws.slice(i, i + 8).map(w => `'${esc(w)}'`).join(', ') + ',\n';
  return out;
};
const file = `// 0.250.0 敏感词库常量（脚本生成，禁手改；更新须重跑生成脚本）
// 来源：github.com/fwwdn/sensitive-stop-words（开源词库，已清洗去重：去空行/去重/trim/长度>=2）
export const SENSITIVE_POLITICAL: string[] = [\n${arr(load('pol.txt'))}];
export const SENSITIVE_PORN: string[] = [\n${arr(load('porn.txt'))}];
export const SENSITIVE_WEAPONS: string[] = [\n${arr(load('weapons.txt'))}];
`;
fs.writeFileSync('entry/src/main/ets/utils/SensitiveWords.ets', file, 'utf-8');
```
