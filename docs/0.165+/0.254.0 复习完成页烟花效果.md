# 0.254.0 复习完成页烟花效果

## 需求（用户原话要点）
- 参考桌面 123.txt「指尖烟花」方案，做烟花效果
- 位置：卡片复习区域（ReviewPage）最后的「复习完成页」
- 自动 + 手动一起放：进入完成页自动表演；用户点击空白区域也有烟花
- 硬约束：按钮点击不被遮蔽/不被干扰（继续复习 / 完成 / 登录入口等照常可用）

## 方案
**纯 ArkTS Canvas 原生实现**（123.txt 是 ArkWeb+JS 方案，本项目无 Web 组件先例且 Web 层触摸拦截与本页多层叠点击冲突，故只移植其物理算法，不用 ArkWeb 宿主）：

1. 新组件 `components/FireworksOverlay.ets`：全屏 Canvas（坐标 1:1 映射 vp，BBTreeCanvas 0.167.2 实锤），叠在完成页内容**底层**。
2. 物理参数照抄 123.txt：发射体从底部飞向目标点 → 到达爆 55 粒子（随机方向、初速 65~210）→ 粒子受重力 65、指数阻力 exp(-0.6·dt)、寿命 1.2~1.8s；每帧半透明深色（BG_CANVAS #160D26 的 25%）覆盖清屏形成拖尾；上限发射体 4 / 粒子 440（超限暂缓/减量，防连点内存膨胀）。
3. 自动表演：进入完成页 0.2s 后首发，此后每 ~1.3s（±随机）随机位置发一束。
4. 手动：点击空白区域 → 发射体从底部飞向点击处；发射体已满 4 时原地即爆（连点永远有反馈）。
5. **按钮不遮蔽**：命中测试天然分层——上层内容（按钮等有 onClick 的组件）拦截点击正常工作；纯展示区域（Text/总结卡无事件）点击穿透到 Canvas 触发烟花。零遮罩、零事件劫持。
6. 色彩：每束随机 hue，HSL→RGB 纯函数拼 rgba 字符串（不依赖 hsla 字符串解析兼容性）。

## 风险点
- 定时器泄漏：组件卸载（继续复习/退出完成页）→ aboutToDisappear clearInterval（铁律）
- 尺寸变化（分屏/悬浮窗）：onAreaChange 重读宽高 + 重置底色铺底标志
- 性能：粒子峰值 440 线段/帧，Canvas 2D 无压力；粒子全空时跳过铺底绘制省电
- 视觉：拖尾覆盖色与完成页背景 BG_CANVAS 一致，无两层色差

## 验收标准
1. 背完一轮进完成页：自动放烟花（约 1.3s 一发，位置随机）
2. 点空白/总结卡文本区：对应位置有烟花（发射体飞达爆炸）
3. 「继续复习」「完成」「登录后体验 AI 鼓励」按钮点击照常（不触发烟花、不误触）
4. 「继续复习」回到复习→再完成 → 烟花层重建正常；退出页面无定时器残留
