## 第一部分：给 Pixso AI 设计师的需求书（可直接复制发送）

### Goal

为「**DAG AI Chat**」（一款 HarmonyOS 原生应用，DAG 气泡树对话学习工具）设计**主画布工作台**界面：左侧导航栏 + 中部气泡树画布的双栏布局。整体采用**深暗紫色系**，风格定位为「专业深度学习工具」——安静、克制、有沉浸感，避免娱乐化卡通倾向。

### Confirmed Requirements（已确认的设计要求）

**色板（深暗紫色系，已定稿）**：

| 用途 | 色值 |
|------|------|
| 应用底色 | `#120B1F` |
| 左侧导航层 | `#1A1030` |
| 画布容器 | `#160D26` |
| 气泡节点卡片 | `#241640`（配 8% 不透明度白色描边） |
| 主紫色（品牌色/强调色） | `#7C4DFF` |
| 辅助紫（次级强调/悬停态） | `#A78BFA` |
| 文字主色 | 纯白 `#FFFFFF` |
| 文字次级 | 60%~70% 白 |
| 文字弱化 | 40% 白 |

**圆角与阴影（已定稿）**：

- 导航项圆角：12
- 气泡节点卡片圆角：18
- 画布容器圆角：24
- 控件（按钮/输入框）圆角：10
- 阴影：柔和、低透明度，避免生硬投影

**布局**：

- **平板基准 1280×800**：左侧导航栏 240 宽（含：导航项 + 底部账号区），右侧为圆角 24 的画布容器
- **手机基准 360×780（鸿蒙 vp 单位）**：侧边导航收窄为 72 宽图标栏，气泡节点纵向排布
- 左侧导航项（自上而下）：**画布**（当前选中态）/ **单词库** / **知识库** / **设置**；导航底部为**账号区**（华为账号头像 + 昵称/登录入口，与设置项并列或紧邻）

**画布区内容**：

- 顶部信息条（画布标题 + 节点统计）
- 6 个气泡节点卡片：每个卡片含 DAG 气泡 logo、节点标题、对话条数
- 节点间为 DAG 父子连线（有向、层级展开）
- 右下角缩放控件（放大/缩小/复位）

### Design Assumptions（设计假设）

- 遵循 **HarmonyOS Design** 设计规范（已添加鸿蒙官方设计组件库，见下）
- **应用已锁定暗色模式**（代码层 setColorMode(DARK)），**无需设计浅色变体**，只出暗紫一套
- 画布支持手势缩放与拖拽，设计稿需体现缩放控件的常态样式

### Background & Context（重要：组件库情况）

**本设计工作已在 Pixso 后台添加了鸿蒙官方设计组件库（HarmonyOS Design 官方组件）。请优先使用鸿蒙官方组件搭建界面框架（导航、按钮、卡片、图标等），再用上述暗紫自定义品牌色板覆盖组件默认色值。不需要从零自建设计系统，也不需要自绘基础控件。**

产品背景：DAG AI Chat 是一款「对话式 DAG 学习工具」——用户在画布上以气泡节点的形式组织多条 AI 对话，节点之间以有向无环图（DAG）连接，形成知识树。主画布工作台是应用的核心界面，用户在此总览、管理、进入各个对话节点。

### Scope

- **本次设计**：主画布工作台（平板 + 手机两个画板）
- **本次不设计**：对话页内部、单词库/知识库/设置页内部（后续迭代）；画布「选项卡模式」（现有画布有平铺/选项卡双模式，本次仅设计**平铺模式**）

### Solution Design（期望产出）

- 平板（1280×800）主画布工作台完整设计稿 1 张
- 手机（360×780）主画布工作台完整设计稿 1 张
- 关键状态标注：导航项默认态/选中态、气泡节点卡片默认态/悬停态、账号区已登录/未登录两种形态
- 组件规格标注：色值、圆角、字号、间距

### Implementation Steps（建议步骤）

1. 先用鸿蒙官方组件搭出双栏布局骨架（平板/手机各一）
2. 套用暗紫色板覆盖组件默认色
3. 填充画布区内容（信息条 + 6 节点 + 连线 + 缩放控件）
4. 补齐状态标注与规格标注

## 第二部分：现状对照分析（开发侧依据，供设计师参考）

> 本段描述应用**现有**实现，供设计师理解迁移前状态；设计稿回来后，开发侧将按稿重构。

### 现有页面结构

| 页面 | 现状 |
|------|------|
| Index 首页 | 居中大标题 +「进入对话画布」按钮 + 华为账号登录/退出区 + 版本号 |
| BBTreeCanvas 画布页 | 全屏画布，气泡节点可拖拽、双击进入对话、长按弹出菜单；有平铺/选项卡双模式 |
| ChatPage 对话页 | 自定义标题行 + 消息气泡列表 + 底部输入区 |
| 单词库 / 知识库 / 设置 | 独立页面，从画布页路由跳转 |

### 结构级重构说明（设计师需知）

本次设计是**信息架构级重构**：现有应用是「首页 → 画布 → 各功能页」的多页 push 导航（Navigation Stack 模式）；目标结构是「左侧导航 + 主工作区」的**侧边栏工作台**——用户不再经过首页，打开应用直接进入画布工作台，通过左侧导航切换功能区。

### 必须保留的功能点位

设计稿中需为以下现有功能预留位置：

1. **华为账号登录/退出**（现有登录区在首页，新结构移至左侧导航底部账号区）
2. **版本号展示**（v0.166.x，可放导航底部或设置页入口附近）
3. **画布平铺/选项卡双模式**（本次仅设计平铺模式，但导航/画布结构需为选项卡模式留出后续迭代空间）
4. **气泡节点交互**：拖拽摆位、双击进对话、长按菜单（新建子节点/圈注/删除等）——设计稿体现常态即可，交互态后续补

### 技术约束（开发侧实现能力边界）

- HarmonyOS ArkUI 声明式开发，Navigation 路由容器已切 Stack 模式（单栏，v0.166.2）
- 主题已锁暗色（v0.166.3），全项目色值走统一暗色分支
- 气泡节点为自绘组件（Canvas 连线 + 可拖拽卡片），设计稿的节点卡片样式可直接落地
- 侧边栏工作台结构可用 Navigation 自定义侧边栏或双栏容器实现，平板/手机自适应断点已有先例
