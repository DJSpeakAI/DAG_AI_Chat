# 0.185.0 单词库设置新增「音标口音」切换（美式/英式 + 确认提示框）

> 开线：2026-10-04。**当前版本：v0.185.0（versionCode 1000049），已实现（2026-10-04），待编译装机验收。**

## 一、需求分析

- 单词库设置弹窗（顶栏 ⚙）目前仅有「学习数量设置」（复习显示数量）一项。
- 新增「音标口音」设置项：**美式音标（默认）/ 英式音标** 二选一。
- 切换流程（用户指定）：点击另一口音 → 先弹确认提示框，告知「**切换音标后，原先的音标将会被删除**」→ 用户确认后执行切换并更新音标数据；取消则不切换。
- 音标口音需跨重启保存（PersistenceV2）。

## 二、设计思路

1. **口音存储**（`common/ChatModel.ets`）：新增 `PhoneticAccentStore`（`@ObservedV2` + `@Trace british: boolean = false`，false=美式默认）+ `connectPhoneticAccent()`——PersistenceV2 **独立全新 key `'phonetic-accent-v1'`**，与 LearnCountStore 同模式（全新 key 首次创建即含全部字段，无旧快照缺字段坑）。
2. **音标数据更新**（`utils/WordStoreUtil.ets`）：新增 `clearAllPhonetics(store)`——遍历将全部词条 `usPhonetic` 置空（`@Trace` 保证列表即时刷新；不重建数组，ForEach key=w.id 不受影响）。
3. **查词 prompt 口音化**（`utils/ApiClient.ets`）：`WORD_QUERY_PROMPT` / `WORD_QUERY_ZH_PROMPT` 由常量改为按口音生成（「美式音标」↔「英式音标」，其余文案与 JSON 格式约束不变）；`queryWord` 内通过 `connectPhoneticAccent()` 读取当前口音（PersistenceV2.connect 幂等，调用方零改动）。不口音化则切换后新查词仍生成美式音标，与设置矛盾。
4. **设置弹窗 UI**（`components/WordBankPage.ets` `learnSettingsDialog()`）：
   - 标题「学习数量设置」→「设置」（两项设置后不再是单一学习数量弹窗）。
   - 原学习数量描述改为小节标签「复习显示数量」+ 原描述。
   - 新增「音标口音」小节：描述 + 「美式（默认）」/「英式」两按钮（样式对齐学习数量按钮：选中 TEXT_PRIMARY+BRAND_PRIMARY、未选 TEXT_SECONDARY+透明、layoutWeight(1)、margin left 8）。
   - 点击已选口音无操作；点击另一口音 → 记录待切换口音，确认弹窗叠在设置弹窗之上（对齐 0.184.0「返回确认弹窗覆盖补充要求」先例）。
5. **确认弹窗**（新增 `phoneticConfirmDialog()`，样式对齐 `deleteConfirmDialog()`：面板 86%/RADIUS_NAV/SURFACE_NODE/padding 20、标题 FONT_SIZE_SCREEN_TITLE/600/TEXT_PRIMARY、遮罩 OVERLAY）：
   - 标题「切换音标」+ 正文「切换音标后，原先的音标将会被删除」。
   - 「取消」→ 仅关确认弹窗（留在设置弹窗，口音不变）；「确认切换」（TEXT_PRIMARY + DANGER 底，对齐删除按钮红色警示先例）→ 翻转口音 + `clearAllPhonetics` + 关确认弹窗 + toast 反馈。
6. **返回键拦截**：`phoneticConfirmVisible` 在 `learnSettingsVisible` 之前拦截（上层弹窗先关）。

## 四、风险点

- PersistenceV2 全新 key 模式，无旧快照缺字段坑（0.143 教训已规避）。
- `clearAllPhonetics` 逐项置空 `@Trace` 字段，列表即时刷新，无 ForEach key 问题。
- prompt 动态化仅改音标类型词，JSON 格式约束不变；模板串内 `{"word":...}` 无 `${` 序列，安全。
- `usPhonetic` 字段名保留不改（改名需动多处调用方，非最小改动），语义升级为「当前口音的音标」+ 注释。
- ApiClient 引 `connectPhoneticAccent` 无循环依赖（ApiClient 已引 ChatModel 的 ChatMessage 等）。

## 五、验收标准

1. 设置弹窗显示「音标口音」小节，默认选中「美式（默认）」。
2. 点击「英式」→ 弹确认框「切换音标后，原先的音标将会被删除」；取消 → 口音不变、留在设置弹窗；确认 → 口音切英式、全部词条音标清空（列表即时刷新）+ toast 反馈。
3. 切换后新查词（划词翻译/查词）生成的音标为英式（prompt 口音化）。
4. 重启应用口音设置保持（PersistenceV2）。
5. 返回键：确认弹窗打开时先关确认弹窗，再关设置弹窗。
6. 编译 BUILD SUCCESSFUL，无新增告警（基线仅 2 个历史 media 警告）。
