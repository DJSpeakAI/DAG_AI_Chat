## 三、关键技术结论（勿重查）

- **Path 无 viewport 属性**：未设置时 ArkUI 自动缩放 commands 适配组件尺寸 → 连线飞左上角真根因。自由绘图一律 Canvas 命令式（`redrawEdges()`，重排/视口/缩放/平移/捏合/删除/返回全触发重绘）。
- **缩放锁死根因**：对称限幅在 scale 越界后永远进不了合法区间；修复 = 限幅方向感知（放大只拦 2.0、缩小只拦 0.05，zoomBy 与 PinchGesture 同步）。
- **fitViewport topSafe**：垂直可用区排除信息条底板（flat=80 / tabs=128）；`scale = min(viewW/treeW, (viewH-topSafe)/treeH, 1.0)`；offsetY 从 topSafe 起在剩余区域居中——首节点不再被底板遮挡。
- **registerFont since18 废弃**：改用 `windowStage.getMainWindowSync().getUIContext().getFont().registerFont(...)`（loadContent 回调内）。
- **字体三 familyName**（'Inter'/'Inter-Medium'/'Inter-SemiBold'）：Pixso 导出三份同名注册互相覆盖是瑕疵勿照抄；中文自动 fallback 系统 HarmonyOS Sans SC，无需打包中文字体。
- **布局几何单一来源**：NODE_W/NODE_H 从 DesignTokens 引入 ChatModel，防布局与 UI 漂移。
- **控件树 y 分段分析法**（验证技巧）：层间距 = 160×s（verticalSpacing×scale）、树间过渡 = 188×s，可从截图坐标反推树结构与 scale。
- 连线规格真相源 = 平板稿 `Frame_2_664.svg` 矢量（#7C4DFF 85% 宽 2、箭头实心三角 7×8.4），详见 UI_GUIDELINES 六-7。
