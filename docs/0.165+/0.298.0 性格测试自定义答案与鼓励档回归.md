3. **SP 门槛前置 + 开场引导页 + 节点奖励弹窗**：
   - 答题入口（画布信号灯 + GSD 重做）前置 `requireSiyiGate()`——未开云同步不进答题（SP 铁律：答题=SP 获得）；

## 三、设计要点

- **Schema 合规**：`customAnswers` 尾部追加（choiceAnswers 0.292.1 同款先例），key `personality-quiz-v1` 不变；与 choiceAnswers 逐题同步 push 保持等长对齐，历史数据 customs 长度<choices 读侧兜底 ''。
- **评阅链路零结构变更**：自定义文本只是 buildReviewInputs 输出格式扩展（`选项文案；自定义：xxx` / 纯自定义 `自定义：xxx`），AI 评阅/本地兜底/画像写入管道原样。
- **SP 弹窗时序**：granted>0 不立即推进题号，「继续答题」onClick 才推进（pendingAdvance 暂存）；granted=0（挂账，入口已拦截后概率极低）保持 toast。末节点弹窗叠在 FinishView 上，「完成」只关弹窗。
- **开场页条件**：`answeredTotal===0 && !started`；续做（>0）直接进 QuizView；GSD 重做 reset 后 answeredTotal=0 自然重现开场页。
- **UI 规范**：弹窗宽 480/90% 断点制（既有）；TextArea placeholder `placeholderColor(TEXT_TERTIARY)`；自定义行虚线描边（DashStyle）区分常规选项；奖励弹窗遵 12a。

## 四、风险点

- GSD 内弹 syncGatePrompt 存在层级遮挡风险 → 重做入口先 `requestClose()` 再 `requireSiyiGate()`。
- letters 空串哨兵：`choiceToOptionText('')` 返回 ''（现有循环天然跳过），`quizAnswerTotal` 按数组长度计数自定义题照常 +1——无既有代码破坏。
- 多 AI 并行：0.297.0 数学画板线可能触碰 BBTreeCanvas（+号双按钮入口）——改动区段（信号灯 1690-1710 附近）不重叠，编译冲突以实读为准。

## 五、验收标准

1. GSD AI 偏好 Tab 见鼓励三档，保存后复习完成/统计页按档位生成（off=固定一句话）。
2. 未登录/未开云同步点信号灯或 GSD 重做 → 弹云同步引导，不进答题。
3. 每题可见「以上都不像——我想自己说」，选中展开灰 placeholder 输入框；单选互斥；空/单字提交被拦。
4. 首次进入见开场页；5/10 题弹奖励弹窗点「继续答题」推进；15 题末节点弹窗「完成」→ 完成页。
5. 自定义答案出现在评阅输入（测试断言）；画像照常生成。
6. 编译零错 + 四端冷安装冒烟。
