## 一、改动清单

### 1. 手机端顶栏间距收紧对称（10/10）
- 搜索栏 Row padding top/bottom：4/4 → `(isTablet || isPcDevice()) ? 4 : 2`（两库同款）
- List padding top：12 → `(isTablet || isPcDevice()) ? 12 : 8`
- 效果：标题↔搜索栏 = 8+2 = 10；搜索栏↔首卡 = 2+8 = 10；顶栏 56/padding 8/8 不动；宽屏/PC 零变化

### 2. 搜索栏滚到底「鬼畜抖动」修复（真 bug）
- 根因：0.240.0 handleSearchScroll 无冷却期 + 收/放阈值对称（均 10vp）——触底回弹反向信号被判「下滑」→弹出→惯性又判「上滑」→收起，循环横跳
- 修法（两库逐字同款）：新增 `private lastToggleAt: number = 0`
  - **冷却期 300ms**：收/放切换后 300ms 内丢弃一切偏移信号（`scrollAccum = 0` 后 return——回弹尾巴不带进冷却后的判定）
  - **不对称阈值**：收起 10vp / 唤回 ≥24vp（`threshold = dir > 0 ? 10 : 24`）
  - 回顶强制显示（yOffset ≤ 0.5）、宽屏短路、直接赋值+transition 范式全部保留

### 3. 左下角浮动导航胶囊条（两库，仅手机端）
- 挂载：build Stack 弹窗层之前（弹窗盖胶囊、抽屉在最后盖一切）
- 结构：全屏 `Stack({ alignContent: BottomStart })` 容器 + **hitTestBehavior(HitTestMode.None) 穿透**（容器不拦列表触摸、胶囊本体可点——0.200.0 变暗层范式）
- 胶囊 Row：高 40 / padding 横 12 / 圆角 20 / SURFACE_NODE 底 + 1px STROKE_CARD 描边 / 左下边距各 14
- 内部：sidebar.svg（20×20，点击 openSidebar）＋ 1px 分隔线 ＋ 面包屑横向 Scroll（maxWidth 230，长路径横滑）
- 面包屑：根「全部卡片」（KB）/「全部单词」（WB）→ 各级文件夹名；chevronright.svg 16 分隔；当前级 BRAND_SECONDARY、祖先级 TEXT_SECONDARY；**点任意一级 `folderNav.folderId = 该 id` 直接跳转**（与边栏树同源）
- 滚动联动：复用 searchBarVisible（搜索栏显示=胶囊显示）；transition y:+8 / 200ms（与搜索栏 y:-8 镜像）
- 渲染条件：`!isTablet && !isPcDevice() && !multiSelectMode && searchBarVisible`；左上角入口保留（拍板本次不动）
