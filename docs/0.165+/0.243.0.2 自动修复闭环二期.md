## 三、方案（双层）

**层1 治本（默认启用，本期主交付）**：`autofix.model = "deveco/GLM-5.3"`——afRunCli spawn 追加 `-m` 参数，闭环全部 CLI 调用（修复任务+健康检查探针）走官方通道。官方网关无流式截断（实锤 #3），无人值守链路稳定。用户日常交互式 deveco 会话零影响（不传 -m 时行为不变）。

**层2 救生艇（默认关闭，基础设施储备）**：本地非流式适配代理 afProxy（server.js 内置）——CLI 的 provider baseURL 若被指到代理（`http://127.0.0.1:8989/compatible-mode/v1`），代理改写 `stream:false` 转发上游、整包 JSON 回拼标准 OpenAI SSE（role→reasoning→content→tool_calls→finish→usage→[DONE]），环回收流零截断。**当前局限（实锤 #4/#5）**：provider 覆盖通道未打通，启用前需配套「全新自定义 provider+auth.json 条目复制」或「项目插件 catalog.transform 改 api.url」——本期不投入，转发/拼装/SSE 回放代码保留待用。

```
层1（默认）：CLI(afLoop spawn) -- -m deveco/GLM-5.3 --> 官方网关（无截断，实测全绿）
层2（备用）：CLI -- baseURL=127.0.0.1:8989 --> afProxy -- stream:false --> 阿里网关
                                              └──整包 JSON 回拼 SSE──┘（覆盖通道待打通）
```
