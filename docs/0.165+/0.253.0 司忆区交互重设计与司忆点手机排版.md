# 0.253.0 司忆区交互重设计与司忆点手机端排版优化

日期：2026-10-18
基线：v0.252.1 / versionCode 1000312 → 本版 v0.253.0 / 1000313
改码：entry/src/main/ets/components/GlobalSettingsDialog.ets（单文件）

## 一、需求来源（用户 2026-10-18 手机截图 ×2 + 语音）

1. **司忆点页手机端排版乱**：等级表三栏挤一行——左侧「Lv8 司忆令」+ 中间含义被压缩截断（"最高神格！令，代表号令、法则制定..."）+ 右侧条件/权益两行右对齐，窄屏上折行混乱、信息密度过高。
2. **司忆区交互体验差（用户口述）**：「0/1/2/0~20 输入框 + 确定」结构中，用户没输入就点「确定」→ 弹红色「请输入 0~20 的整数」，看着像 bug（实际不是）。用户拍板方向：**取消两个「确定」按钮**——左下角已有「保存」统一落盘；用户点 0/1/2 直接选中；选自定义值直接在输入框输入，**输入合法值时输入框高亮（颜色变深），之前 0/1/2 的高亮自动取消**；授权 agent 自行优化细节。

## 二、设计方案

### A. 司忆区设置项（两项同款：单词库词条数 / 知识库卡片数）

- **删除**：每项的「确定」按钮 + 红色错误 Text（reviewWordError / reviewCardError 状态随之删除）——「没输入点确定报红字」的场景随确定按钮一起消失。
- **新交互（即时选中，保存统一落盘不变）**：
  - 点 0 / 1 / 2：直接写编辑副本 `editReviewLearn/Knowledge = n`，同时清空输入框（防残留数字误导选中态）。
  - 输入框输入：即时清洗（保留 0.252.0 双防线清洗）后：
    - 合法（0~20）→ 即时写编辑副本（保存仍走底部「保存」），输入框亮紫描边=自定义值选中态；此时 0/1/2 自动全暗（值 ∉ {0,1,2}）。
    - 空 → 不写值，保持当前选中。
    - 超 20 → **不写值**（保存永远取最近一次合法选中，绝不落非法值），输入框红色描边弱警示（不再弹红色大字报错）；改回合法值即恢复。
- **选中态判定**：输入框高亮条件 = `editReviewLearn > 2`；警示态 = `@Computed reviewWordWarn/reviewCardWarn`（输入非空且解析值 > 20）。

### B. 司忆点等级表（siyiLevelRow 断点分治）

- **宽屏（PC/Pad，windowMode.isTablet）**：保持 0.251.1 三栏一行不变（宽屏不乱）。
- **手机**：改两行结构——
  - 上行：`Lv8 司忆令`（主文字，占满剩余宽）+ 权益（右对齐紫色小字，如「充能 98 折 · 每日嘉奖 +10%」）；
  - 下行：`含义 · 条件` 合并灰色小字（如「最高神格！令，代表号令、法则制定者 · 累计 365 天（一年封神）」），**不设 maxLines、不截断**，自然换行。
- 用户偏好 4 合规：断点走 WindowMode 共享真相源（PC 窗口缩窄仍按宽屏布局）。

### C. 顺手小优化：获取途径行（siyiGainRow）

- 值文本加 `layoutWeight(1) + textAlign(End)`：长值（新用户礼包「首月 +2,000,000 SP / 此后 +1,000,000 SP（永久有效）」）在剩余空间内右对齐自然换行，左侧名称永不被挤压；删除冗余 Blank()。

## 三、风险点

- @Computed 源状态全部 @Local（雷区已核：reviewWordInput/reviewCardInput 本就 @Local）。
- siyiLevelRow 带参 @Builder 内引用 this.windowMode——参数仍是纯静态文案（无状态参数），this 状态引用响应正常（弹窗宽度同源状态本就在主 build 链使用）。
- 保存链路零改动：saveAll 仍读 editReviewLearn/Knowledge；非法输入不写副本=安全忽略。
- Tab 切换预填逻辑（3281-3282）保留；error 复位两行删除。

## 四、验收标准

1. 司忆区两项：无「确定」按钮、无红色报错文案；点 0/1/2 即选；输入 0~20 合法值输入框亮紫描边且 0/1/2 全暗；输入 21+ 红描边弱警示、点「保存」不落非法值；点「保存」后 toast 正常。
2. 司忆点页手机端：等级行两行排版、含义完整不截断；PC/Pad 仍三栏一行。
3. 宽屏拖窄窗口仍按宽屏布局（偏好 4）。
4. 本地 hvigorw 编译一次通过。
