# 0.303.0 首启合并登录引导（协议 + 华为账号登录一屏）

> 2026-10-23 用户口述方案 + 四问拍板（全部取推荐项）。本版只改首启交互，不改协议正文、不改持久化 key、不动云同步/备份红线。

## 一、背景与目标

现状首启为 4 段式：阅读并同意（2 协议）→ 选择外观 → 加入体验改进 → 进入主界面后再引导登录华为账号。
问题：登录被推到最后，用户先进入半成品状态；SP 需云服务才可用（project_rule SP 铁律），新手任务/签到/礼包在未登录时只能挂账。

目标：把「协议同意」和「华为账号登录」合并到首启一屏，登录后即开云同步，再选外观，最后进主界面。

## 二、定稿流程（用户拍板）

1. 首启一屏：
   - 品牌区（DAG AI Chat / 你的AI学习伴侣）
   - 三项协议同一勾选行，均可点开：《用户协议》《隐私政策》《华为账号用户认证协议》
   - 主按钮「华为账号登录」（未勾选不可登录，点按抖动提示）
   - 次级入口「暂不登录，先本地使用」（小字，保住本地三板块）
   - 底部「不同意，退出」（直接退出，不二次挽留）
2. 勾选 + 登录成功 → 记录 agreed/hwAgreed → 开启云同步（入口即意图）→ 选择外观。
3. 勾选 + 暂不登录 → 记录 agreed/hwAgreed → 选择外观（不登录、不开云同步）。
4. 外观页内置「加入体验改进计划」开关，默认关；选完即进主界面。
5. 不同意 → terminateSelf 直接退出（去掉二次挽留）。

## 三、合规依据（官方文档已核对）

- 「不打勾不能登录」：官方 LoginWithHuaweiIDButton 提供 setAgreementStatus(NOT_ACCEPTED/ACCEPTED)；本项目沿用自定义按钮登录（官方允许，需符合按钮规范），用按钮禁用 + 点击拦截实现同等效果。
- 《华为账号用户认证协议》必须展示官方链接、不得以自有协议替代（FAQ faqs-account-17）；本项目沿用 Agreement.ets 的官方 URL。
- 勾选前不得发起登录/收集个人信息/权限请求（FAQ faqs-appgallery-2）——本版登录只在勾选后触发。
- 「不同意退出」为官方允许方式二；建议同时配置 module.json5 removeMissionAfterTerminate=true（本版已按用户拍板补上）。
- 官方 FAQ 明确「不允许通过多次弹窗强制用户操作」——本版删除二次挽留。
- 不强制登录：保留「暂不登录，先本地使用」，与《用户协议》第 2 条「不登录可使用本地功能」一致，规避审核「基本功能强制登录」风险。
- 体验改进计划保持「单独、非捆绑、默认关」，只作为外观页可选开关，不与必选协议混排。

- 新增 `entry/src/main/ets/components/OnboardingGate.ets`：首启合并门禁全屏组件（协议勾选/正文查看/登录/本地使用/退出）。

- `entry/src/main/ets/components/ThemeChooseDialog.ets`：新增「加入体验改进计划」默认关开关；onChoose 增加 improve 参数。
- `entry/src/main/ets/components/ImproveDataDialog.ets`：删除（首启不再单独一屏）。
- `entry/src/main/module.json5`：EntryAbility 增加 removeMissionAfterTerminate=true（红线文件，用户拍板同意）。
- 版本：0.303.0 / versionCode 1000448（两处写入 + Index 自动跟）。

## 五、风险与边界

- 协议正文与 AGREEMENT_VERSION 不变（仍为 3），存量已同意用户不重弹、不重新征求。
- 登录失败/取消：停留首启页，显示中文提示，可重试或走「先本地使用」。
- 云同步开启依赖系统云空间授权；拒绝授权则保持关闭，SP 门卫按既有逻辑引导，不静默扣点。
- 老入口（边栏/设置云同步/AI 登录引导）仍走原两段式弹窗，行为不变。
- 主题不同步（cfg 行不含 theme），登录后选主题不会与云端打架。

## 六、验收标准

1. 全新安装（清数据/卸载重装）首启只出现一屏合并门禁。
2. 不勾选点登录：抖动 + 中文提示，不拉起华为授权页。
3. 勾选 + 登录成功：进入外观页，云同步开关为开；选完进主界面。
4. 勾选 + 暂不登录：进入外观页，可正常使用词库/知识库/复习；AI 对话按既有登录门卫引导。
5. 不同意：应用直接退出，无二次挽留。
6. 外观页体验改进开关默认关；开启后埋点生效，设置页可关。
7. `devecocli build` 成功。

## 七、0.303.1 追加：debug 包「重置为新用户资产」测试入口

### 背景
老账号云端 `cfg:siyi-points` 行含 `welcomeGranted=true` + 历史 SP/新手任务/签到，卸载重装后首拉会把这些标记带回来，无法模拟真新用户。用户拍板：加一个 debug 专用重置入口，只重置资产行，保留聊天记录/词库/知识库。

### 实现
- `ChatModel.debugResetNewUserAssets()`：置零 SP 三池/消耗累计/welcomeGranted/signedDates/milestone/iapPackages/rookie 两集合，清 `cfg:stat-days`、本地签到与等级桥、礼包影子；`upsertIfChanged` 覆盖 `cfg:siyi-points` + `cfg:stat-days` 后 `flushCloudRowsNow()` 上行。
- 会话内 `debugResetLatched`：跳过 `mergeSiyiPointsRow` 下行合并，防旧云端值把重置冲掉；进程重启自然失效。
- `WelcomeGiftShadow.clearWelcomeGiftIssued()`：清当前账号「已发」影子。
- `GlobalSettingsDialog` 关于页：`BuildProfile.DEBUG` 时显示「调试工具（仅测试包）→ 重置为新用户资产（保留对话/词库/知识库）」，系统 AlertDialog 二次确认，toast 提示彻底退出重开。
- 版本 0.303.1 / versionCode 1000449。

### 使用与边界
1. 登录并开启云同步、首拉完成后，设置→关于→调试工具→重置→确认。
2. 彻底退出重开：首拉后自动发新用户礼包（200 万，2026-11-30 前）、新手任务/签到/统计归零。
3. 想连首启门禁一起测：重置成功后卸载重装，首启门禁→登录→礼包全流程复现。
4. 只动 `cfg:siyi-points` + `cfg:stat-days`；`node/tab/word/card/文件夹/cfg:api-config/ai-pref/face-mode` 全部保留。
5. 正式包 `BuildProfile.DEBUG=false`，入口不渲染。
