# 0.200.0 知识卡片导入气泡对话（含 L3 特效）

> 业务闭环关键一环：知识卡片（未来卡片商城/UGC 分享的核心资产）→ 温故知新产生问题 → 问 AI。
> 现状只能复制粘贴/截图，体验断裂。本功能打通「卡片 → 气泡树对话」最后一段路。
> 用户定位：这是本产品与 Obsidian/Anki 等全世界学习工具的核心差异点——**卡片是产品的灵魂**，值得 L3 特效。

---

## 一、需求定稿（用户已拍板）

| 决策点 | 定稿 |
|---|---|
| 入口 | **A+B+C 三入口全做**（用户拍板：浏览即产生问题��真实学习动线，「要问 AI 还得点进去」体验不可接受） |
| 发送时机 | **等用户补充**（卡片填入输入框，用户补一句问题再发送；自动发送=答非所问浪费 token） |
| 选气泡确认 | **单击气泡 → 高亮锁定 + 底部确认条**「导入到『XXX』✓ / 取消」（防误触：选错父节点建错气泡成本高） |
| 动画 | **L3 完整版**：遮罩变暗+气泡脉冲+横幅滑入+卡片飞行+气泡弹跳发光+对话页输入区渐显 |

## 二、交互设计

### 2.1 三入口

| 入口 | 形态 | 动作 |
|---|---|---|
| **A 知识库列表** | 每卡右侧「问 AI」icon（与 × 并排、主紫；多选模式下随 × 隐藏） | 点击 → 底部弹出二选一面板：导入气泡对话 / 创建子气泡 |
| **B 编辑弹窗** | 弹窗底部两按钮（与圈注页三按钮同构） | 直接发起对应动作 |
| **C 复习页** | 知识卡右上角「问 AI」icon（保持一页一卡美学） | 同 A 二选一面板 |

### 2.2 画布选择模式

- **CardImportStore**（AppStorageV2 共享 store，annotationResult 同模式）：`{ action: '' | 'import' | 'branch', title, definition, imageUri }`，action 非空 = 导入进行中
- 流程：入口点击 → 写 store → `sideBarNav('canvas')` 回画布（0.195.0 四态导航复用）→ 画布检测 action 进入选择模式
- 选择模式 UI：画布半透明遮罩变暗 + 气泡脉冲微浮动 + 顶部横幅「点选要导入的气泡」+ 取消按钮
- 画布拖拽/缩放**保留**（气泡多时可平移缩放找目标，单击才触发确认）
- 单击气泡 → 高亮锁定 + 底部确认条「导入到『气泡标题』✓ / 取消」→ 确认后播放动画并导航
- **手势接管**：选择模式下单击=选中目标（不进 0.173.2 双击判定，禁用双击进对话）

### 2.3 L3 动画时序

| 阶段 | 动画 |
|---|---|
| 进入选择模式 | 遮罩淡入 + 横幅顶部滑入 + 气泡 pulse（scale 1→1.03 循环 ~1.6s，低频防性能问题） |
| 单击气泡 | 目标气泡锁定高亮 + 确认条底部弹出 |
| 确认瞬间 | 卡片缩略图从横幅位置**飞行**至目标气泡（getRectangleById 取全局坐标；失败跳过飞行直接弹跳，不阻断功能） |
| 飞行到达 | 目标气泡 scale 弹跳（1→1.15→1 spring 弹性）+ BRAND_SECONDARY 发光描边 |
| +200ms | pushPath 进入 ChatPage |
| ChatPage 落地 | 输入区内容渐显（opacity 0→1 + translateY 8→0，300ms） |

### 2.4 导入落地（复用圈注页 0.184.0 全套机制）

- **import（导入对话）**：进 ChatPage（目标气泡）→ `inputText = 格式化文本` + `pendingImages = [imageUri]`（有图时）
- **branch（创建子气泡）**：进 ChatPage（目标气泡）→ `addBubble([imageUri], 格式化文本)`（carryText/carryImages 随 140ms 切换回调带入，防清空——0.166.1/0.184.0 成熟机制）
- 文字格式：`📚 知识卡片｜{title}\n{definition}\n\n（我想问：）`
- **不自动发送**，聚焦输入框等用户补充
- 纯文本模型发图：0.190.2 拦截已有，零改动
- AI 流式回复中发起 branch：沿用圈注降级（导入当前对话 + toast）

## 四、风险点

1. **手势冲突**：选择模式下接管单击、禁用双击判定——0.173.2 手动判定逻辑加分支
2. **坐标获取失败**：getRectangleById 拿不到 → 跳过飞行段直接弹跳+导航（功能优先）
3. **多气泡 pulse 性能**：限制可见气泡或低频周期，真机验收 60fps
4. **气泡标题缺失**：确认条显示自定义标题（无标题回退「未命名气泡」）
5. **动画中断**：确认后飞行途中用户返回/操作——动画回调里检查状态，防重复导航
6. **DevEco 旧缓冲区**（0.196.0 教训）：改代码期间用户勿保存旧文件
