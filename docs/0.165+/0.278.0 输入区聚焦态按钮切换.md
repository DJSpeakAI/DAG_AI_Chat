# 0.278.0 输入区聚焦态按钮切换（2026-10-20）

## 需求（用户三张截图口述，"你先做，慢慢调整"）

1. **未聚焦态（图1）**：删除「发送」按钮——保留 新建气泡树（gitbranch）+ 输入框 + 屏幕圈注（铅笔）
2. **聚焦态（图2）**：删除 新建气泡树、右侧铅笔、下方聚焦工具栏的圈注——保留「发送▾」
3. **发送▾ 菜单内容（图3）**：三个部分——对话模式切换（正常对话/播客模式）、回复长度（短/中（默认）/长）、添加图片（icon + 文字）。现有菜单三组结构已满足，本轮将 💬/🎙 彩色 emoji 换成华为风格单色细线 svg（图标军规 + 图3 样式对齐）。

## 设计

- 复用 0.270.0 已有 `isInputFocused` 状态（onFocus/onBlur + 150ms 宽限定时器），**零新增状态**。
- 输入行三件套按 `isInputFocused` 条件渲染 + TransitionEffect.OPACITY（200ms）过渡：
  - `!focused` → gitbranch + TextArea + 铅笔
  - `focused` → TextArea + 发送▾
- 聚焦工具栏（0.270.0 一期仅圈注一个入口）唯一入口被删，整块移除；未来膨胀预留位随 git 历史可找回。
- blur 150ms 宽限天然兼容 PC 发送后 50ms 重聚焦（发送按钮不闪）。
- 菜单选中态品牌紫高亮/描述小字/选项逻辑（sendMode、replyLengthMode、selectImages）零改动。

## 改动文件

- `entry/src/main/ets/components/ChatPage.ets`：输入行条件渲染 + 删聚焦工具栏块 + 菜单两行 emoji→svg

## 风险与不动项

- 回车发送 / Shift+回车换行 / 草稿 saveDraft / PC 重聚焦 requestFocus('chatInputField') 四铁律链零改动

- 纯 UI 交互不接测试台（0.241.0/0.253.0/0.270.0 先例，用户自测）

## 验收

- 未聚焦：只见 新建气泡树 + 输入框 + 铅笔，无发送按钮
- 点击输入框：按钮组切换为 发送▾（新建气泡树/铅笔/下方工具栏全消失），输入框展开两行高
- 发送▾ 菜单：对话模式（正常对话/播客模式，单色图标）→ 回复长度（短/中/长，默认中）→ 添加图片（icon+文字）
- PC 发送后重聚焦不闪、回车发送/换行照旧；三端布局不破
