# 0.187.0 记忆算法与复习系统

> 版本：v0.187.0（versionCode 1000051）｜日期：2026-10-04｜状态：已实现，待真机验收
> 本文档是记忆算法的**完整设计记录**：公式、参数、防抖推导、ArkTS 核心代码、未来开放设置的构思。
> 算法目前**纯后台隐藏**，不开放用户设置——等理解透彻后再决定开放哪些旋钮（见 §7）。

## 1. 背景与目标

- 原复习区（AI 气泡底部 + 提炼弹窗）**纯随机**选词——词量一大后随机不靠谱（用户拍板要改）
- 传统背单词软件（Anki）**必须点击评分**才算复习；本应用是气泡对话场景，用户**不保证 100% 点击**
- 因此核心差异：**展示即复习**（每次抽进复习区 = 复习 1 次），点击评分是可选的增强反馈
- 评分从传统 4 档简化为 **3 档**：生疏 / 尚可 / 熟知

## 2. 核心公式与方案B

**遗忘曲线**：`R = e^(-t/S)`

| 符号 | 含义 | 单位 |
|------|------|------|
| R | 记忆保留率（0~1，越低遗忘越多） | — |
| t | 距上次复习的时间 | 天（浮点） |
| S | 记忆强度（每次评分更新） | 天（浮点） |

**方案B（用户拍板）**：下次复习时间 = 现在 + S。

- 复习时保留率 ≈ e^(-1) ≈ **37%**，属"偏难复习"策略
- 这是**简化工程模型**：不锁定目标保留率（Anki/FSRS 默认目标 0.9），信 3 档评分**自纠错**——觉得难就点「生疏」，间隔自动缩短
- 备选方案A（未采用）：下次复习 = 现在 + 0.6×S，复习时 R≈55%，体感更轻松但复习次数多 ~40%
- R 公式在本方案中的实际用途：**选词排序**（遗忘风险最高的优先展示）

## 3. 数据字段（WordItem 新增 4 字段，用户不可见）

```typescript
@Trace strength: number = 0;     // 记忆强度 S（天）；0 = 从未评分（新词标记）
@Trace reviewCount: number = 0;  // 展示复习次数（展示即复习，被动计数）
@Trace lastReviewAt: number = 0; // 上次展示复习时间戳（ms）
@Trace nextReviewAt: number = 0; // 计划下次复习时间戳（ms）；0 = 新词，视为已到期
```

- 存量数据兼容：`normalizeMemoryFields()` 在 connectWordBank 时兜底（undefined/NaN → 0），防 PersistenceV2 旧数据缺字段
- **单位约定**：内部全部用「天」（浮点）——10 分钟 = 10/(24×60) ≈ 0.00694 天；6 小时 = 0.25 天；12 小时 = 0.5 天。展示层再转中文（豆包审查采纳，防单位混用 BUG）

## 4. 评分规则（3 档 + 不点评）

| 评分 | 首评（S=0 → 绝对间隔） | 复评（乘系数） | 下次复习 | 语义 |
|------|----------------------|---------------|---------|------|
| 🔴 生疏（几乎想不起来） | 10 分钟 | S × 0.5（下限 10 分钟） | 现在 + S新值 | 打回重学 |
| 🟡 尚可（回忆有点费劲） | 12 小时 | S × 1.6 | 现在 + S新值 | 温和巩固 |
| 🟢 熟知（一眼就能反应） | 2 天 | S × 2.4 | 现在 + S新值 | 大步拉长 |
| ⚪ 不点评（展示即复习） | 6 小时 | **S 不变** | **固定 现在 + 6 小时** | 只顺延不涨强度 |

- S 钳制范围：[10 分钟, 365 天]（下限防趋近 0，上限防长期词高频打扰）
- 不点评顺延**固定 6 小时**、不套 S——防止看一眼强词（S=100天）直接顺延一年（豆包审查采纳）
- 未点评的到期词会以 6 小时周期反复出现，直到用户评分——**刻意设计**：评分是唯一提升强度的途径

## 5. 选词逻辑（替换纯随机）

`pickReviewWords(store, count, now)` 三级队列：

1. **到期老词**（reviewCount>0 且 nextReviewAt ≤ now）：按 R 升序——**遗忘风险最高优先**
2. **新词**（reviewCount=0）：按加入时间升序——公平轮转
3. **未来词**（nextReviewAt > now）：按 nextReviewAt 升序——最快到期优先

到期队列会随每次展示自然排空（每个被展示的词至少顺延 6h），积压自动消化。

## 6. 展示即复习 + 到期闸门防抖

**规则**：词被抽进复习区（新 AI 气泡 / 提炼弹窗打开）且 `now ≥ nextReviewAt`（真到期）→ `reviewCount++` + 顺延 6h。未到期被重复抽到 → 不计数不顺延。

**为什么不用固定 24h 防抖（豆包原方案）**——反例推导：

```
t0        被动展示 → 计数，顺延至 t0+6h
t0+6h     到期 → 再展示 → 距上次计数仅 6h < 24h → 不计数也不顺延
t0+6h ~ t0+24h  一直卡在「到期」状态 → R 最低 → 每条消息都优先抽它
          → 单个词霸占复习位长达 18 小时，轮转卡死
```

到期闸门（now ≥ nextReviewAt 才计数）零卡死：到期→展示→顺延→再到期→再展示，天然限频 6h/次。

**配套修复**：复习区缓存原按「词库长度」失效——加 1 个词 = 历史全部消息重抽 = 一次性虚假复习几十次。已改为**按消息 ID 永久固定**（历史消息展示"当时"的词），已删除的词读取时滤除。

## 7. 参数总表（未来开放设置的候选旋钮）

| 参数 | 当前值 | 常量名 | 开放建议 |
|------|--------|--------|---------|
| S 下限 | 10 分钟 | S_MIN_DAYS | 固定不开放 |
| S 上限 | 365 天 | S_MAX_DAYS | 可开放（长期词打扰频率） |
| 不点评顺延 | 6 小时 | PASSIVE_INTERVAL_DAYS | 可开放（被动复习节奏） |
| 生疏首评/系数 | 10 分钟 / ×0.5 | FIRST_HARD / MULT_HARD | 系数可开放 |
| 尚可首评/系数 | 12 小时 / ×1.6 | FIRST_GOOD / MULT_GOOD | 系数可开放 |
| 熟知首评/系数 | 2 天 / ×2.4 | FIRST_EASY / MULT_EASY | 系数可开放 |
| 复习时机 k | 1.0（方案B） | —（未实现） | 开放即"复习难度"：0.6=轻松 / 1.0=标准 |

开放形式构思：设置弹窗加「复习强度」档位（轻松/标准/紧凑），映射到 k 系数与三档系数预设，高级参数收进"自定义"。

## 8. UI 变更

**复习区（气泡底部 + 提炼弹窗，两处同款）**：
- `📚` 前缀 → `👆`（手指图标勾引点击）
- 点词条 → 展开 3 档评分按钮（生疏红 #E5484D / 尚可黄 #F5A623 / 熟知绿 #3BB273，各带一句小描述）
- 评分后 → 按钮收起，显示「下次复习：10 分钟后 / 明天 / 3 天后」（按评分着色）
- 不点 → 无感，算法自动按"展示即复习"处理

**单词本页**：
- 每词条新增「下次复习」行：未学习（灰）/ 已到期（红 DANGER）/ N 分钟后·N 小时后·N 天后·日期（灰）
- 排序按钮 3 态循环：最新↓ → 最早↑ → **需复习↑**（nextReviewAt 升序，已到期/未学习排最前）

## 9. 验收标准（真机）

1. 复习区词条前缀为 👆；点词展开 3 个评分按钮（生疏/尚可/熟知 + 小描述）
2. 点「生疏」→ 按钮收起，显示「下次复习：10 分钟后」（红）
3. 单词本列表出现「下次复习」行；点排序按钮循环 最新↓→最早↑→需复习↑
4. 需复习排序下：刚评「生疏」的词排最前（10 分钟后到期最早）
5. 不点评分直接发新消息 → 复习区换一批词（到期队列轮转），原词在单词本显示「6 小时后」顺延
6. 重启应用 → 单词本「下次复习」时间保持（持久化生效）
