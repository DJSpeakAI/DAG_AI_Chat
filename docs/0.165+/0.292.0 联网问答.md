# 0.292.0 联网问答（AI 自主搜索 + 工具调用循环）

> 2026-10-22 用户拍板方案 C（混合）直接开工。versionCode 1000428（多 AI 并行顺延：基线 0.291.4/1000427 被并行线占用）。

## 一、需求

用户不贴链接、纯自然语言提问（如「帮我看华为开发者论坛有没有 XXX 资质要求」），AI 能自主联网查证后精确回答。现状 0.286 只支持"消息里带链接→客户端预抓正文注入"，AI 无法自己找资料。

## 二、方案 C 架构（Function Calling 工具循环）

模型本身不能上网；DeepSeek API 原生支持 `tools` 参数（OpenAI 兼容格式），AI 需要外部信息时返回 `tool_calls` 而非文字，**客户端执行工具后把结果回填再问一轮**，循环直到 AI 给出最终回答。业界标准 agentic loop。

```
用户开启「联网」胶囊发消息（自然语言）
→ ① streamChat 带 tools=[search_web, open_url]（强制关思考，FC 兼容保守）
→ ② AI 返回 tool_calls（流式分片按 index 拼接）+ finish_reason=tool_calls
→ ③ 客户端执行：search_web=抓 Bing 解析前5条 / open_url=WebFetchUtil 两级瀑布（复用 0.286.2 隐形 Web 组件渲染通道）
→ ④ buildToolRoundMessages 追加 assistant(tool_calls)+tool 结果 → 回到①再问
→ 上限 3 轮；第 3 轮后不再声明 tools（AI 只能落笔回答）
→ finish_reason=stop → 正常 onDone
```

SP 计费军令：**工具轮与正文轮 token 累加一次性落账实扣**（webIn/Out/Cached 三暂存，复刻 0.290.0 planInTok 模式）；错误时已耗 token 照落账（同 plan 语义）。

## 四、工具定义（发模型的 JSON Schema）

- `search_web(query)`：联网搜索。描述词：需要最新/官方/论坛信息且不确定时调用；query 2~8 词。
- `open_url(url)`：读取网页正文。从 search_web 结果选最相关链接深读。

search_web 实现：GET `https://www.bing.com/search?q=...`（UA 伪装同 0.286），正则解析 `b_algo` 条目（标题/直链/摘要）。零新增 API Key（用户零配置）；后续可升级博查/腾讯混元搜索 API（独立迭代）。

## 五、风险与边界

1. **腾讯云通道 tools 透传未验证**——真机首验点；400+`tool` 关键词自动降级纯聊天（提示"当前通道不支持联网"）。
2. Bing 反爬/结构变化——搜索失败时 tool 结果写明失败原因，AI 按已有资料回答（不瞎编）。
3. **重生成不带 tools**（第一版边界，后续迭代）。
4. tool 消息仅存在于发送侧请求副本（内存态），**气泡树/Schema/持久化零改动**（复刻 0.235.0 划词引用注入语义）。
5. token 上限三闸不变：单页 6000 字、单轮 5 条搜索、3 轮工具。
6. FC+思考兼容未验——联网模式强制 thinking disabled（保守）。

## 六、验收标准

1. 开联网胶囊问「华为开发者论坛里 XXX 有什么要求」→ AI 自动 search_web →（可选 open_url 深读）→ 回答含真实出处链接。
2. 关联网胶囊行为与现状完全一致（回归零影响）。
3. 消息带链接的 0.286 预抓链路不回归。
4. SP 实扣=各轮 token 之和，消息明细可见合并值。
5. 工具执行期间状态行显示「正在联网搜索/正在打开网页」。
