## 二、章节折叠设计（本期核心新增）

### 2.1 触发与生命周期（★A 方案定稿：流式直显→完成收拢）

1. **流式期间：照常打字机直显，不折叠**（content 每 chunk 更新全量重解析，现有机制不动；保留流式爽感）
2. **onDone（回复完成）瞬间**：解析章节结构 → **一次性收拢**（前 1/3 章节展开、其余收起）→ 播放收拢过渡动画（springMotion 弹簧曲线，~250ms）——「文章写完自动叠好呈上来」的惊喜时刻
3. regenerate / 重新生成：重新走一遍（直显→收拢）
4. 折叠状态**内存级**（组件成员 `Map<msgId, Set<展开节序号>>`）：切页面回来保留；重启 app 恢复默认 1/3；**不落盘、不改 content 原文**

### 2.2 章节划分规则

- **章节单位 = `##` 二级标题**（AI 长回复惯例）；`#` 一级标题视为整篇总标题不单独成章；`###` 及以下、列表、代码块、表格全部归属最近的上一个 `##` 章节（**块级归属，天然不会截断代码块/表格**）
- 开头到第一个 `##` 之间的引言 = 第 0 节「开篇」，默认恒展开（不占章节序号）
- **无 `##` 标题兜底**：按块累计正文 ~500 字切一段，折叠行显示「第 X 段 · 约 Y 字」
- 代码块内部的 `##`（代码内容）不算章节——MdInline 已把代码块解析为独立块类型，章节分组只作用于 heading 块，天然安全
- **折叠启用门槛：≥3 节才折叠**（1~2 节折叠无意义，直接全显）；仅长回复模式适用

### 2.3 折叠行 UI 与交互

- 收起态整行卡片：左侧 `▸/▾` 折叠小三角（**对齐项目知识库文件夹树规格：字号 16/宽度 22，0.222.14 定式**）+ 中间章节标题（14fp）+ 右侧「约 X 字」小字（11fp、TEXT_SECONDARY）
- 章节标题前带序号「第 X 节」（共 N 节）——**位置感即进度**（用户定稿：这就是「中文 progress 简化版」的落地形态，不再做独立进度 UI）
- **整行可点** toggle 展开/收起；展开后**不自动收起**（读完整章，下一章折叠行就在眼前）
- 默认展开集 = 前 `ceil(总节数/3)` 节（至少 1 节）+ 开篇引言
- 三端（PC/Pad/手机）交互一致；折叠仅影响显示：content 原文完整 → 复制/导出/摘要/云同步零影响

### 2.4 TTS（用户定稿：全文照发）

- 不管折叠状态，TTS 朗读送 **content 全文**（mdToSpeakableText 现有链路+锚点清洗，见 §5.4）；不做「逐章自动展开」联动（二期）

## 三、锚点协议与类型（微观节奏）

### 3.1 标记协议

AI 在回复正文中输出，**独占一行，前后各空一行**：

```
[[anchor:类型|锚点文案]]
```

- 类型白名单：`quiz` / `hook` / `link`（AI 可用）；`breath` 保留本地；AI 输出其他类型一律后处理剔除或转本地 breath
- 解析宽容（三家云端模型+流式现实）：大小写不敏感；**不完整标记（流式截断如 `[[anchor:qu`）按普通文本**；非法类型/缺竖线/空文案整行降级普通文本；非独占行标记不解析

### 3.2 类型表（4 类，进度型已砍）

| 类型 | 生成方 | 文案要求 | 科学原理 |
|---|---|---|---|
| `quiz` 考考你 | AI | 1 句问句，只问刚讲过的内容，**不给答案** | 检索练习（主动回想记忆效果数倍于重读） |
| `hook` 悬念预告 | AI | 1 句，吊胃口不剧透，指向下文重点 | 蔡格尼克效应 |
| `link` 生活联想 | AI | 1 句，把刚讲概念类比到生活 | 精细加工 |
| `breath` 喘息 | **本地** | 文案池确定性轮换（如「歇口气，消化一下刚看的」） | 注意恢复理论（微休息） |

### 3.3 密度（因章节折叠承担宏观节奏而下调）

| 场景 | 规则 |
|---|---|
| 长回复 | AI 每**章**最多 1 个锚点、全文 2~4 个；相邻类型不得重复 |
| 中回复 | >300 字时正中附近 1 个；≤300 字不插 |
| 短回复 | 不注入 |
| 本地保底 | 渲染层累计 ~550 字（密度档可调）无 AI 锚点时块边界补 1 个 breath；相邻锚点最小间距 200 字 |

密度三档：密 400 / 中 550（默认） / 疏 700 字（只调本地保底阈值；AI 侧密度随档位联动=二期）。

### 3.4 禁插区（毁灭性体验红线）

代码块、表格、公式块、列表项内部绝对禁止。双防线：prompt 明令禁止（AI 侧）+ 后处理校验（解析出的锚点若在代码块/表格块内→剔除标记保留文案）。

## 四、Prompt 全文（★用户重点审阅；落 `common/Prompts.ts` 单一真相源，禁止散落）

### 4.1 SECTION_PROMPT（分节指令，★新增）

```
本次回答必须用 ## 二级标题清晰分节（如「## 一、核心概念」），每个小节聚焦一个主题；禁止用 ### 以下层级做整篇主分节。
```

注入条件：长回复模式 且（锚点开 或 折叠开）任一为真（**折叠的地基=## 标题，两个开关谁开都需要**）。

### 4.2 ANCHOR_LONG_PROMPT（长回复、锚点开时追加）

```
本次回答中需要插入「注意力锚点」标记，严格遵守：
1. 格式：[[anchor:类型|文案]]，必须独占一行，前后各空一行；
2. 类型三选一：quiz=考考你（只问刚讲过的内容，1 句问句，禁止给出答案）、hook=悬念预告（1 句，吊胃口但不剧透，指向即将讲的重点）、link=生活联想（1 句，把刚讲的概念类比到日常生活场景）；
3. 密度：每个 ## 小节最多 1 个锚点，全文总数 2~4 个；相邻两个锚点类型不得重复；
4. 位置：只插在自然段落之间，禁止插在代码块、表格、公式、列表内部；
5. 文案必须与上下文强相关，禁止通用套话，禁止重复之前用过的表述；全文最多 1 次自然使用用户的称呼；
6. 禁止解释标记本身，禁止输出任何关于锚点的额外说明。
再次强调：[[anchor:类型|文案]] 独占一行、代码块表格内禁止、总数 2~4 个。
```

### 4.3 ANCHOR_MEDIUM_PROMPT（中回复、锚点开时追加）

```
若本次回答超过 300 字，在全文正中附近插入 1 个锚点标记：[[anchor:类型|文案]]（独占一行，类型从 quiz/hook/link 三选一，文案 1 句且与上下文强相关）；禁止插在代码块、表格、公式内部；禁止解释标记；不足 300 字则不插。
```

### 4.4 军规自检（docs/CONTEXT_MANAGEMENT.md 十条军规）

数字锚定 ✓（「1 句」「2~4 个」）/ 负向配对 ✓（每条"要 X"配"禁止 Y"）/ 穷举 ✓（类型逐个列定义）/ 失败模式接种 ✓（禁止解释标记/重复表述/通用套话）/ 首尾强化 ✓（格式规则首尾各一次）/ 逃生舱 ✓（开关 off 不注入）。

### 4.5 删除项（鼓励撤离回复开头）

- `ENCOURAGE_LIGHT_PROMPT` / `ENCOURAGE_HEAVY_PROMPT` 常量整体删除；`buildStatEncouragePrompt`（统计页/复习页用）**原样保留不动**

## 五、渲染与算法（utils/MdInline.ets + components/ChatPage.ets）

### 5.1 MdInline.ets 新增纯函数（全部可 ohosTest，遵循现有纯函数模块模式）

1. `MdBlock` 增加 anchor 块类型（kind='anchor' + anchorType/anchorText 尾部可选字段）
2. `parseBlockMd` 识别独占行锚点标记 → 锚点块；半标记/非法 → 普通文本
3. `stripAnchorMarks(content, keepText)`：keepText=true 去 `[[anchor:type|` 与 `]]` 留文案（TTS 用）；false 整行删（复制/摘要上下文用）
4. `insertLocalAnchors(blocks, density)`：本地 breath 保底插入（块边界、文案池按序号确定性轮换——同输入同输出）
5. **`splitSections(blocks): Section[]`（本期核心新增）**：按 ## heading 块切章节（### 以下归属上一 ##；开头引言=第 0 节；无 ## 时按累计 ~500 字切段）；返回 `Section { title, blocks, charCount, index }[]`
6. **`initExpandedSet(sections): Set<number> | null`**：≥3 节返回前 ceil(N/3) 节+第 0 节；<3 节返回 null（不折叠）

### 5.2 ChatPage.ets 消息渲染改造

- AI 消息渲染：`insertLocalAnchors(parseRichBlocks(content), density)` → ForEach（锚点开关关则跳过 insert）
- **折叠状态机**：组件成员 `foldState: Map<msgId, Set<number>>`（内存级，@Trace 驱动重渲）；流式期间（消息 streaming 中）全显不折叠；**onDone 时对该消息调 `initExpandedSet` 初始化并触发收拢动画**；用户点击章节行 toggle 更新 Set
- 渲染分节：`splitSections` 结果按 Section 渲染——展开节直接渲染 blocks（锚点块在所属节内正常渲染）；收起节只渲染折叠行
- ForEach key 纳入节 index 与展开态（防 Key 碰撞，0.231.0 教训）

### 5.3 锚点卡片样式

- 独立小卡片：上下 4~6vp 间距、圆角胶囊卡、左侧类型徽标（紫底文字胶囊：「考考你」「前方高能」「联想一下」「歇口气」四档映射）+ 右侧文案（14fp、TEXT_SECONDARY）
- 品牌紫系（暗紫底 12% 透明+紫描边），暗色模式对比度必查；**禁止 emoji**（项目图标规范=华为细线克制风格）；宽度随气泡自适应、单行截断省略

### 5.4 TTS / 复制 / 摘要接线

| 链路 | 处理 |
|---|---|
| TTS（mdToSpeakableText） | `stripAnchorMarks(content, true)` 读全文（折叠不参与，§2.4） |
| 消息复制（若现有复制功能） | `stripAnchorMarks(content, false)` |
| 备份/云同步 | 不处理（content 原文即真相；折叠/锚点均为渲染层行为） |
| 链路摘要上下文（buildBranchMessageList 送 LLM） | `stripAnchorMarks(msg, false)`——防标记污染摘要与后续上下文 |

### 5.5 动画三件（克制版；代码留 `animOn` 常量一键关，出 bug 可秒回退）

1. **onDone 收拢**：整篇从直显收拢为章节形态，`curves.springMotion` ~250ms（华为物理弹簧曲线，项目动效血统）
2. **章节展开/收起**：`animateTo` ~220ms（对齐边栏滑入滑出手感）
3. **锚点卡片浮现**：淡入+上移 8vp+~200ms；**每卡只播一次**（利用 ForEach key 稳定性：transition 出现动画只在节点新增时触发，key 稳定即不重播——流式全量重解析下务必真机验证此点）

## 八、验收标准

### 8.1 ohosTest（MdInline 纯函数，List.test.ets 或同目录既有测试文件追加）

1. 合法锚点标记 → 锚点块（type/text 正确）；半标记/非独占行/非法类型/缺竖线/空文案 → 普通文本
2. 代码块内锚点行 → 剔除标记留文案；代码块内 `##` 不成章节
3. `stripAnchorMarks` keepText 两种模式输出正确
4. `insertLocalAnchors`：超阈值补插 breath、区间有 AI 锚点不补、文案确定性（同输入同输出）
5. **`splitSections`**：有 ## 正确切分（### 归上节、引言第 0 节）；无 ## 按 ~500 字切段；空输入/单节边界
6. **`initExpandedSet`**：≥3 节返回前 ceil(N/3)+第 0 节；<3 节返回 null

### 8.2 手工验收（用户/执行 AI 窗口缩窄自测）

1. 长回复提问 → **流式直显 → 完成瞬间收拢动画** → 前 1/3 章节展开、其余收起（折叠行含「第 X 节/共 N 节 · 约 X 字」）
2. 点折叠行展开章节、再点收起；展开后不自动收
3. 章内锚点卡片 2~4 张、紫色系、无 `[[anchor` 泄漏、代码块内无锚点；卡片浮现动画每卡只播一次
4. 中回复 >300 字=1 张卡不折叠；短回复=零改动
5. **开关矩阵**：关锚点→无卡片但折叠正常；关折叠→纯流式直显但卡片正常；都关→完全回到现状
