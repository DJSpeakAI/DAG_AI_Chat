## 一、Bug：切后台回来对话清零（根因实锤）

**链路**：ChatPage 的消息绑定 = `nodeList.find(nodeID === currentBubbleStore.nodeID)`（@Computed）。
手机回前台 → EntryAbility.onForeground → `forceCloudSyncNow()`（0.223.0 手机掉队根治点）→ cloudSync 完成 → reconcileWithRows → 任一域有变更（PC/Pad 同步来的数据；手机=被动合并端最易触发）→ `refreshWorkspaceFromPools()`（ChatModel.ets:2362）→ **无条件 `current.nodeID = ''`**（旧注释：旧选中节点在新工作区可能失效）→ ChatPage `currentMessages` 变空数组 = **对话清零**。退回画布重点气泡恢复 nodeID，数据无损——与用户描述逐字吻合。

**修复**：重建工作区后，`prevId` 仍在新的 nodeList 中则保留 nodeID+bubbleX/bubbleY（子气泡创建坐标基准）；节点真被远端删除/不在池中才清空。唯一调用点= reconcileWithRows，改动局部化。

**风险点（记录不扩修）**：流式回复进行中若恰逢 reconcile 替换节点实例，sendMessage 持有的旧实例引用会脱钩（今日已存在的旧风险，非本次引入；切后台 SSE 已被中断，实际暴露窗口极小）。

## 二、云端 TTS 回归（0.139 管线复活 + 三层兜底）

### 2.1 实证（2026-10-13 本机 curl 探针）

| 组合 | 结果 |
|---|---|
| `seed-tts-2.0` + `zh_female_vv_uranus_bigtts`（官方音色） | ✅ code=0 + mp3（base64 ID3 头实锤） |
| `seed-tts-2.0` + `S_bv8H32Sg2`（合成音色） | ❌ 55000000「resource ID is mismatched with speaker related resource」——端点/Key 正常，音色属另一资源体系 |
| `volc.service_type.10029/10028/10030~10036`、`volc.megatts.default`、`seed-tts-1.0` | ❌ 45000030 资源未开通（seed-tts-1.0 内部别名=10029） |

结论：合成音色（S_ 前缀，声音复刻体系）需控制台开通对应资源后才能直用。**当前用户控制台未开通 → 引擎做音色自动回退**。

### 2.2 方案

- **恢复 0.139 管线**（存档：docs/0.165+/0.189.0 §9 + git 16001f2^）：`synthesizeTTS`（openspeech /api/v3/tts/unidirectional，X-Api-Key/X-Api-Resource-Id/X-Api-Request-Id 三头，req_params 体，chunked JSON 拼 base64）+ 分段串行合成 + AVPlayer 临时文件顺序播放（代际号失效机制原样）。新文件 `utils/CloudTtsEngine.ets`（模块单例 `cloudTts`），不再塞回 ChatPage。
- **配置零 Schema 变更**：复用 ApiConfig 休眠字段 audioKey/audioModel/audioVoice/audioEndpoint（0.139 起就持久化+随 cfg:api-config 账号级云同步）。audioKey 已在 rawfile/config.json（loadBuiltinApiConfig 自动填空位，不入 git、上架前删）。
- **音色默认值**：`zh_female_vv_uranus_bigtts` → `S_bv8H32Sg2`（用户指定）。历史安装迁移：audioVoice===旧默认值（该字段 0.139 起从未开放编辑，持久化值必为类默认）→ 换新默认，幂等按值比较。
- **三层兜底**（用户规则「没配置→本地；失败→本地」）：
  1. `configured()` = audioKey && audioModel 非空 → 云端优先；
  2. 云端 55000000（音色资源不匹配）→ **自动换官方音色 zh_female_vv_uranus_bigtts 重试一次**（会话内记住生效音色；控制台开通复刻资源后自动回到合成音色）；
  3. 仍失败 → 本地 CoreSpeechKit + 友好中文 toast。
- **朗读文本清洗（顺带根治「星号都读进去」）**：`mdToSpeakableText()`（MdInline.ets 纯函数）——代码围栏整段跳过、表格行→单元格「，」连接、表格分隔行/hr 跳过、行内标记（**/*/~`/链接 url）剥离、标题#去掉。本地+云端共用。ohosTest 断言随 ARKUI-TEST 自动跑（§12.13 军令）。
- 单词发音（WordSpeaker）保持本地 Laura 美式不动（短文本+离线零成本，口音联动体系不扰）。

### 2.3 设置 UI（API Tab 最下方——用户指定位置）

「语音朗读（TTS）」卡片区：
- 提供商：火山引擎（端点内置）/ 自定义（URL 可填）——从端点推导（含 bytedance.com=火山），零新字段。
- 火山：音频模型 / API Key / 音色 ID 三输入框（音色默认已填 S_bv8H32Sg2，两种音色体系可切）。
- 自定义：端点 URL + 上述三项。
- 常驻小字说明回退规则；**首次保存含 Key 配置时一次性 AlertDialog 提示**（PersistenceV2 flag，用户要求「第一次有提示，之后不再提示」）。
