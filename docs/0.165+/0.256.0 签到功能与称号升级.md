## 二、数据层（全部放 ChatModel.ets，签到区紧随 SP 体系）

- **SignInStore**（@ObservedV2，PersistenceV2 **全新 key `sign-in-v1`**）：signDates: string[]（'YYYY-MM-DD'）/ lastSignDate / streak / maxStreak / guideShown。本地存储（按需求 §2 丙方案——卸载重装清沙箱=首登弹窗天然复现；⚠️多端各自可签=已知取舍，风险节 §六-3）。
- **纯函数**：todayStrWithOffset(offset)（本地自然日 getFullYear/getMonth/getDate 拼 YYYY-MM-DD，禁 Date.now 直比）/ nextStreak(last, streak, today)（昨天签=+1 否则归 1）/ signInRewardSp(streak)（递增公式）/ milestoneBonusSp(streak)（7→10000、30→50000、100→200000）/ isSignedToday(store)。
- **doSignIn(store, siyi)**：防重复（今日已签返 0）→ 连击更新 → signDates push → maxStreak → bonusSp += 当日+里程碑 → scheduleRowFlush()（cfg:siyi-points 云上行同款）→ 返回发放总额（UI 成功态展示）。
- **DebugDayOffsetStore**（AppStorageV2 `debug-day-offset`，默认 0）：日期偏移调试开关；签到弹窗底部日期小字长按/右键 bindContextMenu 唤出（+1/+7/+30/+365/清零）。上线默认 0 零影响。
- **SignInDialogBridge**（AppStorageV2 `sign-in-dialog`）{ visible }——边栏入口/首登判定 → Index 根挂载弹窗消费。
- **LevelUpBridge**（AppStorageV2 `level-up-bridge`）{ lastLevel, pendingLevel }——等级升级弹窗触发桥。
- **siyiLevelOf(days)**：头衔数值化 1~8（与 siyiLevelTitle 同阈值）；**SIYI_LEVEL_PERKS: string[]** 权益数组（与 GSD 八级表文案同源，双份维护注释互指）。
- **notifyLevelUp(days)**：lastLevel==0 → 静默基线；level>lastLevel → pendingLevel=level（弹一次）。调用点=**recordStat 尾部 + mergeStatDaysRow 尾部**（本端学习+云下行天数吸收两路）。
- **maybeShowSignInGuide()**：!guideShown && signDates空 && 已登录 → guideShown=true + 弹窗桥 visible=true；挂 **stampFreeTrialOnLogin 内**（四登录入口天然全覆盖：Index.doLogin/Index.aboutToAppear 补查/BillingPage/AppSideBar——0.217.2 铁律）。

## 六、风险点

1. SignInStore 本地不同步：多端同账号各自可签（每日多领）——需求文档定案（重装可重弹引导=同源取舍），上线前若要账号级防薅须走 cfg: 行上云（另立迭代）。
2. 等级嘉奖加成（+5%~+30%）仅 GSD 文案未实装——签到发放不乘加成（与 0.247.7 数值口径一致），加成实装时签到/学习发放需同步乘。
3. 补签卡（1,000 SP/张）仍为文案预留，未实装。
4. signDates 无限增长：年 365 条 ≈4.4KB，PersistenceV2 JSON 无压力，不做裁剪。
