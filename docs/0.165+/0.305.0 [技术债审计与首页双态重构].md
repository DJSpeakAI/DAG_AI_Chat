# 0.305.0 首页双态重构 + 全代码技术债审计

## 一、首页双态重构（用户拍板：不要在首页上盖一层）

### 问题
0.303.0 的首启门禁 `OnboardingGate` 做成了「首页 + 全屏覆盖层」——同一个品牌区/登录入口画了两遍，
用户指出：全新用户永远看不到首页，等于白画一屏，属偷懒/技术债。

### 重构方案（已落地）
- **删除** `components/OnboardingGate.ets`（独立覆盖层）与 Index 根 Stack 挂载。
- 首页 `Navigation` 内容改为**双态渲染**（一套代码）：
  - `@Computed needsOnboarding`（= 未同意 或 协议版本落后，preferences 同步真值，首帧即准）
  - 未同意 → `onboardingPanel()`：品牌 → 华为登录按钮 → 暂不登录 → 协议两行 → 不同意退出 → 版本号
  - 已同意 → 原正常首页：品牌 → 进入气泡树 → 账号区 → 版本号
  - 品牌区抽 `brandHeader()` **两态共用一份**（零重复）
  - 协议正文 `agreementTextPanel()` 作为首页内切换页（非弹窗）
- **合规改为逻辑守卫（非视觉盖层）**：
  - 未同意时不渲染侧边栏/边栏把手；`sideBarNav()` 入口守卫
  - 未同意时不弹业务弹窗（备份恢复询问等加 `!needsOnboarding` 守卫）
- **删除的冗余链路（技术债）**：
  - `AgreementBridge.promptVisible` 字段退役（原 basic 弹窗已无挂载点=死路；协议升版时老用户点登录会静默无反应）
  - `showAgreementPrompt` / `showHomeAgreeCheck` / `homeAgreed` / `homeShakeX` / `shakeHome()`
  - BillingPage / GSD / AppSideBar 三处 `needsAgreement()` 弹窗分支（未同意时不可达）
  - Index 启动 800ms 门禁判定遗留（0.279.5 迁移同步存储后已无意义）
  - 「撤回同意」改为 `terminateSelf()`（原链路依赖已删的 basic 弹窗）——撤回=停止处理，合规
- 版本号在门禁态也显示（装机验收/报障定位用）。

### 审计方法
- 调试日志扫描（console/hilog）、TODO/FIXME、注释代码块
- 零引用源文件扫描（全部 .ets 被 import 次数）
- 零引用 media 资源扫描（$r('app.media.*') 与配置 json 双向核对）
- 硬编码色值统计（页面/组件层）
- setTimeout 全量复核（找「等水合」型遗留）
- AppStorageV2/PersistenceV2 key 一致性
- pages/ 与 main_pages.json 对照（确认无僵尸页面）

### 结论：现存技术债清单（本轮不修，需专项任务）
1. **订阅体系退役残留**（MEMORY 已记「待后续迭代清码」）：subscription 语义仍散落 9 文件 ~37 处
   （ChatModel 19 / AppSideBar 4 / GSD 4 / BillingPage 2 / ReminderDialog 2 / CloudSyncUtil 2（红线）/
   IapUtil 1 / DataWipeUtil 1 / Index 2）；**Index 仍挂载 ReminderDialog（订阅提醒弹窗）**。
   → 建议专项清理；CloudSyncUtil 属红线须转人工。
2. **硬编码色值 85 处**（页面/组件层）：成功绿 #4CAF50、警示红 #F44336/#FF4D4F、纯白 #FFFFFF、
   玻璃效果 rgba 等，UI_GUIDELINES 无对应 token。→ 建议专项「语义色 token 化」（AppTheme 加
   success/warning/overlay 语义色），一次性收敛，视觉零变化为验收标准。
3. **未使用 import/变量 191 条编译警告**（存量）：零风险但机械量大，可随下次相关文件改动顺带清。
4. **hilog 3 处**（EntryAbility persistence error / TrackUtil 上报状态）：诊断类日志，保留（非调试打印）。
5. `subscription-v1` 持久化 key 仍在（数据保留，随订阅清理专项处理，禁擅删）。

### 明确无债项
- 无 TODO/FIXME 临时标记；无注释掉的大块死代码；无僵尸页面（pages 仅 Index）；
  无零引用源码文件（5 个 UNREF 均为 module.json5/main_pages 注册的入口/扩展/页面）。
