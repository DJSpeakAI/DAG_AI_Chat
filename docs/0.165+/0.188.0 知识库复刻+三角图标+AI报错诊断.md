## 3. streamChat 零内容流诊断（用户报「AI 未返回文本内容」）

**现象**：点发送 → AI 气泡显示「（AI 未返回文本内容，请重试或更换模型）」；火山后台费用正常；之前可用。

**排查结论**：
- 该文案只在 **onDone（流正常结束）且零内容** 时出现——不是网络/鉴权错误（那会走 onError 显示「请求出错」）
- **非 v0.187.0 回归**（发送链路未动）
- 根因：`requestInStream` 无状态码校验，火山返回 4xx（key 失效/模型下线/限流）时，JSON 错误体**没有 `data:` 前缀**，SSE 解析器全部跳过 → 零内容 → onDone → 通用文案。**真实错误被吞了**

**修复**（ApiClient.ets）：
- 流式过程留 `rawPreview`（原始体预览，600 字符截断）+ `deliveredAny`（是否交付过内容/思考分片）
- dataEnd 时零内容 → `extractStreamError(rawPreview)`：
  - 纯 JSON 错误体 / SSE 行内 error → 提取 `error.code/message` 走 **onError**（气泡显示真实原因，如「API 返回错误（ModelNotExists）：…」）
  - 非 SSE 原始体（网关 HTML 等）→ 展示前 200 字符
  - 合法 SSE 且无 error → 维持 onDone 通用提示（真·空回复）
- 查词/提炼共用 streamChat，修复自动生效

**下一步**：真机重试一次发送，气泡会显示火山返回的真实错误（最常见：方舟下线旧模型号 → 去火山方舟控制台核对 app 设置里的模型名是否还在）。
