# 0.287.0 回车确定（P1）+ 操作撤销栈（P2 Ctrl+Z 三类）

> ★ 0.287.1 追记（2026-10-21 用户实测反馈同日修复）：Ctrl+Z/Ctrl+Shift+Z 真机可用 ✓；气泡标题紫框回车 ✓；**删除气泡确认弹窗是系统灰框**（confirmDeleteBubble 走 showAlertDialog）→ 本版改自绘暗紫弹窗（样式复刻 titleEdit 定式+文案加「删除后可 Ctrl+Z 撤销」+destructive 不设回车默认焦点）。**「删除气泡 Ctrl+Z 没用」实情**：子气泡/平铺根已入栈，tabs 模式根气泡走 deleteTab（删整个选项卡）未入栈——用户拍板不着急，后续需要撤销处再点名。versionCode 1000407。

## 一、需求与拍板（2026-10-21 用户）

- **P1 回车=确定全套**：单行输入框弹窗（气泡重命名/选项卡重命名/文件夹新建重命名/卡片编辑标题/单词编辑/兑码/标签与学习量 mini 输入）Enter 走确定链；AppConfirmDialog 确认钮默认焦点（Enter 触发）。
- **红线**：消息输入框（TextArea，Enter=发送+Shift+Enter 换行已有 0.215.11）不动；多行内容框 Enter=换行不触发；搜索框（无确定语义）不做；ChatPage 删除/举报自绘确认弹窗（destructive/外发）不绑 Enter 防误触。
- **P2 撤销栈三类**：删除（消息/气泡/卡片/单词/文件夹级联快照）+移动文件夹+重命名；**50 步环形**（PS 默认档，超深裁头）；会话级不持久化；Ctrl+Z 撤销 / Ctrl+Shift+Z 重做；toast「已撤销：××」。
- **不进栈**：设置修改（即时可改回无损失概念）、发送消息（计费请求不可逆）、新建（撤销=删新建有丢内容风险）、导入（一期不做）、文本打字级撤销（P3 缓）。

## 二、设计

### P1 实现模式
- TextInput `.onSubmit((key, ev) => this.confirmXxx())`（官方 FAQ：外接/软键盘回车均触发）。
- AppConfirmDialog 确认钮 `.defaultFocus(true)`（弹窗打开即获焦，Enter 系统焦点链触发 onClick）。

### P2 架构（命令模式）
- `common/UndoStack.ets`：UndoEntry{label, undo(), redo()}；线性历史（push 截断 pointer 后尾）；上限 50 裁头；undo/redo 返回 label 供 toast；AppStorageV2 内存共享不落盘（闭包不可序列化，恰好会话级语义）。
- 键盘：Index 根 `.keyboardShortcut(cb, 'z', [CTRL])` 撤销 / `'z', [CTRL, SHIFT]` 重做（0.285.2 同 API 先例，窗口获焦即响应）。
- 入栈点（闭包捕获完整对象引用快照）：
  1. ChatPage.deleteMessage：msg+index；undo=splice 放回+saveTree
  2. BBTreeCanvas 删除气泡：node 引用+parentID；undo=nodeList 放回+saveTree
  3. 两库滑出删除卡片/单词：对象引用；undo=复用 add* 路径放回（自然触发云上行钩）
  4. 两库 deleteFolderCascade：删前子树快照（folders+cards 全集）；undo=逐个放回
  5. moveFolder：folderId+oldParentId；undo=moveFolder 回旧父（防环校验天然复用）
  6. 重命名（气泡标题/选项卡/文件夹）：id+旧名；undo=写回+save
- 云同步风险披露：undo 放回复用 add* 云钩上行恢复行；墓碑表残留由 0.230.1 幂等清洗机制消化——本轮不碰 CloudSyncUtil（红线），实机开同步验证列为验收项。

## 四、验收标准

1. 任一单行弹窗输入后 Enter=点确定（PC 物理键盘+手机软键盘回车同效）。
2. AppConfirmDialog 弹窗打开 Enter=确认。
3. Ctrl+Z 依序撤销删除消息→气泡→卡片→移动→重命名，toast 显示对应 label；Ctrl+Shift+Z 重做；50 步后最旧丢弃。
4. 级联删除文件夹后 Ctrl+Z 整棵子树（含卡片记忆字段）完整回归。
5. 重启 app 撤销栈清空（会话级）。
6. 消息框 Enter 发送/Shift+Enter 换行行为零变化；设置类无撤销。
7. ohosTest UndoStack 断言全绿；双模块 BUILD SUCCESSFUL。
