### 2.2 根治方案（三选一已定案=A）

- **用同一颗华为风格细线 chevron SVG**（符合项目「单色透明 SVG」图标定式），收起态旋转 **0°**、展开态旋转 **180°**（或 90°，两态二选一并全项目一致），配 220ms `animateTo` 旋转动画（与现有章节折叠 220ms 动画同 `Curve.EaseInOut`）

- 素材优先复用 media 资源目录已有 chevron/arrow；无则新建一颗，风格对齐 ask_ai.svg（细线、白 65% 透明定的图标语言）

### 2.3 范围（军令=全项目只许一套折叠三角）

1. **核心**：章节折叠行 `FoldRow`（ChatPage.ets:1308）字符 `▼/▶` → SVG chevron 旋转

## 四、改动 C：钩子树重构（核心，砍2留2加3）

### 4.1 最终钩子树（6 类：5 类 AI 生成 + 1 类本地保底）

| 类型 | 徽标文案 | 生成方 | 科学原理 |
|---|---|---|---|
| `quiz` | 考考你 | AI | 检索练习（**难度必须高级**，见 4.3） |
| `hook` | 前方高能 | AI | 蔡格尼克效应（悬念预告，**触发可激进试**） |
| `rephrase` | 换个说法 | AI | 精细加工（硬核点翻译成一句大白话递话） |
| `predict` | 先猜再看 | AI | 预测式阅读 PQ4R（暂停让读者预测推导再往下验证） |
| `recap` | 一句话锁住 | AI | 间隔摘要（刚读段落一句话锁住） |
| `breath` | 到这里了 | 本地保底 | 注意恢复 + 进度实感（替代空洞安慰） |

**砍掉**：`link`（联想一下）——AI 给的发散联想必然不是用户要的，联想权只属于用户；`breath` 的旧「歇口气」空洞安慰定位被「到这里了」进度实感替代。

### 4.2 crowd-level 改动点

| 点 | 文件:位置 | 改法 |
|---|---|---|
| 徽标映射 `anchorBadge()` | ChatPage.ets:999-1011 | 四档 → 六档：quiz=考考你 / hook=前方高能 / rephrase=换个说法 / predict=先猜再看 / recap=一句话锁住 / breath=到这里了 |
| 锚点类型白名单（`RE_ANCHOR` 解析处） | MdInline.ets | 加 `rephrase`/`predict`/`recap`；删 `link`（link 输入一律降级普通文本）；`breath` 仍是本地保留 |
| 本地保底文案池 `BREATH_POOL` | MdInline.ets:483-488 | 4 条空洞安慰 → 重写为**结构进度式**实感文案（见 4.4） |
| ANCHOR_LONG_PROMPT | Prompts.ts:38-44 | 类型三选一 → 五选一 + quiz 难度升级 + 措辞约束（见 4.3） |
| ANCHOR_MEDIUM_PROMPT | Prompts.ts:46 | 同步五选一 |

### 4.3 prompt 改写要点（★用户重点拍板：quiz 难度、措辞人味）

`ANCHOR_LONG_PROMPT` 类型段改为：

```
2. 类型五选一：quiz=考考你（就刚讲的核心点出一句有难度的问句，禁止给出答案）、hook=前方高能（一句话吊胃口、不剧透，指向即将讲的重点）、rephrase=换个说法（把刚讲的硬核概念用一句大白话/一个比喻重说一遍）、predict=先猜再看（在推理转折处暂停，问读者“你猜下一步会怎么推”）、recap=一句话锁住（把刚讲的一段用一句话总结锁住）；
```

另加两条硬约束（军规数字锚定 + 负向配对）：

```
* quiz 难度红条：禁止出“1+1”式浅题、禁止出毫无信息量的送分题；必须设计成能促使读者停下来跨知识点、反直觉、需推理才能答的高级问题，可适当提高难度甚至跨章节。
* 措辞像人、禁系统腔：锚点文案必须像“一个懂你的人在递话”，禁止出现「温馨提示」「小贴士」「请注意」等系统提示腔；每句与上下文强相关，禁止通用套话、禁止重复之前用过的表述。
```

`ANCHOR_MEDIUM_PROMPT` 的「类型从 quiz/hook/link 三选一」同步改「五选一」。

### 4.4 本地保底「到这里了」文案池（有实感，不空洞）

`BREATH_POOL` 重写——由**结构信息本地可算**（不进语义填空），例如：

- 「读到这里，你已经走完这一节了」
- 「停一下：上面这段已经讲完了，往下是新的内容点」
- 「到第 X 节了，本节约 Y 字」（X/Y 由渲染上下文注入）
- 「喘口气，把这一段和前面连起来再看下一段」

**关键**：保底文案须携带「第几节 / 本节字数」这类**实感上下文**（`insertLocalAnchors` 签名需传入节序号/总数，或改由渲染层按节号算），不能再是脱离内容的空安慰。同输入同输出的确定性轮换纪律不变。

## 五、改动 D：小标题品牌色 + 术语荧光底

### 5.1 小标题品牌色（方案 A 定案）

`RichBlockView` 里 h1~h6 分支（ChatPage.ets:1156-1158）→ 标题文字上**品牌色**（BRAND_SECONDARY，或 DesignTokens 里一个更亮的蓝紫标题色，以与正文白区分且不刺眼为准），字重 600 保留、字号分级 `headerFontSize` 不变。

- 命中用户已点赞的截图样式：左侧自带「四、」编号 + 整条品牌色
- **不拆标题编号**（AI 编号格式不统一，拆解有误伤风险），整条染色即可

### 5.2 术语荧光底（实验性，留回退开关）

正文 `**加粗**`（`MdInlineSpans` 的 `sp.bold` 分支）→ 加一层 **12% 品牌紫底**（`rgba(124,77,255,0.12)`，荧光笔效果，治「一大片白」）。

- 仅正文段落内的 `bold` 加底；`heading` 块走 5.1 品牌色文字，不加底（避免叠加）
- ⚠️ 风险：`**` 未必是术语，可能是普通强调，全量加底可能过花——**先全量加底试观感**，代码留一处 `glowHighlight` 布尔，观感太花可一键关掉回退为纯加粗

## 八、验收标准

### 8.1 ohosTest（MdInline 纯函数）

1. 类型白名单：`rephrase`/`predict`/`recap` 合法解析为锚点块；`link` 降级普通文本；`quiz`/`hook` 保留
2. `stripAnchorMarks(keepText)` 对新增类型清洗正确
3. `BREATH_POOL` 重写后确定性轮换（同输入同输出）仍成立
4. `breathThreshold` 两档：疏 800 / 密 400，非法档位兜底

### 8.2 手工验收（用户/执行 AI 真机或窗口缩窄自测）

1. 章节折叠行展开/收起 = 同一图标旋转，无「另一个型号」感

4. 真机长回复出现五类锚点，quiz 问题有难度（非送分题）、文案无系统腔
5. 设置页密度两档「疏/密」默认疏，切换后长文锚点密集度变化可感知
