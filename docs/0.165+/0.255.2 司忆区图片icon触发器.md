# 0.255.2 司忆区图片 icon 触发器（2026-10-18 实施完成）

> 正本说明：本文档 = 桌面《司忆区图片展示方案（终版）.md》（用户裁决稿）归档 + 实施记录。
> 用户口头裁决「执行」即开工（project_rule §11）；桌面副本已按 §10/§11 清理。

## 一、原方案（用户终版 v1.0，全文要点）

1. 知识卡两类图：**标题图**（题面插图硬需求）与**内容图**，合计最多 9 张；
2. **禁止缩略图直接铺在列表行里**——每张卡图片颜色不一，列表会花掉（用户明确否决）；
3. 有图显示**图片 icon**，点击弹出图集滑动浏览；**拆分标题图 icon + 内容图 icon 两个独立入口**（题面归题面、答案归答案，不合一）；
4. 图片放文字前面；文字横向滚动条隐藏；
5. 标题图 icon：折叠箭头右侧、标题文字之前固定槽位（不随标题横滑）；内容图 icon：展开后内容行描述文字之前；
6. 复用统一图片查看器（0.211.2 四场景统一的定式——司忆区为第五场景接入），两数组严格分离不交叉；
7. 无图不显示对应 icon（不占位）；评分按钮/文字排版零改动。

## 二、用户执行时两条口头补充（拍板）

1. **icon 统一用输入区「添加图片」同款**——发送▾下拉菜单里的华为透明单色 svg（`$r('app.media.image')`，白 65% 细线画框+山形）。「统一的彩色 icon 太难看」，全应用同款零新素材；
2. **点开查看器返回后 icon 必须原地恒在**——「icon 不可能我点击出来之后不显示，一直留在那个地方，用户想点就点」。实现保障：icon onClick 只动查看器三状态（imageViewerImages/Index/Visible），绝不碰 reviewExpandKey 展开态；查看器四路关闭（×/点图/右滑/返回键）均只翻 imageViewerVisible——展开态与 icon 原地不动，可反复点。

## 四、验收清单（装机后）

1. 带标题图知识卡：标题行 icon 在箭头右侧、标题文字前；无标题图无 icon；带内容图知识卡：展开后内容行描述前出现 icon，折叠态不显示；
2. 点标题图 icon → 查看器只滑标题图；点内容图 icon → 只滑内容图（两数组严格分离）；
3. **点 icon 开查看器 → 任意方式关闭返回 → icon 与展开态原地不动，可反复点开**（用户口头军令）；
4. 长标题/定义横向滚动顺畅、无滚动条横杠；
5. 文字排版/评分按钮与改动前一致（零回归）；
