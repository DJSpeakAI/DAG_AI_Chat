# 0.222.22 知识卡入库弹文件夹选择（两入口）

> 版本：0.222.22（承接 0.222.21 / versionCode 1000224 → 本版 1000225）
> 日期：2026-10-11
> 类型：功能迭代（复刻 0.222.21 单词库同款交互到知识库）

## 一、需求（用户口述拍板）

- 单词库加词选文件夹（0.222.21）已验收，知识库加卡片**同样**要做：现在知识卡入库全落根目录，须弹文件夹选择弹窗，选中归入对应文件夹。
- **知识库加卡有两个入口**（用户点名）：
  1. **划词「入知识库」**——对话页划词悬浮栏 → AI 提炼草稿 → 卡片编辑弹窗 → 保存入库；
  2. **屏幕圈选「存入知识库」**——输入框右侧圈注（AnnotationPage 截图标注）→ AI 反馈自动制作卡片 → 同一个编辑弹窗 → 保存入库。
- 侦察实锤：两入口最终**汇聚到同一个编辑弹窗与保存点**（`ChatPage.saveKnowledgeCard()`），改一处全覆盖。
- 交互与单词库版完全一致：弹窗 UI 复刻知识库「移动/复制」弹窗（树形连接线+折叠三角+根目录行+520/86% 宽）；无文件夹时不弹直接入根目录（待用户确认沿用）。

## 二、现状根因

- `ChatPage.saveKnowledgeCard()`（L2224）：`new KnowledgeCard(generateMessageId(), title, definition, this.knowledgeImageUri, Date.now(), 0, 0, 0, 0, this.knowledgeSelectedTags)` —— 构造截断到第 10 参（tags），**第 12 参 folderId 未传**（默认 '' → 根目录）。与 0.222.20/0.222.21 同族「构造尾部可省参数最容易漏」雷。

## 三、方案（镜像 0.222.21）

1. ChatPage 新增状态：`@Local cardFolderPickerVisible` + `@Local cardPickerCollapsedFolderIds: string[]`（@Local string[] 替换引用触发重渲染）。
2. `saveKnowledgeCard()` 改分流：`knowledgeBank.folders.length > 0` → 弹选择器；否则直接 `confirmSaveKnowledgeCard('')` 入根目录。
3. 新增 `confirmSaveKnowledgeCard(folderId)`：KnowledgeCard **13 参显式传全**（第 11 参 images='' 占位、第 12 参 folderId、第 13 参 titleImages='' 占位）→ `addKnowledgeCard` → `closeKnowledgeEdit()` → 关选择器。
4. 树方法四件套 + 无参 `@Builder cardFolderPickerDialog()`——树源 `this.knowledgeBank.folders`（KFolder），根目录行计数 `this.knowledgeBank.cards.length`，标题「保存卡片到…」。
5. build 渲染在知识卡编辑弹窗 if 块**之后**（同层后绘制在上，编辑弹窗被遮罩覆盖、取消选择器后回到编辑弹窗草稿不丢）；`handleBack()` 在 knowledgeEditVisible 之前加弹窗拦截（返回键先关选择器）。
6. import 补 `KFolder, KFolderTreeItem`（照搬代码漏 import 雷专项核对）。

## 五、风险点

- KnowledgeCard 构造 13 参占位顺序（id,title,definition,imageUri,createdAt,strength,reviewCount,lastReviewAt,nextReviewAt,tags,images,folderId,titleImages）——错一位即字段错位，落码后逐参核对。
- 选择器渲染位必须在编辑弹窗之后（层级在上），否则被编辑弹窗遮罩挡住。
- 遮罩点击取消选择器=回到编辑弹窗（草稿保留），不能误关编辑弹窗。

## 六、验收标准

1. 划词「入知识库」→ AI 草稿 → 编辑弹窗 → 点「保存入库」→ 弹文件夹选择弹窗（UI 与知识库移动/复制弹窗一致）→ 选「数学」文件夹 → 知识库该文件夹下出现新卡。
2. 屏幕圈选 → 标注 → 「存入知识库」→ 同一个编辑弹窗 → 保存 → 同样弹选择器归档。
3. 无文件夹时点保存直接入库（不弹窗，待确认）。
4. 弹窗折叠三角/返回键/取消/遮罩可用；取消后编辑弹窗草稿不丢。
5. 三台 bm dump 实锤 versionCode=1000225。
