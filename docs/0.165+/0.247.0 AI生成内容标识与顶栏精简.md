## 一、需求分析

1. **AI 标识合规**：对话页需常驻「内容由 AI 生成」标识，全局可见、审核截图一眼可见。
2. **顶栏精简（用户拍板）**：删除对话页顶栏右侧「单词库」「知识库」两个 icon（入口与边栏重复、用户认为无用），仅保留设置。
3. **模型名上顶栏（用户拍板）**：当前模型名移到设置图标左侧显示；消息气泡下的别名行删去模型名，只留 token 统计。
4. 本迭代**不含**前端敏感词预过滤（另迭代做）；本迭代仅 UI 标识部分。

## 二、改动方案

### 2.1 顶栏右侧重排（ChatPage.ets `topBarTitle()`，约 4173-4249 行）

改动前：`[←] [气泡/N条对话] …… [📖单词库] [📚知识库] [⚙设置]`

改动后：`[←] [气泡/N条对话] …… [内容由 AI 生成 · 模型名] [⚙设置]`

- 删除 `bookopen`（单词库）与 `library`（知识库）两个 Row 块（约 4211-4232 行），settings Row 原样保留。
- 在 settings 左侧新增一组：`Text('内容由 AI 生成 · ' + 模型名)`。
  - 模型名取值复用现有别名链：`apiConfig.modelAlias` → 空则 `aliasStore.aliasFor(apiConfig.model)` → 再空则 `apiConfig.model` 原名。
  - 字号 11、TEXT_SECONDARY、FONT_INTER、maxLines(1)、TextOverflow.Ellipsis、`constraintSize({ maxWidth: '45%' })`（防长模型名挤爆手机顶栏）。
  - 高度 40vp 包裹行、padding 4，与 settings icon 同款规格对齐。
  - **顺序开放点（用户可一句话改）**：默认「AI 标识在前」（`内容由 AI 生成 · DeepSeek V4 Flash`），审核视角更醒目；备选模型名在前。
  - **点击行为开放点**：默认点击整组打开全局设置弹窗（`gsShared.visible = true`，切模型的自然路径）；不需要则去掉 onClick。

### 2.2 消息别名行只留 token（`modelDisplayText()`，2540 行；调用点 4877 行）

- msg.model / msg.inputTokens / msg.outputTokens Schema 字段**不动**（数据无损，仅展示变化）。

## 四、风险点

1. **入口可达性**：单词库/知识库从对话页顶栏消失，但边栏（PC/Pad 常驻、手机抽屉）入口完整，无功能丢失；用户操作习惯变化属预期内（用户主动要求删）。
2. **手机窄屏拥挤**：顶栏右组加长文本，已用 45% 限宽+省略号兜底；真机验收时看是否需再缩字号/改两行。
3. **合规强度**：顶栏单点标识是全局告知，若审核要求逐条标识，可后续在 AI 气泡区补角标（本迭代不做，留档备选）。
4. **别名为空场景**：未设别名时显示模型原始 ID（如 deepseek-v4-flash-ga-260731），较长——省略号兜底，可提示用户在设置里配别名。

## 五、验收标准

1. 顶栏右侧只剩「内容由 AI 生成 · 模型名」+ 设置 icon；点模型组开设置弹窗（若采纳点击方案）。
2. AI 消息气泡下别名行只显示「输入 x · 输出 y」，无模型名；无 token 的消息（如老数据/失败消息）该行不渲染。
3. 单词库/知识库仍可从边栏正常进入。
4. 三端（手机/Pad/PC）顶栏布局正常无溢出；PC 窗口缩到手机宽度仍按 PC 规则展示。
5. 版本号三处同步 v0.247.0 / 1000285，编译一次通过。
