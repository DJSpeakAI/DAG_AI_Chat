您好，我是 HarmonyOS 个人开发者，应用已接入 AGC 云函数（track-events）和云数据库（Cloud DB events 表）做自建埋点，看板自己搭。现在要做运营监控台，涉及：应用内虚拟点数消耗统计、IAP/兑换收入、下载量、用户量（DAU）、使用时长。请逐条回答以下问题，能引用官方文档链接最好：

## P0 组（直接影响我们的架构决策，请优先回答）

**问题 1：分析服务**
AGC「分析服务」对 HarmonyOS NEXT（ArkTS）应用是否可用？是否免费？内置提供哪些指标——新增用户、活跃用户（DAU/WAU/MAU）、使用时长（人均/单次）、次日/7日留存率？是否必须集成 Analytics Kit SDK（HarmonyOS NEXT 侧对应的 Kit 名称是什么？）才会有数据，还是不集成也有基础数据？

（我们的假设：有、免费、但必须集成 SDK 才有数据；我们目前没集成，打算自建埋点覆盖这些指标。）

**问题 2：数据报告（分发数据）**
AppGallery Connect 控制台里，应用市场的**下载量、安装量、卸载率**数据，个人开发者账号能看吗？数据粒度（按天/按版本/按地域）？能否导出 CSV/Excel？数据延迟多久（T+1 还是实时）？

（我们的假设：能看、能手动导出、T+1。）

**问题 3：【最关键】程序化拉取数据的 API**
AGC 是否对个人开发者开放任何 REST API / OpenAPI，能**程序化拉取**以下三类数据：
① 应用下载量/安装量
② IAP 订阅/付费收入报表
③ 分析服务数据（DAU/留存/时长/自定义事件）
如果有，API 名称和文档入口分别是什么？Publishing API（应用发布 API）的能力清单里包含这些数据吗？个人开发者能申请 Publishing API 权限吗？

（我们的假设：**没有**公开的数据拉取 API，Publishing API 只管版本发布/评论，不含数据报告——所以我们的方案设计成「控制台手动导出 CSV → 拖进自建看板导入」。**如果这条假设是错的、其实有 API，请务必告知，我们会改架构。**）

**问题 4：IAP 收入与对账**
IAP 订阅收入在 AGC 哪个报表看？结算数据更新频率？有无**服务端订单验证 API**（Server SDK 方式）供我们自己的云函数对账用？订阅的续订/退订事件有没有推送通知机制（类似服务端回调/webhook）？

（我们的假设：控制台有收入报表；Server SDK 有验证购买接口；续订事件推送对个人开发者可能不可用或需配置。）

**问题 5：Cloud DB 容量与配额**
AGC 云数据库免费额度：单应用存储上限多少？每秒/每日读写次数限制？我们的埋点表 events 会持续增长（将来可能到百万行），官方建议怎么治理（分区/归档/汇总表/定时清理）？超出免费额度怎么计费？

（我们的假设：小体量免费够用，但没查过具体上限。）

**问题 6：云函数配额**
云函数每月免费调用次数/执行时长额度是多少？超了怎么计费？单次执行超时上限（我们的埋点函数单次写库批量最多 200 条，会不会有问题）？

（我们的假设：免费额度对日活几千的应用绰绰有余。）

## P1 组（影响实现细节）

**问题 7：崩溃与性能**
崩溃服务（Crash）和应用性能服务（APM）对个人开发者免费吗？HarmonyOS NEXT 应用支持吗？需要集成什么 Kit？崩溃数据有 API 拉取吗还是只能控制台看？

**问题 8：匿名统计的合规口径**
我们打算在端侧生成一个**随机 UUID**（不含任何个人信息、每次安装随机生成）作为埋点的匿名用户维度，只用于统计 DAU 和单用户消耗分布。按华为上架审核和个人信息保护合规要求：这属于「必要统计」还是必须放进用户可关闭的「体验改进计划」选项？隐私政策需要披露到什么程度？

（我们的假设：随机 UUID 无个人属性，随体验改进计划开关走最稳；但装机激活计数想随协议同意走，需确认合规边界。）

**问题 9：华为账号 OpenID 用于去重**
用户登录华为账号后，云函数侧能拿到该用户的 OpenID/UnionID 吗？我们只想存它的 hash 做 SP 消耗按账号去重统计（不存明文、不收集资料），AGC 的云函数（cloud-server SDK）有接口获取当前调用者身份吗？

**问题 10：Analytics Kit 自定义事件**
如果集成 Analytics Kit：自定义事件数量上限、单事件参数上限是多少？控制台能看自定义事件的实时（当天）数据吗，还是 T+1？自定义事件数据能导出吗？
