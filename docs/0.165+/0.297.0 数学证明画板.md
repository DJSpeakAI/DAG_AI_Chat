# 0.297.0 数学证明画板（无限画布）

## 需求（用户口述整理）
数学学习者（抽象代数证明）手写证明过程→发 AI 检查思路；也画 3D 图形示意。主战场 Pad/阔折屏/折叠屏/PC，手机也可用。

## 用户四裁决（2026-10-22 对话拍板）
1. 技术路线：**自绘无限画布**（华为 Pen Kit 弃用——只支持纵向长画布不支持左右滑动/私有格式/工具栏不可定制/导出仅缩略图）
2. 工具栏：**无橡皮擦**（两色笔+撤销+保存+关闭，极简）
3. 输入：**手写笔+手指都画**（手写笔活跃期忽略手掌触摸防误触）
4. 导出底色：**跟随主题**（深色主题导出深底白/黄笔迹，所见即所得）

## 方案
- 新 `components/SketchPage.ets`：NavDestination 全屏页（AnnotationPage 先例：pathStack push/pop + store 回传 + onBackPressed 二次确认）
- 无限画布：视口 Canvas + 世界坐标（viewScale/viewX/viewY），屏幕=wx*scale+offset；笔迹按世界坐标矢量存储（缩放平移矢量重放永不模糊）；骨架复刻 BBTreeCanvas（PinchGesture 捏合中心锚点公式 + PanGesture 双指平移）
- 手势分工：单指 onTouch=书写（增量描线）；双指 Pan+Pinch=平移缩放（navActive 标志+touches.length 双保险防误画）；Canvas ≤10000px 限制用视口画布天然规避（华为 FAQ 实锤）
- 双色笔（token 复用零散色）：浅色=textPrimary 黑+danger 红；深色=textPrimary 白+reviewGood 黄
- 撤销=strokes.pop()+fullRedraw；onReady 尺寸变化清屏全量重放（faqs-arkui-1049）
- 新 `common/SketchModel.ets`：SketchResultStore（AppStorageV2 回传桥，imageUri+nonce）
- 导出：全部笔迹包围盒→OffscreenCanvas 矢量重放（短边≥1080 高清，px≤8000）→JPEG 0.92 dataUri→store 回传→ChatPage @Monitor 挂 pendingImages（走现有 9 格附件流）
- 入口：ChatPage 输入卡「+」改弹出双按钮（图片/文件=原 selectAttachments；画板=满格守卫+pushPath）
- 后续优化预留：PointPredictor 报点预测（API12 可用）第一版不接

## 验收标准
1. 冷启入口：+ →左弹「图片/文件」「画板」两钮；图片/文件=原文件选择；画板进画板页
2. 满 9 格点画板→toast 提示不进页
3. 单指画线跟手、双指缩放平移顺滑、笔迹缩放后清晰不糊
4. 撤销逐笔回退；✕有关注确认；完成→输入区出现缩略图（占 1 格）
5. 深浅主题下笔色/底色正确跟随
