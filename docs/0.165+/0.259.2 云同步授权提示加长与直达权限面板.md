# 0.259.2 云同步授权提示加长与直达权限面板

> 2026-10-19。桌面任务书《云同步授权提示加长与直达权限面板-执行方案.md》（用户拍板方案 A）照单施工，本文档为正式迭代档案（任务书原件已按 §11 生命周期删除）。

## 一、需求（用户实测两问题）

1. 授权被拒后的「未授权：请在系统『设置→应用→DAG AI Chat→权限』允许『跨设备同步』」toast 只有 1.5 秒，看不清就没了——加长到 10 秒。
2. 被拒后跳的是系统「应用详情页」，还要手动再点「权限」——改用系统 API 直接跳到权限开关处；三端（手机/Pad/PC）差异必须交给系统 API 统一处理，禁手写分端逻辑。

## 二、改动（4 处 + 1 附带）

| # | 文件 | 内容 |
|---|---|---|
| 1 | GlobalSettingsDialog.ets `showToastSafe` | 签名加 `duration: number = 1500` 可选参数（默认不变，其余调用点零影响；系统只认 1500/10000 两档） |

## 三、验收（三端真机，用户自测）

1. 未授权点「开启云同步」→ 系统授权窗点「拒绝」→ toast 10 秒 + 自动拉起权限面板（停在应用详情页=不达标）
2. 面板上开「跨设备同步」→ 状态卡变绿「已开启」+ toast「云同步已开启」+ 云同步真实激活
3. 已授权路径无回归；其他 toast 仍 1.5 秒；直达 API 异常机型兜底跳详情页不崩溃
