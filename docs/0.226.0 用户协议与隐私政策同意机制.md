## 一、需求分析（用户原始诉求）

用户在其他 APP 登录页底部看到「阅读并同意 用户协议 / 隐私政策 / 华为账号用户认证协议」的勾选同意区，希望本项目也对齐。用户点名要搞清楚：**官方是不是强制要求**。

用户进一步明确了**三个入口场景**都要覆盖：

1. **首页（未登录态）**：底部放常驻勾选框（用户认为"很合理"）。
2. **进入应用后，边栏左下角**（未登录时为空位，**放不下勾选框**）：点「华为账号登录」时，需先弹提示要求同意，同意后才能登录。
3. **设置 → 云同步（默认关，未登录）**：点击开启云同步 → 提示需登录华为账号 → 登录前同样要走同意。

用户逻辑确认：「不同意就不能登录吗？」——需回答并卡准边界。

## 二、合规判定（是否强制）

| 项目 | 是否强制 | 依据 / 口径 |
|---|---|---|
| 隐私政策 | ✅ **强制** | 《个人信息保护法》第17条；工信部《APP违法违规收集使用个人信息行为认定方法》；华为应用市场审核：须在**收集个人信息前**告知并取得同意 |
| 「阅读并同意」勾选/弹窗 | ✅ **实际强制** | 法律要求"取得同意"；审核实践要求首次运行以显著方式征求。本应用使用华为账号登录=处理个人信息，几乎必查 |
| 用户协议（服务协议） | ❌ 不强制 | 产品自选，主流 APP 均提供 |
| 华为账号用户认证协议 | ⚠️ 仅使用华为账号登录时涉及，**内容由华为官方提供** | **不自行撰写**，链接华为官方协议页；Account Kit 拉起登录时华为授权页本身也会展示 |

**核心结论**：隐私政策 + 阅读同意是过审刚需，**必须做**；用户协议建议顺带做；华为账号协议链官方。

**同意边界（回答"不同意能不能登录"）**：
- 不同意 → **不可用**依赖华为账号的功能（登录、云同步）——合规，因登录本身处理个人信息。
- 但**不得**因"不同意"而禁用不依赖个人信息的本地功能（本地对话/词库/知识库应照常可用）。
- 同意只 gate 住"登录 / 云同步"这条链路。

## 三、方案设计

### 3.1 统一同意门禁（一套文案 + 一个全局同意状态）

同意状态持久化（新增 `AgreementStore`，PersistenceV2，key 如 `agreement-v1`），**同意一次后不再重复拦截**。

| 入口 | 交互 |
|---|---|
| ① 首页未登录态底部 | 常驻勾选框 `☐ 我已阅读并同意《用户协议》《隐私政策》《华为账号用户认证协议》`；不勾选点「华为账号登录」→ 输入框/按钮抖动 + 红字提示，不拉起登录 |
| ② 边栏左下角登录按钮 | 点「华为账号登录」→ 先弹**同意弹窗**（复用同一套勾选组件）→ 同意后才拉起华为登录；取消则中止 |
| ③ 设置→开启云同步 | 现有"需登录"拦截前插入同款**同意弹窗** → 同意 → 登录 → 云同步开启 |

- 三者复用同一个勾选组件与同一份 `AGREEMENT_ITEMS` 文案。
- 首页底部勾选框与弹窗共享同一持久化同意状态：首页勾过，②③ 不再弹。

### 3.2 「关于」页法律条款卡片（统一收纳）

在 `GlobalSettingsDialog` 关于 Tab 现有「隐私政策」卡位置，扩为**「法律条款」卡**，三个入口：
- 《用户协议》
- 《隐私政策》
- 《华为账号用户认证协议》（外链华为官方）

用户理解正确：「反馈与联系」「查看隐私政策」等应全部打包在关于页统一呈现。

### 3.3 体验改进计划引导（合规红线）

- **红线**：体验改进计划**不得捆绑**进必选同意框，必须单独、非捆绑、默认关。
- **采纳方案①**：用户同意协议后，**首次**弹一张小卡片「是否加入体验改进计划？默认关 [暂不] [加入]」；选择记忆，只弹一次。
- 保留关于页开关作为随时可改的入口（现状）。

## 六、风险点

1. **隐私政策旧文案矛盾**：现存"不收集任何个人信息"与埋点冲突，不改会构成合规风险。
2. **同意边界**：绝不能因"未同意"禁用本地功能，否则违反"不得因拒绝提供非必要信息而拒绝基本服务"。
3. **体验改进不得捆绑**：必须独立、默认关，否则违规。
4. **华为协议链接**：不可杜撰 URL，须取官方链接。
5. **同意状态持久化**：需三入口共享，避免首页勾了、②③ 还弹。
6. **多端宽度**：同意弹窗须遵 UI_GUIDELINES §6-12a 断点制，禁裸百分比。
7. **@ObservedV2 实例**：新增 Store 挂 `@Local` + `@Computed`（既有铁律）。
