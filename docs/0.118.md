# 输入框多行滚动增强（修复）— 0.118

## 问题

`maxLines(5)` + `constraintSize({ maxHeight: 120 })` 均无法启用 TextArea 内部滚动。超过5行后第6行起内容不可见且无法滑动。

## 根因

ArkUI TextArea 的 `maxLines` 仅限制可见行数，不自动启用滚动。`constraintSize` 是布局约束，不触发内容滚动。`scrollBar` 属性不存在于 TextAreaAttribute。

## 修复方案

移除 `maxLines` / `constraintSize`，改用**动态 `height`**：

1. 新增 `@Computed inputAreaHeight`：根据 `inputText` 中 `\n` 数量计算行数，每行 24vp，上限 5 行（120vp），下限 1 行（24vp）
2. TextArea 绑定 `.height(this.inputAreaHeight)`：≤5 行自适应高度，>5 行固定 120vp
3. TextArea 设置固定 height 后，内容超出组件高度时，可编辑模式下自动启用内部垂直滚动
