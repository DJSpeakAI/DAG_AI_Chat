# Bug 修复 v0.13 — 四个 Bug + pathStack 讨论

## 一、pathStack 讨论

### 问题
其他 AI 指出：`pathStack: NavPathStack = new NavPathStack()` 不应该新建，应该继承 Index 的。

### 分析

当前代码：
```typescript
// Index.ets
@State pathStack: NavPathStack = new NavPathStack();

@Builder pageMap(name: string) {
  if (name === 'BBTreeCanvas') {
    BBTreeCanvas({ pathStack: this.pathStack })  // ← 传入 Index 的 pathStack
  }
}

// BBTreeCanvas.ets
pathStack: NavPathStack = new NavPathStack();  // ← 默认值，被父组件覆盖
```

**结论：当前代码功能正确，不是 bug。**

- `= new NavPathStack()` 是**默认值**，父组件通过 `BBTreeCanvas({ pathStack: this.pathStack })` 传入时会覆盖
- 这是 ArkUI 的标准参数传递模式，不存在"新建"问题
- `@Param` 装饰器在 ArkUI 中不存在，普通属性 + 构造传参就是正确做法

**但可以做一个小优化**：去掉默认值，改为必传参数，避免误导：

```typescript
// BBTreeCanvas.ets
pathStack: NavPathStack;  // 无默认值，必须由父组件传入
```

不过 ArkTS 编译器可能要求初始化，所以保留 `= new NavPathStack()` 也完全可以。

## 二、四个 Bug

### Bug 1：气泡拖拽松手后回到原位

**根因**：`ForEach` 的 key 只用 `nodeId`，位置变了但 key 没变 → 框架认为"没变" → 复用旧组件 → 用旧 `bubble.x` 渲染。

> ArkUI 官方文档确认：*"key 没变 → 认为这一项没变，直接复用旧组件"*

**修复**：key 包含 `x`、`y`、`messages.length`：

```typescript
ForEach(this.bubbleList, (bubble: BubbleNode) => {
  // ...
}, (bubble: BubbleNode) => `${bubble.nodeId}_${bubble.x}_${bubble.y}_${bubble.messages.length}`)
```

### Bug 2：发送后输入框不清零

**根因**：`TextInput` 未与 `this.inputText` 双向绑定。`this.inputText = ''` 只改了变量，输入框不更新。

**修复**：用 `$$` 双向绑定：

```typescript
TextInput({ text: $$this.inputText, placeholder: '输入问题...' })
  .layoutWeight(1)
// 去掉 .onChange()，$$ 自动同步
```

### Bug 3：气泡数量不随对话更新

**根因**：同 Bug 1，`ForEach` key 不含 `messages.length`，消息变了但 key 没变 → 不刷新。

**修复**：同 Bug 1 的 key 改法，已包含 `messages.length`。

### Bug 4：连线仍有问题

**根因**：
1. `Path` 默认有填充色，可能遮盖其他元素 → 加 `.fillOpacity(0)`
2. 连线的 `ForEach` key 也不含 `x/y`，气泡移动后线不更新

**修复**：

```typescript
Path()
  .commands(`M${parent.x + 30} ${parent.y + 30} L${bubble.x + 30} ${bubble.y + 30}`)
  .stroke('#CCCCCC')
  .strokeWidth(2)
  .fillOpacity(0)  // ← 透明填充
  .width('100%')
  .height('100%')
```

连线 ForEach key 也加 `x/y`：

```typescript
ForEach(this.bubbleList.filter(b => b.parentId !== null), (bubble: BubbleNode) => {
  ForEach(this.bubbleList.filter(p => p.nodeId === bubble.parentId), (parent: BubbleNode) => {
    Path()...
  }, (parent: BubbleNode) => `${parent.nodeId}_${parent.x}_${parent.y}`)
}, (bubble: BubbleNode) => `${bubble.nodeId}_${bubble.x}_${bubble.y}`)
```

## 三、修复总结

| Bug | 根因 | 修复 |
|-----|------|------|
| 气泡回原位 | ForEach key 不含 x/y | key 加 `${x}_${y}_${messages.length}` |
| 输入框不清零 | TextInput 未双向绑定 | `$$this.inputText` |
| 气泡数量不更新 | 同气泡回原位 | 同上 key 改法 |
| 连线有问题 | Path 默认填充 + key 不含 x/y | `.fillOpacity(0)` + key 加 x/y |
| pathStack | 不是 bug，默认值被父组件覆盖 | 保留现状 |
