# 进入对话页面自动滚到底部 — 0.110

> 归属版本：v0.1 内部迭代

## 一、问题

点击气泡进入对话页面，List 始终从顶部显示。对话一多，每次都要手动滑到底部看最新消息。

## 二、方案分析

### 方案 A：记住上次滚动位置（用户首选）

在 `BubbleNode` 加 `scrollOffset: number` 字段，退出时保存，进入时恢复。

**不与 @Trace 冲突**：用非 @Trace 的普通字段即可，仅用于存储，不需要触发 UI 更新。

但存在风险：
- `Scroller.scrollTo({ yOffset })` 对 `List` 组件可能不可靠
- `aboutToAppear` 时 List 尚未渲染，pixel offset 可能无效
- 不同屏幕尺寸下 pixel offset 不一致

### 方案 B：进入时滚到底部（用户备选）

在 `aboutToAppear` 中调用 `scroller.scrollEdge(Edge.Bottom)`，延迟 100ms 等 List 渲染完成。

**优点**：一行代码，100% 可靠，符合主流聊天 app 行为
**缺点**：不记住上次阅读位置

### 决策

先实现方案 B（滚到底部），可靠解决"每次从顶部开始"的问题。
方案 A 如后续需要再追加。

## 三、改动

仅改 `ChatPage.ets`，新增 `aboutToAppear()`：

```typescript
aboutToAppear() {
  setTimeout(() => {
    this.scroller.scrollEdge(Edge.Bottom);
  }, 100);
}
```

- `setTimeout 100ms`：等 List 完成首次渲染再滚动
- 不新增任何数据字段，不涉及 @Trace
