# 上半部分：需求、交互、数据模型

## 一、UI交互（划词悬浮操作栏）

1. **长按气泡**：直接唤起自研文本选择器，**移除中间「选择文本/删除」弹窗**；删除气泡统一用气泡左侧 × 按钮。
2. 划词选中文字，弹出 APP 自定义悬浮操作栏，**接管划词逻辑，禁用系统输入法小艺原生菜单**。
   - 按钮：`翻译` | `复制` | `全选`
   - ❌ **移除关闭按钮**：点击页面空白区域，自动收起悬浮栏。
3. 点击【翻译】：弹出小型预览浮窗，**不会新建对话气泡、不会写入气泡树对话流**。

## 二、单词数据模型 WordItem

```typescript
interface WordItem {
  word: string;         // 用户划词选中的原文单词 / 缩写
  fullName: string;     // 缩写的完整英文全称；普通单词此字段为空字符串 ""
  usPhonetic: string;   // 美式音标：缩写场景，是【全称】的音标；普通单词为本词音标
  explain: string;      // 中文释义：缩写场景是【全称】释义；普通单词为本词释义，仅保留1~2个高频核心释义，禁止例句、拓展内容
}
```

### AI 查询单词强制规则

判断输入文本是否为缩写：

- ✅ 如果是缩写：返回全称，附带全称对应的美式音标 + 全称中文释义，缩写字母本身不需要音标释义。
- ✅ 如果不是缩写：`fullName` 返回空字符串，返回单词自身美式音标 + 核心释义。
- 仅输出美式音标，释义精简，禁止例句、额外拓展。

### 翻译浮窗渲染规则【重点】

渲染顺序：**单词 → 全称 → 美式音标 → 中文释义**

代码必须增加条件判断：**`fullName` 为空字符串时，不渲染全称这一行，绝对不能出现空白占位行！**

示例 1：普通单词（无全称，不渲染全称行）

```text
student
/ˈstuːdnt/
n. 学生
```

示例 2：缩写单词（带全称，全部渲染）

```text
ARKTS
Ark TypeScript
/ɑːrk ˈtaɪp skrɪpt/
n. 方舟TS，鸿蒙ArkUI开发语言
```

浮窗底部：【加入单词库】按钮。点击存入持久化单词库；单词已存在时，弹出提示「单词已存在」。

## 三、单词库基础能力

- 单词库页面**没有手动新增单词入口**，新增单词只能从划词弹窗添加。
- MVP 仅支持**单词删除**；不做单词编辑、搜索。
- 单词库列表展示 4 项内容，每行右侧放删除按钮；点击删除，移除这条单词记录。
- 列表渲染同样遵循：`fullName` 为空，不渲染全称行，不出现空白占位。
- **存储方案**：单词库独立持久化，使用 `PersistenceV2`，和 BubbleTree 气泡树数据隔离；App 重启数据不丢失。
- **页面入口**：首页 Index 页面右上角，设置图标旁增加单词库图标，点击跳转到 `WordBankPage` 单词库页面。

### 预置案例单词（Harmony + OS）

首次交付时单词库预置两条案例数据，覆盖两种渲染场景：

**案例 1：Harmony（普通单词场景，fullName 为空）**

```typescript
{
  word: "Harmony",
  fullName: "",
  usPhonetic: "/ˈhɑːrməni/",
  explain: "n. 和谐，融洽"
}
```

渲染效果（不渲染全称行）：

```text
Harmony
/ˈhɑːrməni/
n. 和谐，融洽
```

**案例 2：OS（缩写场景，带全称）**

```typescript
{
  word: "OS",
  fullName: "Operating System",
  usPhonetic: "/ˈɑːpəreɪtɪŋ ˈsɪstəm/",
  explain: "n. 操作系统"
}
```

渲染效果（全部渲染）：

```text
OS
Operating System
/ˈɑːpəreɪtɪŋ ˈsɪstəm/
n. 操作系统
```

## 四、生词复习模块（AI 气泡底部表格）

- AI 回复气泡，正文渲染完成后，用一条细横线 / 虚线分隔正文和复习区域。**用户消息气泡不展示复习表格**。
- 每次 AI 消息渲染，从本地单词库**随机取出 2 条单词**，渲染横向滚动表格放在气泡底部。
- 表格属性：
  - 默认文字不自动换行
  - 支持左右横向拖拽滑动，适配超长全称 / 音标
- 表格列：`原文单词 | 全称 | 美式音标 | 中文释义`
- 单元格渲染逻辑：`fullName` 为空，该单元格不渲染空白占位。
- MVP 不实现艾宾浩斯记忆曲线，记忆曲线留到后续迭代版本。

## 五、边界约束（上半段约束）

- 划词翻译浮窗，**不会新增对话节点、不进入气泡树 DAG**，仅临时弹窗。
- MVP 不开发：单词编辑、单词搜索、批量补齐、自定义复习数量，这些属于未来迭代，本次不实现。
- **不要改动已有功能**：画布双指缩放、气泡高亮、深浅色主题、气泡树持久化等原有代码保持原样，本次只新增单词相关逻辑。

## 七、验收检查清单，编码完成后对照自测

1. 长按对话气泡，直接进入文字选择，不会弹出旧的二级弹窗；气泡删除依靠气泡左侧 × 按钮。
2. 划词选中文本，弹出悬浮栏：翻译｜复制｜全选；点击页面空白，悬浮栏消失。
3. 点击翻译弹出浮窗：渲染顺序单词→全称→音标→释义；fullName 为空，全称行直接不渲染，不能出现空白行；缩写的音标释义是全称内容。
4. 浮窗【加入单词库】保存单词；重复添加提示单词已存在；App 重启单词不会丢失。
5. AI 消息气泡底部出现分隔虚线，下方横向滚动表格展示 2 条随机生词；表格文字默认不换行，支持左右拖动；用户消息气泡没有这个表格。表格全称空的时候单元格无空白占位。
6. Index 首页右上角单词库图标，跳转单词库页面；单词库页面只有删除按钮，**没有新增单词按钮**，列表渲染遵守空全称不渲染规则。
7. 原有气泡画布、缩放、高亮、主题切换等老功能完全不受影响，不破坏原有逻辑。
