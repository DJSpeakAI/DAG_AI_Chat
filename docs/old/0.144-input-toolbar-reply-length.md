# 0.144 输入栏工具栏改版 + 回复长度功能

> 状态：**待审批**
> 日期：2026-10-02

## 一、需求背景

输入栏现有布局为 `[📷 附件] [输入框] [💬/🎙 模式] [发送]`，本次改版为：

```
[📷 图片(占位)] [输入框] [📏 回复长度] [💬/🎙 模式] [发送]
```

核心新增能力：**回复长度控制**——用户通过下拉选择短/中/长，发送时以 Prompt 约束 AI 回复的详略程度。

## 二、需求明细（用户确认版）

1. **布局改造**：在输入框与模式按钮之间新增「回复长度」下拉按钮
2. **附件按钮**：图标暂用相机 📷 占位（后续有资源再换图片图标），缩小水平 padding，不挤压输入框
3. **回复长度下拉**：
   - 三个选项：短回复 / 中回复 / 长回复，默认「中回复」
   - Prompt 约束文本：
     - 短：「你的回答尽量简短，只输出核心结论，不要多余解释，优先一句话给出答案。」
     - 中：「回答简洁完整，条理清晰，避免冗余啰嗦。」
     - 长：「回答详细完整，分点展开，深度讲解原理，尽可能把内容讲透彻。」
4. **UI 小字提示**：「输出长度为 AI 参考约束，无法保证严格固定字数」
5. **状态仅内存**：重启后恢复默认「中回复」，不持久化
6. **播客模式下拉保留**：正常对话/播客模式功能不变
7. **两个下拉独立**：长度与模式可任意组合（如「播客模式 + 长回复」）

## 三、现状分析（已 grep 定位）

| 位置 | 现状 |
|------|------|
| ChatPage 52 行 | PODCAST_PROMPT 常量 |
| ChatPage 141-142 行 | `@Local sendMode = 'normal'` + `modeDropdownOpen` |
| ChatPage 350/366 行 | sendMessage 中播客 prompt 以 **system role ChatMessage** 插入 messagesToSend |
| ChatPage 1038-1072 行 | 输入区布局（📷 1040、TextArea 1049、💬/🎙 1055、发送 1064） |
| ChatPage 1262-1299 行 | 模式下拉面板（新下拉复制其样式） |
| ApiClient buildMessages | 无 system 特殊处理，role 直接透传——**新功能无需改 ApiClient** |

关键机制：播客 prompt 的下发方式是往 `messagesToSend` 里 push 一条 `role='system'` 的 ChatMessage（366 行），不持久化、不进聊天记录显示。**回复长度 prompt 沿用同一机制**。

## 四、改动方案（仅改 ChatPage.ets）

### 4.1 新增常量（52 行 PODCAST_PROMPT 旁，同方式声明）

- `SHORT_REPLY_PROMPT` / `MEDIUM_REPLY_PROMPT` / `LONG_REPLY_PROMPT` 三条约束文本

### 4.2 新增状态变量（141-142 行旁）

- `@Local replyLengthMode: string = 'medium'`（'short' | 'medium' | 'long'）
- `@Local lengthDropdownOpen: boolean = false`

@Local 不持久化，重启自动恢复默认「中回复」，天然满足需求 5。

### 4.3 发送逻辑（sendMessage，366 行区域）

按当前 `replyLengthMode` 往 `messagesToSend` 插入对应长度 prompt（system role）：

- 组合顺序：`[...历史消息, 长度prompt(system), 播客prompt(system), user消息]`——播客风格指令贴近 user 消息
- 中回复也插入 `MEDIUM_REPLY_PROMPT`，三档逻辑统一

### 4.4 输入区布局（1038-1072 行）

- 附件按钮：图标保持 📷 占位（加注释「后续换图片图标资源」），水平 padding 缩小
- 新增 📏 回复长度按钮：位于模式按钮左侧，点击切换 `lengthDropdownOpen`
- **互斥**：打开一个下拉时自动关闭另一个，避免两个面板同时展开重叠

### 4.5 下拉面板（1262-1299 行播客面板旁，复制其结构）

- 三个选项：短回复 / 中回复 / 长回复，选中高亮逻辑与播客面板一致
- 面板下方小字：「输出长度为 AI 参考约束，无法保证严格固定字数」

## 五、不改动部分

- `sendMode` / 播客逻辑 / `PODCAST_PROMPT`（播客功能完全不动）
- ChatModel.ets / ApiClient.ets（system role 透传机制已支持，零改动）
- 持久化层（`replyLengthMode` 不进 PersistenceV2）
