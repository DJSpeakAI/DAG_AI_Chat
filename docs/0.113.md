# AI 回复显示输入/输出 Token 数 — 0.113

> 归属版本：v0.1 内部迭代

## 一、需求

每次 AI 回复完成后，在消息下方显示输入 token 和输出 token 数量。

## 二、技术方案

OpenAI 兼容 API 在流式请求中通过 `stream_options: { include_usage: true }` 返回 usage，出现在最后一个 SSE chunk 的 `usage` 字段：`{ prompt_tokens, completion_tokens, total_tokens }`。

### 改动文件

| 文件 | 改动 |
|------|------|
| `ChatModel.ets` | `ChatMessage` 新增 `@Trace inputTokens / outputTokens`；序列化/反序列化包含 |
| `ApiClient.ets` | `SSEResponse` 加 `usage` 字段；请求体加 `stream_options`；`parseSSEChunk` 提取 usage；`onDone` 签名改为 `(inputTokens, outputTokens) => void` |
| `ChatPage.ets` | `onDone` 回调存储 token 到 `aiMsg`；UI 在 assistant 消息下方显示 `输入 1234 · 输出 567` |

### 数据流

```
API SSE 最后一个 chunk → usage.prompt_tokens / completion_tokens
  → onDone(inputTokens, outputTokens)
  → aiMsg.inputTokens / outputTokens
  → UI 显示
  → serializeBubbleTree 持久化
```

### UI 样式

AI 消息文字下方，小字号灰色文字：

```
输入 1234 · 输出 567
```

- 仅 `role === 'assistant'` 且 `outputTokens > 0` 时显示
- `fontSize(11)`，灰色 `#999`（深色模式 `#888`）
- 右对齐，紧贴消息气泡下方

### 兼容性

- API 不返回 usage 时，tokens 为 0，不显示 token 行
- 不影响现有消息（反序列化时默认 0）
