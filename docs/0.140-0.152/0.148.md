# 单词库 & 知识库 页面增删改查功能 — 0.115
> 归属版本：v0.1 内部迭代
## 一、需求背景
单词库、知识库两个页面，实现基础条目管理能力：增、删、改、查；支持全字段模糊搜索、按创建日期排序；支持长按条目进入多选模式；双击条目修改内容。
> 说明：
> 1. 新增按钮放置页面右上角，和设置按钮同级，不是每个条目右侧带加号；条目右侧仅保留单条删除「×」按钮。
> 2. 多选模式仅用于批量删除，无其他批量操作。进入多选模式后顶部导航栏功能按钮替换为删除按钮。
> 3. 单条删除有特殊防误触弹窗规则；批量删除固定弹出确认提示，不提供“不再提示”选项。

## 二、功能详细定义
### 2.1 基础CRUD
1. **新增**：页面右上角放置「+」新增按钮（和设置同级），点击弹出编辑弹窗，填写内容后保存，生成新条目，自动记录createTime创建时间。
2. **单条删除**：每一行条目最右侧放置「×」删除按钮
    - 首次点击单条删除：弹出确认提醒弹窗，弹窗附带复选框选项：`本次会话内不再提示`
    - 用户勾选复选框并确认删除：当前页面会话内，后续再点击其他条目单条删除，不再弹出提醒，直接删除
    - 页面退出（返回ChatPage），再次重新进入单词库/知识库页面：该标记状态重置，再次点击单条删除，依旧弹出提醒弹窗
3. **修改**：双击条目，唤起编辑弹窗，修改当前条目内容，保存更新。
4. **查询（模糊搜索）**：顶部搜索框，对条目全部字段进行模糊匹配
    - 知识库：同时检索标题 + 正文内容；
    - 单词库：同时检索单词、音标、释义全部字段；
    - 输入关键词实时过滤条目；清空搜索框内容，列表恢复显示全部条目。

### 2.2 排序能力
- 排序字段：createTime 创建时间戳
- 支持切换：创建时间升序 / 创建时间降序；默认：最新创建条目排在列表上方（降序）

### 2.3 多选模式（仅批量删除）
1. 触发方式：长按任意条目，自动进入多选模式，条目出现复选框，支持点选多条。
2. UI变化：进入多选模式后，顶部原有功能按钮替换为批量删除按钮。
3. 操作约束：
    - 多选模式只支持批量删除，无其他批量操作。
    - 批量删除点击后固定弹出确认提醒弹窗，不提供“不再提示”选项，每次批量删除都必须确认。
    - 支持【全选 / 取消全选】。
    - 退出多选：点击页面空白处 / 取消按钮，关闭复选框状态，恢复普通浏览UI。

### 2.4 UI布局约定
1. 优先实现可用的基础布局，保证交互逻辑跑通；视觉美化、全应用统一UI风格放到后续迭代，本次迭代只保证交互逻辑、基础排版。
2. 页面右上角：`+`新增按钮，和设置按钮同一层级。
3. 列表条目：左侧文本内容，条目最右侧固定放置「×」单行删除按钮。
4. 顶部区域：搜索框 + 排序切换控件；进入多选模式时，顶部控件替换为批量删除按钮。

## 三、数据模型（简要）
单词库、知识库条目结构，共用基础字段，各自扩展专属字段
interface KnowledgeItem {
id: string; // 唯一ID
title: string; // 标题
content: string; // 主体文本内容
createTime: number; // 创建时间戳，用于排序
// 单词库额外字段：单词、音标、释义
// 知识库额外字段：分类标签
}

## 五、验收标准
1. 新增：点击页面右上角+按钮，弹出编辑弹窗，保存后新增条目，自动记录创建时间。
2. 修改：双击条目唤起编辑弹窗，修改保存后列表实时刷新。
3. 单条删除：
    - 首次点击条目右侧×，弹出确认弹窗，附带【本次会话内不再提示】复选框；
    - 勾选确认后，当前页面会话内后续单条删除不再弹窗；
    - 退出页面重新进入，重置标记，再次点击删除弹窗重新出现。
4. 模糊搜索：搜索关键词，检索条目全部字段，实时过滤；清空搜索框恢复全部条目。
5. 日期排序：可切换创建时间升序/降序，列表实时重排。
6. 多选模式：长按条目进入多选，显示复选框；顶部切换为批量删除按钮；批量删除每次都会弹出确认弹窗，无免提示选项；支持全选/取消全选，可退出多选模式。
7. 边界：无匹配搜索结果、条目全部删除时，展示空状态提示。
8. 持久化：重启App，单词库、知识库条目数据保留。

## 六、风险&约束
1. 本次迭代：多选模式仅做批量删除，不扩展其他批量操作，简化开发。
2. 单条删除的免提示标记仅保存在页面内存，会话级生效，不持久化存储，页面销毁即清空。
3. UI美化、主题细节统一放到后续迭代，本次优先保证交互逻辑完整可用。
