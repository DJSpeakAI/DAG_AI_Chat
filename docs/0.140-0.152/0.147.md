简化后的需求：画布气泡节点增强 — 0.115
归属版本：v0.1 内部迭代，不升级产品版本号
一、需求
当前画布气泡仅展示对话数字，辨识度太低。升级气泡节点 UI，本次迭代不加入分类功能，只增加气泡节点标题；保留原有长按删除、双击跳转对话页面逻辑。
二、实现方案
交互逻辑
双击气泡：保持原有逻辑，跳转对话页面。
长按气泡弹出操作菜单：仅两项【修改气泡标题】、【删除气泡】，移除分类相关选项。
气泡属性定义
msgCount：气泡内对话消息总数，系统自动统计，只读，用户不可修改。
nodeTitle 节点标题：
默认自动提取气泡内第一条用户提问，截取前 15 个汉字，超出末尾添加省略号；
暂无对话的空气泡，默认显示「空气泡」；
支持用户手动自定义修改标题，覆盖自动生成的内容。
不再新增 categoryName 字段，分类相关逻辑全部延后迭代。
气泡 UI 改造：圆形改为圆角矩形；设置最小、最大宽度限制，防止节点尺寸极端。气泡内部只展示：节点标题、消息计数。
数据持久化：nodeTitle 存入 BubbleNode，保存本地，预留后续云同步。
三、改动文件
表格
文件	改动范围
common/ChatModel.ets	BubbleNode 新增 nodeTitle 字段
components/BBTreeCanvas.ets	Canvas 气泡绘制改造：圆角矩形渲染、文本截断逻辑；长按弹窗精简
TreeFileUtil.ets	序列化 / 反序列化适配 nodeTitle 字段，save/load 兼容新属性
四、约束
标题上限 15 汉字，超出截断 + 省略号；
不调用大模型生成标题，节省 token；
原有画布拖拽、双指缩放、节点高亮逻辑保持不变；
分类、筛选功能全部延后，本版本不实现。
