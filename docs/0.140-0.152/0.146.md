对话选中文本一键入知识
归属版本：v0.1 内部迭代
一、需求背景
当前气泡对话页面支持文本划词选中，已有翻译 / 复制 / 全选 菜单。新增入知识库选项。变成翻译 / 入知识库 / 复制 / 全选 菜单
解决痛点：重度学习者在对话中遇到新概念（如Named Exports 具名导出），不用切换 App，原地快速生成知识库卡片初稿；AI 仅做提炼辅助，用户保留最终编辑权，适配知识洁癖，卡片支持后续追加图片。
二、核心业务流程
用户在气泡内划词选中一段文本，弹出悬浮菜单：翻译 | 入知识库 | 复制 | 全选
用户点击【入知识库】：将选中原文提交给大模型，附带固定强约束 Prompt
大模型仅基于选中原文提炼，禁止额外脑补、拓展举例，输出严格 JSON，固定 key
App 接收 JSON，自动填充到【知识库卡片编辑弹窗】
用户手动二次修改标题 / 定义文本，按需上传图片；确认后存入知识库。
定位：AI 生成卡片草稿，不是最终卡片，人拥有最终修改权。
三、AI 返回 JSON 固定结构（强制约束）
json
{
"title": "概念名称",
"definition": "精简定义，只从原文提炼，压缩核心描述，禁止多余铺垫、案例"
}
下发给 GLM 的固定 Prompt（代码内硬编码）
plaintext
你是卡片提炼助手，仅基于用户提供的原文生成知识库卡片。
规则：
1. 只使用原文信息，严禁增加原文不存在的内容、例子、拓展解释；
2. title填写术语/概念名称；definition写精简核心定义，压缩文字；
3. 输出严格JSON，**不要任何额外文字、注释、markdown**，只返回json字符串；
   四、知识库卡片数据模型（新增，独立于单词库）
   单词库、知识库两张独立数据表，共用同一套间隔重复调度引擎
   知识库卡片字段：
   | 字段 | 类型 | 说明 |
   | ---- | ---- | ---- |
   |id|string | 卡片唯一 id|
   |title|string | 卡片标题（概念名）|
   |definition|string | 卡片正文定义，支持 LaTeX 公式 |
   |imageUri|string|null 为无图片；存储图片本地路径 |
   |createdAt|number | 创建时间戳 |
   |reviewInfo|RepeatInfo | 间隔重复调度信息（和单词卡片复用结构）|
   五、卡片编辑弹窗功能
   两个文本输入框：标题、定义，AI 返回内容自动填充，用户可自由编辑增删
   图片区域：预留图片占位框；点击【添加图片】，唤起相册选择 / 截图导入
   无图片：占位框隐藏，不渲染图片区域
   有图片：卡片内展示缩略图；点击缩略图，打开全屏图片预览
   底部按钮：【保存入库】【取消】

   AI 只做初稿提炼，不能直接自动入库，必须经过用户编辑确认才保存。
