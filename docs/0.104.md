# 修复双指缩放 Canvas 的 4 个 Bug — 0.104

> 归属版本：v0.1 内部迭代

## 一、问题清单

| # | 现象 | 优先级 |
|---|------|--------|
| 1 | 缩放倍率太快，稍微捏合就放大/缩小过度 | P0 |
| 2 | 缩放后点击气泡无反应，gesture 失效 | P0 |
| 3 | 必须退出到 Index 重新进入才能恢复 | P0（Bug2 的后果） |
| 4 | 缩放后连接线从气泡脱落，独立移动 | P0 |

## 二、根因分析

### Bug 1 — 缩放倍率过快
```typescript
// ❌ 当前：每次 onActionUpdate 累积相乘
PinchGesture.onActionUpdate((event) => {
  this.canvasScale = this.canvasScale * event.scale;  // event.scale 是累计值！
})
```
`event.scale` 是手势开始到当前帧的**累计倍率**。每次更新都乘一次，导致指数级放大/缩小。

### Bug 2 — 缩放后 gesture 失效
```typescript
// ❌ 当前：在 Stack 容器上应用 scale + translate
Stack() { ... }
  .translate({ x: this.canvasOffsetX, y: this.canvasOffsetY })
  .scale({ x: this.canvasScale, y: this.canvasScale })
```
ArkUI 的 `.scale()` 和 `.translate()` 只改变**视觉渲染**，不改变**布局坐标**。手势（PanGesture/TapGesture）的命中检测仍在原始坐标上，导致缩放后点击坐标错位。

### Bug 4 — 连接线脱落
```
连线 position = parentX + 30 + canvasOffsetX  ← 已加 offset
Stack .translate({ x: canvasOffsetX })          ← 又加 offset

结果：连线被偏移 2 次，气泡只偏移 1 次，两者分离
```

## 三、修复方案

### 核心策略：手动坐标变换，弃用容器 scale/translate

不再在 Stack 上使用 `.scale()` 和 `.translate()`，而是对所有元素的位置做**手动坐标变换**：

```
屏幕坐标 = 画布坐标 × 缩放倍率 + 偏移量
画布坐标 = (屏幕坐标 − 偏移量) / 缩放倍率
```

### 具体改动

#### 3.1 新增坐标变换辅助方法
```typescript
// 画布坐标 → 屏幕坐标
c2sX(cx: number): number { return cx * this.canvasScale + this.canvasOffsetX; }
c2sY(cy: number): number { return cy * this.canvasScale + this.canvasOffsetY; }

// 屏幕偏移 → 画布偏移（用于拖拽）
s2cDx(dx: number): number { return dx / this.canvasScale; }
s2cDy(dy: number): number { return dy / this.canvasScale; }
```

#### 3.2 连线位置使用屏幕坐标
```typescript
getEdgeStartX(bubble) → return c2sX(bubble.parentX + pDragX + 30);
// 不再手动加 canvasOffsetX
```

#### 3.3 气泡位置使用屏幕坐标
```typescript
.position({
  x: c2sX(bubble.x + (isDragging ? dragOffsetX : 0)),
  y: c2sY(bubble.y + (isDragging ? dragOffsetY : 0))
})
```

#### 3.4 拖拽偏移量除以缩放倍率
```typescript
.onActionUpdate((event) => {
  this.dragOffsetX = s2cDx(event.offsetX);  // 屏幕像素 → 画布坐标
  this.dragOffsetY = s2cDy(event.offsetY);
})
```

#### 3.5 缩放使用起始倍率锚定
```typescript
@Local pinchStartScale: number = 1.0;

PinchGesture({ fingers: 2 })
  .onActionStart(() => { this.pinchStartScale = this.canvasScale; })
  .onActionUpdate((event) => {
    const newScale = this.pinchStartScale * event.scale;
    // 限制范围 0.3~2.0
    if (newScale >= 0.3 && newScale <= 2.0) {
      // 以捏合中心为锚点调整 offset
      const ratio = newScale / this.canvasScale;
      this.canvasOffsetX = event.pinchCenterX - (event.pinchCenterX - this.canvasOffsetX) * ratio;
      this.canvasOffsetY = event.pinchCenterY - (event.pinchCenterY - this.canvasOffsetY) * ratio;
      this.canvasScale = newScale;
    }
  })
```

#### 3.6 移除容器级 scale/translate
```typescript
Stack() { ... }
  .width('100%').height('100%')
  .backgroundColor('#FAFAFA')
  // ❌ 删除 .translate({ x, y }) 和 .scale({ x, y })
  // ✅ 画布平移手势只更新 canvasOffsetX/Y
```
