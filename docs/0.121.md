# 消息气泡Markdown渲染增强：代码块 + 表格渲染 — 0.121

归属版本：v0.1 内部迭代

## 需求

当前ChatPage消息气泡仅渲染纯文本。AI返回内容为Markdown格式，需要支持**代码块、表格**的美化排版，参考主流AI产品消息渲染效果。

AI流式返回的内容是Markdown文本，在消息气泡内自动解析并渲染：
1. Markdown 代码块 \`\`\` \`\`\`：单独代码块容器，固定等宽字体，保留换行、语法高亮基础底色，支持横向滚动（代码过长时左右滑动查看）
2. Markdown 表格 | xxx | xxx |：渲染为可视化表格，带边框，单元格自动换行，表格超出气泡宽度可横向滚动
3. 普通Markdown（换行、加粗等）保留原有渲染逻辑

## 实现方案

1. 对AI返回的Markdown文本做解析，区分普通文本、代码块、表格节点，在消息气泡内分段渲染
2. 代码块样式：
   - 使用等宽字体
   - 深色/浅色主题自动适配背景色
   - 保留代码原始换行与空格
   - 代码内容超出容器宽度时，开启横向滚动
3. Markdown表格：
   - 渲染带边框表格，表头区分样式
   - 单元格文字自动换行
   - 表格宽度溢出时支持横向滚动查看
4. 流式输出兼容：AI边输出边解析渲染，不需要等全部内容接收完成
5. 用户发送消息保持纯文本渲染，不做Markdown解析

## 改动文件

`components/ChatPage.ets` 消息气泡渲染组件

## 约束

1. 原有全部业务逻辑不动：气泡树、图片预览、输入框、持久化、Canvas画布、流式接口保持原样
2. 只改造AI消息气泡的渲染逻辑，用户消息不变
3. 跟随系统深浅色主题切换代码块、表格配色
4. 新增/修改代码添加注释，标记改动位置
5. 鸿蒙ArkUI V2
