## 新版 layoutChildren — 左右交替分叉排布

```typescript
// ★ 递归布局：子节点左右交替分叉展开（0.125）
const layoutChildren = (parent: BubbleNode, depth: number): void => {
  const children = childrenMap.get(parent.nodeID);
  if (!children || children.length === 0) return;

  const childCount = children.length;
  for (let i = 0; i < childCount; i++) {
    // 奇偶索引左右交替偏移，同级子节点不挤在一条竖线上
    const offset = (i % 2 === 0 ? -1 : 1) * (Math.floor(i / 2) + 1) * horizontalSpacing;
    children[i].x = parent.x + offset;
    children[i].y = (depth + 1) * verticalSpacing;
    layoutChildren(children[i], depth + 1);
  }
};
```

**偏移公式说明**：`i=0 → -120, i=1 → +120, i=2 → -240, i=3 → +240`，左右对称展开。

## fitViewport 顶部安全留白

```typescript
// 原：this.canvasOffsetY = 100 - minY * this.canvasScale;
// 修改：加大顶部安全留白，防止节点顶到标题栏（0.125）
const topSafePadding = 120;
this.canvasOffsetY = topSafePadding - minY * this.canvasScale;
```
