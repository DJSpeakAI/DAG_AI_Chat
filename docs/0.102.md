# 画布双指缩放功能 — 0.102

> 归属版本：v0.1 内部迭代，不升级产品版本号

## 一、需求

BBTreeCanvas 气泡画布增加双指捏合缩放，气泡 + 连线整体同步缩放。

## 二、实现方案

1. 新增 `@Local canvasScale: number = 1.0` 缩放系数
2. `PinchGesture({ fingers: 2 })` 双指捏合手势更新 canvasScale
3. 缩放范围限制：0.3 ~ 2.0，超出区间不再变化
4. 画布容器 `.scale({ x: canvasScale, y: canvasScale, centerX, centerY })` 整体缩放
5. 缩放中心：以双指捏合的手势中心点（`event.pinchCenterX/Y`）作为缩放原点
6. 气泡拖拽逻辑使用原始坐标；缩放仅影响视觉渲染，BubbleNode 节点 x/y 原始数据保持不变

## 三、改动文件

| 文件 | 改动范围 |
|------|---------|
| `components/BBTreeCanvas.ets` | 新增 canvasScale/scaleCenterX/Y 变量 + PinchGesture + 缩放容器 Stack |

## 四、约束

- 原有渲染、拖拽、点击、选中高亮、连线逻辑全部保留，禁止修改原有业务逻辑
- 不新增 Model，不改动持久化数据结构
- ChatPage 页面完全不改动
- 缩放仅视觉效果，节点 x/y 原始值不变
