# 三、活红线（非任务，开发与文案全程遵守）

1. **首版合规硬红线**：UI 禁词（社区/广场/发帖/求卡论坛→统一「需求提交/素材征集/官方卡包」）；APP 内严禁任何用户文件上传接口；用户之间零交互（不看需求/不评论/不私信/不点赞）；不做用户作品前台署名。
2. **防反推铁律（最高优先级）**：任何用户可见界面禁止出现 token 字样与钱-SP 换算关系（÷7 刻意不整除）；钱锚点否决，用学习量锚点。
3. **司忆点合规定义文本**（用户协议+IAP 商品描述+礼包弹窗小字三处同款）：「司忆点｜司忆区体系专属服务凭证，可用于 AI 对话、获取知识卡片、支持创作者。仅限本 APP 内使用，不可提现、不可转让。」兜底备选=「学习点（LP）」仅改名零重构。
4. **命名红线**：任何场合禁用「虚拟货币/币/单独使用的充值」表述；无抽奖开箱等随机性玩法；对外口径只称「司忆点/嘉奖 SP/充能 SP」，禁「赠送」字样。
5. **扣费铁律**：扣费优先级先嘉奖后充能（FIFO）；失败原路返还（逆序回填）；预估先行展示；奖励确定性（无随机）；「邀新」只给经验不给 SP；每日获取上限防刷；流水永久留痕。
6. **折扣底线**：Lv7 最低 85 折不跌破毛利保本线；调折扣前先重算毛利。
7. **通道商业判断三问**（2026-10-17 定）：本地 agent+独立外接平台+卖 token 壳——计费高于官方直采的转售通道一律不接。
