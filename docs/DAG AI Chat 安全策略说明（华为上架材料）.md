## 二、AI 功能与模型服务说明

### 2.1 AI 功能范围

本应用在以下功能场景中使用人工智能生成内容（AIGC）：

1. **AI 对话**：气泡树对话页的问答与内容生成；
2. **AI 辅助学习**：划词翻译、屏幕圈选提炼知识卡片、知识卡片生成；
3. **AI 复习辅助**：复习页的学习鼓励语、卡片内容辅助生成；
4. **AI 查询**：单词库查词释义辅助生成。

### 2.2 模型服务来源

| 项目 | 说明 |
|---|---|
| 模型服务提供方（技术支持者） | 腾讯云 TokenHub 平台接入的 DeepSeek-V4.1-Flash 模型服务 |
| 接入方式 | 应用通过 HTTPS API 调用云端模型服务，应用自身**不部署、不微调、不二次训练**模型 |
| 平台侧内容安全 | 该模型服务**内置输入/输出双向内容安全过滤**：违规请求在模型调用前后被自动拦截并返回错误；平台侧留存对话审计日志 |
| 上游模型备案信息 | 生成式人工智能服务上线备案号 / 算法备案号：【待填：向腾讯云 TokenHub 服务方索取，多个用英文逗号分隔】 |

**说明**：本应用作为生成式人工智能**服务提供者**，模型厂商为**服务技术支持者**。本应用不改变模型输出内容后单独分发，所有生成内容均按第三章、第四章机制落实安全责任与标识义务。

## 三、内容安全机制（核心章节）

本应用建立"**平台侧过滤 + 应用侧自审 + 用户举报**"三层内容安全防线：

### 3.1 第一层：平台侧内容安全（基础防线）

- 所有 AI 请求经腾讯云 TokenHub 平台，模型调用**前**对用户输入、调用**后**对模型输出进行安全过滤；
- 违规内容（涉政有害、色情低俗、暴恐、违法信息等）直接拦截，应用端收到错误并展示友好中文提示，**不向用户呈现违规内容**；
- 平台侧留存对话审计日志，满足监管追溯要求。

### 3.2 第二层：应用侧内容自审（兜底防线）

- 应用客户端内置**敏感词本地预过滤模块**：用户输入在发送前先经应用侧敏感词库初筛，命中即本地拦截并提示，减少违规请求外发；
- 应用侧对 AI 输出按会话展示，出现明显异常内容时用户可直接删除该条消息（应用内置消息删除能力）；
- 应用**不提供任何用户公开发布内容的功能**（无社区、无评论、无广场、无用户间内容分享），内容仅在用户本人设备内产生、存储与消费，传播面被结构性限制。

### 3.3 第三层：用户举报与处置

- 应用「设置 → 关于 → 反馈与联系」提供常驻反馈入口（邮箱）；
- 用户发现违规内容可随时反馈，开发者承诺**及时响应、对确认违规的功能内容予以拦截处置**；
- 应用保留日志审计能力（本地元数据：时间 / 功能类型 / 服务商 / 状态，不含对话正文），配合监管要求追溯。

### 3.4 内容红线承诺

应用在产品设计与运营中遵守以下红线：

1. 不生成、不传播法律法规禁止的内容；
2. 不提供恶意删除、篡改、伪造、隐匿 AI 生成内容标识的功能；
3. 不含"拍照搜题"等惰化中小学生思维能力的学习方法，不含违规校外培训信息；
4. 不含网络游戏链接及与教学无关的广告推送；
5. AI 生成内容不用于新闻信息服务、舆论引导等具有舆论属性或社会动员能力的场景。

## 四、AI 生成内容标识（合规硬性项）

依据《人工智能生成合成内容标识办法》（2025-09-01 施行）第四条、第五条，本应用落实**显式标识 + 隐式标识**双轨：

### 4.1 显式标识（交互界面，用户可直接感知）

应用内**所有 AI 内容出口**均以灰色小字常驻标注：**「内容由 AI 生成 · 仅供参考」**，覆盖：

| 场景 | 标识位置 |
|---|---|
| AI 对话 | 每条 AI 回复气泡底部 |
| 背单词复习 | 卡片内容下方（单词卡与知识卡统一） |
| 划词翻译入知识库 / 圈选存入知识库 | AI 提炼编辑弹窗标题下方 |
| 导入外部学习包 | 导入弹窗内提醒「导入内容可能包含 AI 生成的内容，请注意甄别」 |

> 提审时随本说明上传以上场景的**界面标识截图**。

### 4.2 隐式标识（文件元数据）

- 应用提供知识库 / 单词库**导出**功能（DagPack 格式），导出文件顶层写入标识字段 `aiNotice`：「本包内容可能包含 AI 生成的内容，请注意甄别」，并携带服务提供者编码 `origin: DAGAI`；
- 隐式标识随文件落盘、无法通过应用正常导入流程剥离，满足"导出文件含显式标识要素 + 元数据隐式标识"要求。

## 五、实名认证与使用门槛

1. 应用 AI 功能与**华为账号登录绑定**：用户发起 AI 请求前须登录华为账号（应用内置登录前置校验，未登录时弹窗引导登录后使用），依托华为账号体系完成实名核验，**应用自身不收集、不存储身份证件与生物特征信息**；
2. 用户协议与隐私政策在首次启动时以弹窗呈现，**用户明确同意后方可进入应用**（同意记录留存）；
3. 应用不提供游客免登录直接使用 AI 生成的通道。

## 六、数据安全与隐私保护

1. **本地优先**：用户数据（气泡对话、知识库、单词库、学习统计）默认存储在用户设备本地（应用沙箱），不经开发者服务器中转；
2. **可选云同步**：仅在用户主动开启时，通过华为账号云空间（境内服务）同步用户数据；同步数据与华为账号登录态绑定，用户可随时关闭；
3. **境内存储**：模型 API 调用走腾讯云境内服务，用户输入与模型输出数据存储于中华人民共和国境内；
4. **最小必要**：应用不收集手机号、身份证号、位置、通讯录等敏感个人信息；图片仅用于用户主动发起的多模态提问与知识提炼；
5. **用户控制权**：用户可随时在应用内删除任意对话、卡片、单词及全部数据；卸载应用即清除本地数据；
6. 隐私政策全文（含收集清单、存储期限、用户权利）见应用内「设置 → 关于 → 隐私政策」，与本说明一致。

## 七、未成年人保护

1. 应用定位**成人学习与知识管理工具**，内容池以用户自建知识内容与 AI 学习辅助为主；
2. 应用不设社交、直播、论坛等未成年人高风险功能场景；
3. 遵守《未成年人保护法》及学习类应用专项要求：不含违规校外培训信息、不含诱导性广告；
4. 建议监护人为未成年人使用 AI 功能提供必要指导；后续版本将评估提供青少年使用模式（内容过滤 + 时长管理）。
