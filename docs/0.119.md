# 输入框首行文字被遮挡修复 — 0.119

## 问题

动态 `height` 绑定后，第1行输入文字有半行被遮挡，看不清内容。根因：`height(24)` 单行高度不足，TextArea 内部 padding/行高导致文字被裁剪。

## 修复方案

将单行基准高度从 24vp 提高到 40vp，确保首行文字完整显示。多行时每行递增 24vp，上限5行 = 40 + 4×24 = 136vp。

公式：`baseHeight + (lines - 1) * 24`，baseHeight = 40

## 改动文件

`components/ChatPage.ets`：仅调整 `inputAreaHeight` 计算公式
