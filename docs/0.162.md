# 0.162 分支树杈 icon + 新建分支过渡动画

## 0.162.1（2026-10-03）

### 需求（用户原话要点）

1. Chat 页面左下角 ＋ 按钮 icon 会让人以为是图片添加
2. 改成分支树杈 icon，让人知道是「另起一个树杈」的意思
3. 点击后跳转新页面因刷屏过快，空消息页时用户不知道是否跳转了——做一个 0.3~0.5 秒的「页面关闭/打开」类过渡动画，让用户明确感知跳到了新的空白消息页
4. 新建 docs/0.162.md（本文件）
5. 版本号 v0.162.1

### 根因分析

探查发现 `addBubble()`（原 ChatPage.ets 1715-1742）**根本不是页面跳转**：
点击 ＋ 后是同页面切换 `currentBubbleStore` 三属性（nodeID/bubbleX/bubbleY），
消息列表由 `@Computed currentMessages` 驱动**瞬间清空重载**——
这就是「刷屏过快、空页面无感知」的根因。动画必须做在消息区内容切换上，而非导航转场。

### 动画时序（总时长 ≈ 440ms，落在 0.3~0.5s 区间）

```
点击 🌿
  ├─ 防抖检查（branchAnimating=true 期间忽略）
  ├─ 建节点入库（nodeList 追加 + saveTree + needsRelayout）+ stopTTS
  ├─ 第一段：消息区淡出 140ms（Curve.EaseIn，opacity 1→0，模拟「页面关闭」）
  │    onFinish：
  │    ├─ 切换 currentBubbleStore 三属性 + 清 inputText/pendingImages
  │    │  （列表清空/重载发生在透明态，用户看不见闪变）
  │    └─ 第二段：消息区淡入 300ms（Curve.EaseOut，opacity 0→1，模拟「页面打开」）
  │         onFinish：branchAnimating=false 解锁
```

- 淡出用 EaseIn（加速消失）、淡入用 EaseOut（减速浮现）——开关页的经典手感
- 防抖：动画播完前重复点击 🌿 直接 return，避免动画叠加/气泡连开
- `isLoading`（流式回复中）禁止新建的原防御保留，优先级在防抖之前

### 设计取舍

- **icon 用 emoji 🌿 而非资源图**：与项目现有 ✏️/🖼️/⚙/🔄/🔈 emoji icon 风格统一，
  零资源文件开销；树杈/嫩枝语义直指「另起一个树杈（新分支）」
- **动画挂 if/else 两个分支根容器**（空态 Column + 消息 List）而非外包新容器——
  不动现有布局层级，layoutWeight/justifyContent 等约束原样保留
- **切换发生在淡出完成的 onFinish 里**而非 setTimeout——无定时器竞态，页面销毁天然安全

- 真机（平板 MatePad 11.5 S）装机测试清单：
