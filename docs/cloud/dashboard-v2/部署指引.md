## 一、部署到老机器（5 步）

1. **拷贝文件**：把本目录 `server.js`、`index.html` 拷到 `E:\track-events\dashboard\`（覆盖同名旧版）。
   - `coords.json`、`screenshots/` 保留旧版不覆盖（热区标注沿用）。
   - `node_modules` 依赖沿用（`@hw-agconnect/cloud-server` 走父目录 `E:\track-events\node_modules` 向上查找，零新增依赖）。
2. **建配置**：`config.example.json` 拷为 `config.json`，改 `password`（★ 必改，默认 changeme 等于裸奔）；按需调 `spCostPer10kCny`（每 1 万 SP 对应成本 ¥，内部调参口径）。
3. **重启服务**：旧 node 进程 Ctrl+C 停掉 → `node server.js`（或沿用原启动方式）。启动日志看到 `[dash v2]` 即新版。
4. **验证口令**：浏览器开 `http://localhost:8766` → 应先出口令页 → 输入 config.json 的 password 进入。
5. **验证数据**：Tab2 出现 SP 卡片（0.260.0 装机后才有 sp_consume/sp_grant 数据，此前显示 0 是正常）；Tab4 配额条显示当日 events 行数百分比。

## 二、数据架构（口径速查）

| 项 | 说明 |
|---|---|
| 分卷 | `data/data-YYYY-MM-DD.json` 按事件 t 本地日归属；`data/state.json` 记 lastSyncT |
| 同步 | 启动全量 + 每 10 分钟增量（`>=lastT` 拉取 + `e|t` Map 去重幂等）；单轮上限 1 万条，满批自动续拉 |
| 查询 | 页面全部走内存缓存（零 Cloud DB 读）；「手动同步」按钮=立即增量 |
| 配额 | 写口径=events 当日行数 vs 2 万/天，60% 黄 80% 红（云函数 upsert 主键幂等，重试不增行） |
| 清理 | 启动时删 >90 天明细卷（汇总类指标由 Cloud DB 长期持有；日终 metrics 汇总留二期） |
| 口令 | SHA256(password+盐) 固定 token Cookie（HttpOnly 7 天），重启不掉线 |

## 三、SP 指标口径（Tab2）

- `sp_consume.p`：`{id_type:'uuid', id, sp, m, sc, f, bal, h}`——sp=实扣额（免扣=0）、bal=扣后真实余额、h=缓存命中率%、f=y 免扣账号照报（成本要真实）
- `sp_grant.p`：`{id_type, id, src, sp, bal}`——src=welcome/sign/redeem（charge/learn 待实装）
- P50/P90：分布单元=uid×自然日；余额分层取每 uid 最新 bal；¥换算=`累计SP/10000×spCostPer10kCny`

## 四、Reports API 接入（华为 AI 回复实锤 + 本机双轮实测校正，2026-10-19）

1. **凭证（关键坑）**：必须用「**开发者中心 → 开发者管理 → ID、证书和Profile → 凭证 → 开发者级凭证 → API客户端凭证 → 创建**」拿到的一套（凭证ID+密钥）。⚠️「项目设置→常规→应用信息」的 Client ID/Secret 是应用级凭证——**实测调 Reports 报 `client id or secret error`，不通**。
2. **token**：`POST https://connect-api.cloud.huawei.com/api/oauth2/v1/token`（JSON body：grant_type=client_credentials + client_id + client_secret）；48h 有效，服务端已做内存缓存。
3. **报表**：`GET https://connect-api.cloud.huawei.com/api/report/harmony-report/v1/harmony/{接口}/{appId}`，双请求头 `Authorization: Bearer {token}` + `client_id`；参数 language/startTime/endTime（UTC YYYYMMDD，窗口≤180 天）；响应 `fileURL` → 下载 CSV。已接入 `appDownloadAnalysisExport`（下载安装）+ `userAnalysisExport`（用户分析），近 30 天窗、每日自动一拉+手动按钮；CSV 落 `data/reports/`。
4. **前提**：应用**上架后**才有报表数据（未上架拉取=无 fileURL，前端有引导文案）。付费报表（Tab3）：IAP 集成+上架后走「付费下载明细」接口（AppGallery Connect 侧），二期接入。
5. 官方文档：Reports API 指南 developer.huawei.com/consumer/cn/doc/app/agc-help-report-api-guide-0000002271134669（华为 AI 提供，接入前按链接复核）。
