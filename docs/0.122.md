# 代码块自动换行按钮 + 代码清理 — 0.122

归属版本：v0.1 内部迭代

## 需求

当前 AI 回复的代码块仅支持横向滚动查看长代码。需要新增**自动换行按钮**，让用户可以切换"换行显示"和"横向滚动"两种模式。

## 方案选择

**方案 a**（已选）：在代码块上方直接加自动换行按钮，默认开启换行。

- 优点：实现简单，只需 @Local 状态 + Text 属性切换
- 交互：点击按钮切换 wrap/scroll，默认 wrap=true

方案 b（全屏代码查看器）暂不实现，复杂度高。

## 实现方案

1. 新建 `CodeBlockView` 组件（`@ComponentV2`），封装代码块渲染 + 换行按钮
2. `@Local wrap: boolean = true`，默认开启自动换行
3. 换行开启时：`Text` 自然换行，无 `Scroll`
4. 换行关闭时：`Scroll` 横向滚动（原行为）
5. 按钮样式：蓝色背景 + 边框 + 图标（↩/⇄）+ 左对齐 + 小字体
6. 深浅色主题适配
7. 每个代码块独立维护换行状态，互不影响

## 按钮样式迭代

| 迭代 | 样式 |
|------|------|
