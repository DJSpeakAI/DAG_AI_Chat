# 图片显示优化 + 全屏浏览 — 0.114

归属版本：v0.1 内部迭代

## 需求

1. 消息布局调整：图片展示放到文字上方，符合先看图后看文字的阅读习惯
2. 图片点击唤起全屏图片浏览器，支持左右滑动浏览当前对话内全部历史图片

## 改动文件：仅 ChatPage.ets

### 1. 消息内部结构调整

原有消息Column：
```
Column {
  Text(msg.content)      //文字
  Row { ForEach Image }  //图片（在下方）
  Text(token stats)
}
```

修改顺序，图片移到文字上方：
```
Column {
  Row { ForEach Image }  //图片（在上方）
  Text(msg.content)      //文字
  Text(token stats)
}
```

### 2. 新增 @Local 状态变量

```typescript
@Local imageViewerVisible: boolean = false;
@Local imageViewerIndex: number = 0;
@Local imageViewerImages: string[] = [];
```

### 3. 新增 openImageViewer(url:string) 方法

功能：遍历 this.currentBubble.messages，收集当前对话所有消息里 imageUrl，扁平化合并为图片 url 数组；找到点击图片在数组里的索引，打开全屏 viewer。
需要过滤空 url、空数组。

### 4. 图片组件增加 onClick

```typescript
Image(xxx)
  .onClick(() => {
    this.openImageViewer(url);
  })
```

### 5. 页面最外层用 Stack，叠加全屏黑色覆盖层

```
Stack {
  // 原有页面主体内容

  if (this.imageViewerVisible) {
    Stack() {
      Swiper() {
        ForEach(imageViewerImages, (url:string) => {
          Image(url)
            .objectFit(ImageFit.Contain)
            .width('100%')
            .height('100%')
        }, (url:string) => url)
      }
      .index(this.imageViewerIndex)
      .indicator(true)
      .backgroundColor(Color.Black)

      // 右上角关闭按钮
      Button('×')
        .position({x: 20, y: 20})
        .onClick(() => { this.imageViewerVisible = false })
    }
    .width('100%')
    .height('100%')
    .backgroundColor(Color.Black)
    // 点击黑色背景也关闭浏览器
    .onClick(() => { this.imageViewerVisible = false })
  }
}
```

## 交互规则

1. Swiper 左右滑动切换图片，开启页码指示器
2. 关闭方式：右上角 × 按钮 / 点击黑色背景
3. 没有图片时，不会唤起 viewer
4. 支持远程 URL、base64 格式图片，Image 组件正常渲染

## 兼容性 & 边界

1. 过滤空图片地址，避免 Swiper 渲染异常条目
2. 不改动 ChatModel、BubbleTree、ApiClient，原有 token 展示、消息持久化逻辑保持不变
3. AI 消息、用户消息里的图片都支持点击全屏查看
