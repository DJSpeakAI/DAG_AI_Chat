# 修复退出对话页面崩溃 — 0.111

> 归属版本：v0.1 内部迭代

## 一、问题

从对话页面返回气泡节点页面时 app 崩溃。

## 二、根因

`aboutToDisappear` 中调用 `this.scroller.currentOffset()` 时，List 组件正在销毁，Scroller 已失效，抛出异常导致崩溃。

```typescript
// 当前代码（0.110）
aboutToDisappear() {
  ...
  if (this.currentBubble) {
    this.currentBubble.scrollOffset = this.scroller.currentOffset().yOffset; // ← 崩溃点
    this.persistData.bubbleTreeJson = serializeBubbleTree(this.store);
  }
}
```

## 三、修复

用 `try-catch` 包裹滚动位置保存，组件销毁时 Scroller 失效不致命：

```typescript
aboutToDisappear() {
  ...
  try {
    if (this.currentBubble) {
      this.currentBubble.scrollOffset = this.scroller.currentOffset().yOffset;
      this.persistData.bubbleTreeJson = serializeBubbleTree(this.store);
    }
  } catch (e) {
    // Scroller 已失效，跳过滚动位置保存
  }
}
```

仅改 `ChatPage.ets` 一个方法。
