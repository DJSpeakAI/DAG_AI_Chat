# 修复：按钮点击无响应 + 箭头尺寸过小 — 0.123fix6

归属版本：0.123 内部修复

## 改动文件

`components/BBTreeCanvas.ets` — 仅两处代码

## 改动 1：自动排版按钮

**删除**：外层 `Row`、`Blank`、`.width('100%')`、`.hitTestBehavior(HitTestMode.Transparent)`、`.onClick()`

**替换为**：`Text` 直接使用 `.position({ x: 260, y: 10 })` 绝对定位右上角 + `.gesture(TapGesture().onAction(...))` 走手势管线

```typescript
// ★ 右上角悬浮【自动排版】按钮（0.123fix6：TapGesture 手势管线，与气泡交互一致）
Text('自动排版')
  .fontSize(14)
  .fontColor(this.getThemeStore().isDark ? '#FFFFFF' : '#333333')
  .padding({ left: 12, right: 12, top: 6, bottom: 6 })
  .borderRadius(8)
  .backgroundColor(this.getThemeStore().isDark ? '#333333' : '#FFFFFF')
  .border({ width: 1, color: this.getThemeStore().isDark ? '#555555' : '#DDDDDD' })
  .shadow({ radius: 4, color: 'rgba(0,0,0,0.2)', offsetX: 0, offsetY: 2 })
  .position({ x: 260, y: 10 })
  .gesture(
    TapGesture()
      .onAction(() => {
        this.autoLayout();
      })
  )
```
