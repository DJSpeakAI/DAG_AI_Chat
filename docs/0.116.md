# 0.116 bug 修复：选择文本功能不能用

## 问题

点击"选择文本"后，无法框选消息文字。

## 根因分析

两个问题叠加：

1. **手势冲突**：消息 Row 绑定了 `LongPressGesture`，而 ArkUI Text 的原生文本选择也依赖长按手势。父组件的 `LongPressGesture` 拦截了长按事件，Text 的选择功能无法触发。
2. **动态属性不生效**：`textSelectable()` 在组件创建时求值，运行时动态切换 `TextSelectableMode` 可能不会重新生效。

## 修复方案

**改用文本预览弹窗**：点击"选择文本"后，弹出独立弹窗，内含只读 `TextArea` 展示该消息全文。`TextArea` 原生支持文本选择 + 复制，无手势冲突。

### 具体改动

1. 新增 `@Local textPreviewVisible: boolean = false` + `@Local textPreviewContent: string = ''`
2. "选择文本"按钮 onClick：设 `textPreviewContent` 为消息内容，`textPreviewVisible = true`，关闭菜单
3. 新增文本预览弹窗：全屏遮罩 + 居中卡片，卡片内放只读 `TextArea`（`enabled(false)` 保持可选但不可编辑）+ 关闭按钮
4. 移除 Text 组件上的动态 `.textSelectable()` 行（不再需要）
5. 移除 `@Local selectableMessageId`（不再需要）
