# V1 → V2 全量迁移 — 0.14（修订版）

## 一、当前状态：100% V1

| 文件 | 装饰器 |
|------|--------|
| Index.ets | `@Entry` `@Component` `@State` |
| BBTreeCanvas.ets | `@Component` `@State` `@StorageLink` |
| ChatPage.ets | `@Component` `@State` `@StorageLink` `$$` |
| ChatNode.ets | `interface`（无装饰器） |

SDK: `compatibleSdkVersion: "6.1.1(24)"` (API 14)，支持 V2。

## 二、V1 → V2 装饰器对照

| V1 | V2 | 说明 |
|----|-----|------|
| `@Component` | `@ComponentV2` | 组件声明 |
| `@State` | `@Local` | 组件内部状态 |
| `@StorageLink` | `@StorageLink` | V2 仍存在，配合 `@ObservedV2` + `@Trace` 深度观测 |
| `interface` | `@ObservedV2 class` + `@Trace` | 数据模型必须改为 class |
| 无 | `@Param` | V2 父→子参数传递 |
| 无 | `@Computed` | V2 计算属性，自动响应式 |
| `$$` | `$$` | ✅ **官方确认支持 `@Local`** |

### $$ 兼容性确认

> 官方文档：*"当前 `$$` 支持基础类型变量，当该变量使用 `@State`、`@Link`、`@Prop`、`@Provide` 等 V1 装饰器，**或者 `@Local` 等 V2 装饰器**时，变量值的变化会触发 UI 刷新。"*

**结论：`$$this.inputText` 在 `@Local` 下完全可用，所有文件可全量迁移 V2。**

### 3.1 ChatNode.ets — interface → @ObservedV2 class

```typescript
export type ChatRole = 'user' | 'AI';

@ObservedV2
export class ChatMessage {
  @Trace messageId: string;
  @Trace role: ChatRole;
  @Trace content: string;

  constructor(messageId: string, role: ChatRole, content: string) {
    this.messageId = messageId;
    this.role = role;
    this.content = content;
  }
}

@ObservedV2
export class BubbleNode {
  @Trace nodeId: string;
  @Trace parentId: string | null;
  @Trace messages: ChatMessage[];
  @Trace x: number;
  @Trace y: number;

  constructor(nodeId: string, parentId: string | null, messages: ChatMessage[], x: number, y: number) {
    this.nodeId = nodeId;
    this.parentId = parentId;
    this.messages = messages;
    this.x = x;
    this.y = y;
  }
}
```

### 3.2 BBTreeCanvas.ets — 全量 V2

```typescript
import { BubbleNode } from '../common/ChatNode';

@ComponentV2
export struct BBTreeCanvas {
  @Param pathStack: NavPathStack = new NavPathStack();
  @StorageLink('nodeList') bubbleList: BubbleNode[] = [];
  @Local dragBubbleId: string = '';
  @Local dragOffsetX: number = 0;
  @Local dragOffsetY: number = 0;
  @Local isDragging: boolean = false;
  @Local canvasOffsetX: number = 0;
  @Local canvasOffsetY: number = 0;
  @Local canvasPanStartX: number = 0;
  @Local canvasPanStartY: number = 0;

  build() {
    NavDestination() {
      Stack({ alignContent: Alignment.TopStart }) {
        Stack({ alignContent: Alignment.TopStart }) {
          // 1. 连线 — Path 组件
          ForEach(this.bubbleList.filter(b => b.parentId !== null), (bubble: BubbleNode) => {
            ForEach(this.bubbleList.filter(p => p.nodeId === bubble.parentId), (parent: BubbleNode) => {
              Path()
                .commands(`M${parent.x + 30} ${parent.y + 30} L${bubble.x + 30} ${bubble.y + 30}`)
                .stroke('#CCCCCC')
                .strokeWidth(2)
                .fillOpacity(0)
                .width('100%')
                .height('100%')
            }, (parent: BubbleNode) => parent.nodeId)
          }, (bubble: BubbleNode) => bubble.nodeId)

          // 2. 气泡 — ForEach key 只用 nodeID，@Trace 自动追踪 x/y/messages
          ForEach(this.bubbleList, (bubble: BubbleNode) => {
            Column() {
              Text(`${bubble.messages.length}`)
                .fontSize(20)
                .fontColor('#FFFFFF')
                .width(60)
                .height(60)
                .borderRadius(30)
                .backgroundColor('#1976D2')
                .textAlign(TextAlign.Center)
            }
            .position({
              x: bubble.x + (bubble.nodeId === this.dragBubbleId ? this.dragOffsetX : 0),
              y: bubble.y + (bubble.nodeId === this.dragBubbleId ? this.dragOffsetY : 0)
            })
            .gesture(
              PanGesture({ distance: 5 })
                .onActionStart(() => {
                  this.dragBubbleId = bubble.nodeId;
                  this.dragOffsetX = 0;
                  this.dragOffsetY = 0;
                  this.isDragging = true;
                })
                .onActionUpdate((event: GestureEvent) => {
                  this.dragOffsetX = event.offsetX;
                  this.dragOffsetY = event.offsetY;
                })
                .onActionEnd(() => {
                  // ✅ V2：直接修改 @Trace 属性，不需要 map 创建新数组
                  const bubble = this.bubbleList.find(b => b.nodeId === this.dragBubbleId);
                  if (bubble) {
                    bubble.x = Math.max(0, bubble.x + this.dragOffsetX);
                    bubble.y = Math.max(0, bubble.y + this.dragOffsetY);
                  }
                  this.dragBubbleId = '';
                  this.dragOffsetX = 0;
                  this.dragOffsetY = 0;
                  setTimeout(() => { this.isDragging = false; }, 200);
                })
            )
            .gesture(
              TapGesture({ count: 2 })
                .onAction(() => {
                  if (this.isDragging) { return; }
                  AppStorage.setOrCreate('currentBubbleId', bubble.nodeId);
                  this.pathStack.pushPath({ name: 'ChatPage' });
                })
            )
          }, (bubble: BubbleNode) => bubble.nodeId)
        }
        .width('100%')
        .height('100%')
        .translate({ x: this.canvasOffsetX, y: this.canvasOffsetY })
      }
      .width('100%')
      .height('100%')
      .backgroundColor('#FAFAFA')
      .gesture(
        PanGesture({ distance: 5 })
          .onActionStart(() => {
            this.canvasPanStartX = this.canvasOffsetX;
            this.canvasPanStartY = this.canvasOffsetY;
          })
          .onActionUpdate((event: GestureEvent) => {
            this.canvasOffsetX = this.canvasPanStartX + event.offsetX;
            this.canvasOffsetY = this.canvasPanStartY + event.offsetY;
          })
      )
    }
    .title('气泡树')
  }
}
```

**V2 关键变化**：
- `@Component` → `@ComponentV2`，`@State` → `@Local`，`@Param` 声明 pathStack
- ForEach key 简化：`nodeId`（`@Trace` 自动追踪属性变化）
- `onActionEnd` 直接 `bubble.x = ...`，不需要 `map` 新数组

### 3.3 ChatPage.ets — 全量 V2

```typescript
import { BubbleNode, ChatMessage, generateMessageId, generateNodeId } from '../common/ChatNode';

@ComponentV2
export struct ChatPage {
  @Param pathStack: NavPathStack = new NavPathStack();
  @StorageLink('nodeList') bubbleList: BubbleNode[] = [];
  @Local inputText: string = '';
  @Local currentBubbleId: string = '';
  private scroller: Scroller = new Scroller();

  aboutToAppear() {
    this.currentBubbleId = AppStorage.get<string>('currentBubbleId') ?? '';
  }

  // ✅ V2 @Computed：自动响应式，不需要手动同步 currentMessages
  @Computed
  get currentBubble(): BubbleNode | undefined {
    return this.bubbleList.find(b => b.nodeId === this.currentBubbleId);
  }

  // ✅ V2 @Computed：messages 直接从 bubble 读取，@Trace 自动追踪
  @Computed
  get currentMessages(): ChatMessage[] {
    return this.currentBubble?.messages ?? [];
  }

  sendMessage(): void {
    if (!this.inputText.trim() || !this.currentBubble) {
      return;
    }
    const userMsg = new ChatMessage(generateMessageId(), 'user', this.inputText);
    const aiMsg = new ChatMessage(generateMessageId(), 'AI', '1');
    // ✅ V2：直接替换 messages 数组，@Trace 触发刷新
    this.currentBubble.messages = [...this.currentBubble.messages, userMsg, aiMsg];
    this.inputText = '';
    this.scroller.scrollToIndex(this.currentMessages.length - 1);
  }

  deleteMessage(messageId: string): void {
    if (!this.currentBubble) { return; }
    this.currentBubble.messages = this.currentBubble.messages.filter(m => m.messageId !== messageId);
  }

  addBubble(): void {
    if (!this.currentBubble) { return; }
    const newBubble = new BubbleNode(
      generateNodeId(), this.currentBubbleId, [],
      this.currentBubble.x + 80 + Math.floor(Math.random() * 40),
      this.currentBubble.y + 80 + Math.floor(Math.random() * 40)
    );
    this.bubbleList = [...this.bubbleList, newBubble];
    this.pathStack.pop();
  }

  build() {
    NavDestination() {
      Column() {
        // 顶栏
        Row() {
          Blank().layoutWeight(1)
          Button('＋ 添加子气泡')
            .fontSize(14)
            .backgroundColor('#1976D2')
            .fontColor('#FFFFFF')
            .onClick(() => { this.addBubble(); })
        }
        .width('100%')
        .padding({ left: 16, right: 16, top: 8, bottom: 4 })

        // 消息列表 — 直接用 @Computed currentMessages
        if (this.currentMessages.length === 0) {
          Column() {
            Text('暂无对话')
              .fontSize(16)
              .fontColor('#999999')
          }
          .width('100%')
          .layoutWeight(1)
          .justifyContent(FlexAlign.Center)
        } else {
          List({ space: 12, scroller: this.scroller }) {
            ForEach(this.currentMessages, (msg: ChatMessage) => {
              ListItem() {
                Row() {
                  Text(msg.content)
                    .fontSize(14)
                    .fontColor(msg.role === 'user' ? '#1976D2' : '#616161')
                    .padding(10)
                    .borderRadius(8)
                    .backgroundColor(msg.role === 'user' ? '#E3F2FD' : '#F5F5F5')
                  Button('×')
                    .fontSize(16)
                    .fontColor('#F44336')
                    .backgroundColor(Color.Transparent)
                    .onClick(() => { this.deleteMessage(msg.messageId); })
                }
                .width('100%')
                .justifyContent(msg.role === 'user' ? FlexAlign.Start : FlexAlign.End)
              }
            }, (msg: ChatMessage) => msg.messageId)
          }
          .layoutWeight(1)
          .width('100%')
          .padding({ left: 16, right: 16, top: 12 })
        }

        // 输入区域 — $$ + @Local 官方确认支持
        Row() {
          TextInput({ text: $$this.inputText, placeholder: '输入问题...' })
            .layoutWeight(1)
          Button('发送')
            .margin({ left: 8 })
            .onClick(() => { this.sendMessage(); })
        }
        .width('100%')
        .padding({ left: 16, right: 16, bottom: 16 })
      }
      .width('100%')
      .height('100%')
    }
    .title('对话')
  }
}
```

**V2 关键变化**：
- `@Component` → `@ComponentV2`，`@State` → `@Local`，`@Param` 声明 pathStack
- `@Computed` 替代 `currentMessages` 变量 + `syncMessages()` + `getCurrentBubble()` — 全部删除
- `sendMessage` 直接 `this.currentBubble.messages = [...]`，`@Trace` 触发刷新
- `$$this.inputText` + `@Local` — 官方确认支持
- 对象字面量 → `new ChatMessage(...)` / `new BubbleNode(...)`

```typescript
import { BBTreeCanvas } from '../components/BBTreeCanvas';
import { ChatPage } from '../components/ChatPage';
import { BubbleNode, ChatMessage, generateNodeId, generateMessageId } from '../common/ChatNode';

@Entry
@ComponentV2
struct Index {
  pathStack: NavPathStack = new NavPathStack();

  aboutToAppear() {
    const rootId = generateNodeId();
    const rootBubble = new BubbleNode(rootId, null, [
      new ChatMessage(generateMessageId(), 'user', '你好'),
      new ChatMessage(generateMessageId(), 'AI', '1')
    ], 200, 200);
    AppStorage.setOrCreate('nodeList', [rootBubble]);
  }

  @Builder
  pageMap(name: string) {
    if (name === 'BBTreeCanvas') {
      BBTreeCanvas({ pathStack: this.pathStack })
    } else if (name === 'ChatPage') {
      ChatPage({ pathStack: this.pathStack })
    }
  }

  build() {
    Navigation(this.pathStack) {
      Column() {
        Button('进入气泡树')
          .onClick(() => {
            this.pathStack.pushPath({ name: 'BBTreeCanvas' });
          })
      }
      .width('100%')
      .height('100%')
      .justifyContent(FlexAlign.Center)
    }
    .mode(NavigationMode.Stack)
    .navDestination(this.pageMap)
  }
}
```

- `@Component` → `@ComponentV2`，`@State` 去掉（pathStack 不需要响应式）

## 四、迁移收益

| 方面 | V1 (当前) | V2 (迁移后) |
|------|-----------|-------------|
| ForEach key | `${nodeId}_${x}_${y}_${msg.length}` | `nodeId` |
| 拖拽提交 | `map` 新数组 O(n) | `bubble.x = ...` O(1) |
| 消息更新 | 手动 `currentMessages` + `syncMessages()` | `@Computed` 自动计算 |
| 响应粒度 | 对象级整体刷新 | 字段级精准刷新 |
| 数据模型 | `interface` 无追踪 | `@ObservedV2` + `@Trace` |
| 参数传递 | 隐式 | `@Param` 显式声明 |
| 代码量 | 多（手动同步） | 少（自动响应式） |

## 五、删除的 V1 代码

| 删除项 | 替代 |
|--------|------|
| `@State currentMessages` | `@Computed get currentMessages()` |
| `syncMessages()` 方法 | `@Computed` 自动计算 |
| `getCurrentBubble()` 方法 | `@Computed get currentBubble()` |
| `onBubbleListChange()` / `@Watch` | `@Computed` 自动响应 |
| `map` 创建新数组 | 直接修改 `@Trace` 属性 |
| 复杂 ForEach key | 简单 `nodeId` key |
