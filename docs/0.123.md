# Canvas画布UI增强：父子连线箭头 + 一键纵向自动排版 — 0.123

归属版本：v0.1 内部迭代

## 需求

基于现有BBTreeCanvas气泡画布（已完成MVP基础能力、节点拖拽、双指缩放、选中气泡高亮）做增强：

1. 父子连线增加方向箭头，从父节点指向子节点，直观区分父子关系；跟随画布双指缩放同步缩放，普通连线浅灰色，选中分支连线使用橙色高亮。气泡增加圆角、阴影样式，适配系统深浅色主题。
2. 在画布**右上角增加悬浮【自动排版】按钮**。
3. 排版规则：**纵向树形布局（根节点在上，子节点向下展开）**
    > 核心约束：**不能丢弃用户已经手动拖拽调整过位置的气泡节点坐标**
    - 自动排版算法：仅对**未被用户手动拖拽过**的节点，自动计算、更新x/y坐标
    - 用户手动拖拽过的节点：坐标保持固定不动，不受自动排版影响
    - 同层级节点保持统一纵向高度，节点之间预留间距，避免节点互相重叠
    - 排版计算完成后，画布自动调整视口，让整棵树完整展示在当前可视区域
    - 排版完成后，依旧保留原有拖拽、双指缩放、节点选中高亮全部能力
4. 原有画布能力保留：气泡拖拽、双指捏合缩放、节点选中橙色高亮、DAG树渲染逻辑全部不变。

## 实现方案

1. **连线箭头绘制**：Canvas绘制线段末端增加三角形箭头，箭头方向由父节点指向子节点；缩放时箭头大小同步跟随scale；区分普通连线/选中分支连线颜色。
2. **数据模型补充**：BubbleNode增加布尔标记字段 `isUserDragged: boolean`，默认false；**当用户完成拖拽动作onActionEnd时，设置isUserDragged = true**，用来标记该节点是人工手动摆放。
3. **自动排版逻辑**：
    - 布局方向：纵向树形布局，根节点放置在上层，子节点向下展开
    - 遍历整棵气泡树，只处理 `isUserDragged === false` 的节点，自动分配坐标
    - `isUserDragged === true` 的节点，直接跳过，坐标不改动，保留用户手动拖拽位置
    - 布局计算逻辑放在TS业务层，**不要写在Canvas onDraw渲染回调里面**，防止画布渲染卡顿
4. **右上角悬浮【自动排版】按钮**，叠加在画布上层（非Canvas绘制文字），按钮样式适配深浅色主题，点击触发布局计算，更新节点坐标并触发画布重绘。

## 改动文件

- `components/BBTreeCanvas.ets` — 箭头绘制 + 自动排版按钮 + 排版算法 + 气泡样式增强
- `common/ChatModel.ets` — BubbleNode 新增 `@Trace isUserDragged: boolean` 字段

## 约束

1. 其余业务代码完全不动：ChatPage、消息渲染、Markdown代码表格、输入框、图片预览、持久化逻辑保持原样。
2. ArkUI V2 @ObservedV2 结构体，新增字段添加 `@Trace`。
3. 新增/修改代码添加注释，标记改动位置。
4. 排版仅修改节点x/y坐标，**不修改nodeID、父子关联等业务数据**。
