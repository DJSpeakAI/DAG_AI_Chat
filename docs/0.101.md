# 画布选中气泡高亮标记 — 0.101

> 归属版本：v0.1 内部迭代，不升级产品版本号

## 一、需求

画布页面（BBTreeCanvas）高亮标记当前选中气泡节点，从 ChatPage 返回画布时快速定位。

## 二、实现方案

- 复用全局状态 `currentBubbleStore.nodeID`
- 气泡渲染时判断 `bubble.nodeID === currentBubbleStore.nodeID`
- 命中：加粗边框 `width: 3, color: '#FF6600'`（橙色高亮）
- 未命中：边框 `width: 0`（不可见，保持原样）
- 响应式自动生效，切换节点自动重绘
