# 消息气泡跟随系统深浅色主题 — 0.103

> 归属版本：v0.1 内部迭代，不升级产品版本号

## 一、需求

ChatPage 对话页面消息气泡文字、背景色跟随系统深浅色模式切换，参考千问风格：深色模式下黑底白字；浅色模式白底黑字。系统切换深色/浅色，APP 实时自动刷新 UI。

## 二、实现方案

1. `ThemeStore`（`@ObservedV2`）全局 UI 状态类，`@Trace isDark: boolean`，通过 `AppStorageV2.connect` 共享
2. `EntryAbility.onConfigurationUpdate` 监听系统主题变化，实时更新 `ThemeStore.isDark`
3. `EntryAbility.onWindowStageCreate` 初始化时通过 `this.context.config.colorMode` 读取当前系统主题
4. ChatPage 气泡样式分支：
   - 深色模式：AI 气泡 `#1E1E1E` 黑底 `#FFFFFF` 白字；用户气泡 `#0D47A1` 深蓝底 `#FFFFFF` 白字
   - 浅色模式：AI 气泡 `#F5F5F5` 浅灰底 `#616161` 深字；用户气泡 `#E3F2FD` 浅蓝底 `#1976D2` 蓝字

## 三、改动文件

| 文件 | 改动范围 |
|------|---------|
| `entryability/EntryAbility.ets` | 新增 `ThemeStore` 类 + `onConfigurationUpdate` 监听 + 初始化 colorMode |
| `components/ChatPage.ets` | 导入 `ThemeStore`，气泡 `fontColor` / `backgroundColor` 增加深浅色三元分支 |

## 四、约束

- 原有消息渲染、流式对话、图片预览、加载/错误气泡逻辑全部保留
- BBTreeCanvas 画布页面本次不做主题适配，保持原样
- 持久化、ApiClient、TreeFileUtil 全部不改动
- 切换系统深浅色，页面无需重启，实时自动刷新 UI
