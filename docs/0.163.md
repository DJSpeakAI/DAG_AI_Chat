# 0.163 代码块按钮去文字纯 icon 化

## 0.163.1（2026-10-03）

### 需求（用户原话要点）

1. 代码框上面的按钮太难看——取消文字，留下左边的 icon（意思已经很明显不需要加文字）
2. 整齐排列
3. 新建 docs/0.163.md（本文件）
4. 版本号 v0.163.1

### 改造前状态

代码块顶部按钮栏为「icon + 文字」组合（⧉ 复制 / ↩⇄ 自动换行·横向滚动 / ⤢ 放大），
文字长短不一（2 字 / 4 字 / 2 字）导致按钮宽窄不齐、视觉杂乱。
全项目共 **6 处**同款按钮（探查定位，全部同步改造保持视觉统一）：

| # | 位置 | 按钮 |
|---|------|------|
| 1 | CodeBlockView 顶部栏 | ⧉ 复制 |
| 2 | CodeBlockView 顶部栏 | ↩/⇄ 自动换行/横向滚动 |
| 3 | CodeBlockView 顶部栏 | ⤢ 放大 |
| 4 | 表格块左上角 | ⤢ 放大 |
| 5 | 代码放大弹窗标题行 | ↩/⇄ 自动换行/横向滚动 |
| 6 | 表格放大弹窗标题行 | ↩/⇄ 换行/不换行 |

### 改动清单（ChatPage.ets / Index.ets）

1. **6 处按钮全部去文字留纯 icon**：删除文字 Text（复制/自动换行/横向滚动/放大/换行/不换行），
   icon 保留并放大 fontSize 11 → 13（去文字后更清晰易点）
2. **整齐排列**：固定尺寸 `.width(24).height(22)` + `.justifyContent(FlexAlign.Center)`
   + `.alignItems(VerticalAlign.Center)`——6 处完全同款，icon 居中；
   弃用原 padding 自适应（文字长短导致的宽窄不齐根除）
3. **间距统一**：CodeBlockView 三键统一 `margin right 6`（原复制 right 6 / 换行无 / 放大 left 6 的
   混排改为统一右距）
4. **视觉风格不变**：borderRadius 4、深浅色底色（#1E3A5F/#E3F2FD）、边框（#3D5A80/#90CAF9）、
   icon 蓝（#7AB8FF/#1976D2）全部保留
5. **语言标签保留**：python/text/plaintext 标签不在改造范围（非按钮）
6. Index.ets 版本号 v0.162.1 → v0.163.1

### 设计取舍

- **icon 语义自明**（用户判断）：⧉=复制、↩/⇄=换行模式切换（动态切换保留）、⤢=放大
- **24×22 紧凑尺寸**：符合用户「图标按钮紧凑（宁可图标缩小）」的一贯偏好；
  与原带文字按钮高度（≈21vp）接近，不撑高代码块
- **6 处同步改造**：表格放大键、两个放大弹窗换行键虽非用户截图主诉，
  但属同款按钮——只改代码块三键会造成「一处纯 icon 一处带文字」的割裂，
  按项目「同类模块视觉统一」原则一并处理
