# 0.165 版本线：云同步（多设备共享数据）

> 目标：登录同一华为账号的多设备（畅享 90 Pro Max + MatePad 11.5 S 活力版）间同步对话树数据。
> 技术路线：**端云数据同步**（ArkData RDB + cloudSync，数据存华为云空间）。

---

## 一、方案选型

| 候选方案 | 结论 |
|---|---|
| **端云数据同步（ArkData RDB + cloudSync）** | ✅ **选定** |
| Cloud DB（对象型数据库）直连 | ❌ 需要自建云端对象类型映射、手动 CRUD 同步逻辑，开发量大 |
| 自建服务器 + REST API | ❌ 违背「本地免费离线可用」定位，服务器成本高 |

**选定理由**：
1. **本地优先**：数据先写本地 RDB，离线完全可用，联网后框架自动双向同步——与产品定位（本地功能永久免费离线可用）天然契合
2. **零服务器成本**：数据存华为云空间（用户自己的云空间配额），开发者免基础设施
3. **多端自动一致**：登录同一华为账号的设备自动同步，正是用户需求本身
4. **隐私保护**：支持端侧加密字段（Encrypted String），数据仅本人可访问
5. **版本满足**：要求 HarmonyOS ≥ 6.1.0 + 云空间 ≥ 6.3.0，项目 compatibleSdkVersion 6.1.1(24) ✅，两台测试设备均满足

**官方约束（重要）**：
- 仅支持中国大陆地区
- 同步触发频率过高会被云端限流——只对用户操作触发的数据启用（对话数据是离散用户操作 ✅）
- **本地表主键须唯一（禁自增）、表列只能新增不能修改删除**（SQLite 端云同步硬约束）
- **本地表字段禁设 NOT NULL**（云端字段默认允许为空）
- debug 证书连**开发环境**，release 证书连**生产环境**——当前 debug 签名正好连开发环境调测
- 开发环境配置「实施变更到生产环境」后**不可撤回、不可改删、仅可增加**——上生产前必须充分调测

## 二、数据模型：快照行模式（key-value 表）

### 2.1 为什么不拆节点表

BubbleNode.messages 是嵌套结构，节点级拆表（Bubble 表 + Message 表）需处理外键、消息顺序、级联删除，且现有 PersistenceV2 数据流是**整树 JSON 序列化**（serializeBubbleTree 已稳定运行 16 个版本），拆表 = 重写全部持久化逻辑，风险高收益低。

**快照行模式**：每个数据池 = 一行记录，value 存整池 JSON。复用现有序列化函数，持久化点只加一行 RDB 写入。

- 多端冲突：行级 last-write-wins（updated_at 裁决），单用户多设备场景可接受（一人不会同时在两台设备编辑）
- 同步粒度：一次树变更 = 该池一行 upsert，autoSync 自动上云。对话树典型体量（百节点 × KB 级消息）单次同步几十~几百 KB，频率为离散用户操作，限流风险低
- 未来演进：RDB 表列只能加不能删，快照模式不影响后续拆表升级

### 2.2 表结构（本地表名 = 云侧数据类型名 = `cloud_data`）

| 字段 | 类型 | 说明 |
|---|---|---|
| key | TEXT | **主键**（云侧「端侧去重主键」须勾选此字段） |
| value | TEXT | 整池 JSON（云侧配置为 **Encrypted String** 加密字段，对话数据属隐私数据） |
| updated_at | INTEGER | 最近更新时间戳（毫秒，多端裁决参考） |

### 2.3 行设计（key 命名）

| key | value 内容 | 对应现有持久化 |
|---|---|---|
| `flat_pool` | 平铺池全部树 JSON | PersistData.bubbleTreeJson |
| `tabs_pool` | Tab 池全部 Tab 元数据+树 JSON | TabForestStore.tabsJson |
| （预留）`word_book` | 单词库数据 | 后续版本 |
| （预留）`knowledge_base` | 知识库数据 | 后续版本 |

> 0.151 互通设计：当前模式的池是权威数据源。RDB 只写权威池的行（与现有 if/else 持久化分支一一对应），另一池行在模式切换重建后写入。

### 2.4 RDB 库

- 库名：`dag_chat_cloud.db` → **AGC 容器名必须为 `dag_chat_cloud`**（大小写一致，无后缀）
- securityLevel: S1（对话数据非高敏，S1 即可上云；S4 不能同步）
- autoCleanDirtyData: false（保留脏数据供 cleanDirtyData 增量处理）

## 三、AGC 云侧操作步骤（用户手动操作）

1. **进入云同步服务**：登录 [AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html) → 「开发与服务」→「我的项目」→ 选项目 → 选应用 `dag_ai_chat` → 在 **API 管理**（或开放能力管理）启用 **「云空间」** → 点左下角「全部功能」→「构建 > 云空间服务」→ 点固定按钮钉到左侧导航树
2. **创建容器**：云同步服务主页面 → 「创建容器」→ 容器名称填 **`dag_chat_cloud`**（必须与本地 RDB 库名一致）
3. **配置数据类型**（⚠️ AGC 实测新界面与官方文档有差异，以下为实测可行配置）：
   - **数据类型名称填 `cloudData`**（驼峰）——该输入框命名约束「仅允许包含字母、数字、且以字母开头」，**不允许下划线**，`cloud_data` 会被拦
   - 展开**「高级设置」→「本地表名称」填 `cloud_data`**——AGC 新界面把云端类型名与本地表名拆成两个独立字段，此字段承接映射，必须与端侧 RDB 表名一字不差；**端侧代码无需改动**
   - 字段：`key`：String / `value`：String（若类型下拉有 **Encrypted String** 选项则选它实现加密；实测新界面「高级设置」仅有「可检索」「可排序」，无加密勾选框，保持 String 不影响同步功能）/ `updated_at`：Integer（字段名允许下划线，仅「数据类型名称」输入框受限）
   - **「高级设置」→「端侧去重主键」→ 勾选 `key`**（本地主键必须勾，否则同步报错）；「可检索」「可排序」均不用勾
4. **调测**：两台设备登录**同一个华为账号**（与 AGC 开发者账号一致才能用「数据记录调测」页面查看），A 设备写数据 → B 设备查看是否同步
5. 调测期间可「重置开发环境」清空调测数据；**充分调测后**才「实施变更到生产环境」（不可撤回！）

## 四、端侧集成步骤

1. **app.json5**：app 标签加 `"cloudStructuredDataSyncEnabled": true` → 「设置-云空间」出现应用开关
2. **CloudSyncUtil.ets**（新建）：
   - `initCloudDb(context)`：getRdbStore 建库 + executeSql 建表 + `setDistributedTables(['cloud_data'], DISTRIBUTED_CLOUD, {autoSync: true})`
   - `upsertCloudData(key, value)`：INSERT OR REPLACE + updated_at
   - `queryCloudData(key)`：下行查询
   - `triggerCloudSync()`：手动 cloudSync（SYNC_MODE_TIME_FIRST）
   - `subscribeCloudChange(cb)`：on('dataChange', SUBSCRIBE_TYPE_CLOUD) 订阅云端下行变化（多端刷新入口）
3. **持久化点桥接**：ChatPage.ets / BBTreeCanvas.ets 现有 serialize 调用点后追加 `upsertCloudData('flat_pool' | 'tabs_pool', json)`
4. **同步状态提示**（后续版本）：参考状态码表——0=已同步 / 3=未开启同步 / 6=云空间不足 / 7=未连WLAN；Deeplink `hicloud://cloudDrive/getInfo?path=MainActivity` 跳云空间设置页

## 六、排障速查（官方 FAQ 实证）

| 现象 | 原因/解决 |
|---|---|
| 日志 `{"schedule":2,"code":1,"details":{}}` | ① 本地表类型不符 SQLite 规范 ② 云侧端侧配置不一致（未设分布式表/表名不匹配/字段属性不匹配）→ 依次排查 |
| 云端改配置后端侧同步失败 | 退出华为账号重新登录 |
| 找不到云空间服务 | 「全部功能」→「构建>云空间服务」→ 固定到导航树 |
| 端侧同步无反应 | 检查「设置-云空间」应用开关是否打开 + 云空间存储是否充足 + 仅 WLAN 策略时是否连着 WiFi |
| 数据类型名称输入 `cloud_data` 被拦（提示「仅允许包含字母、数字、且以字母开头」） | AGC 命名约束不允许下划线 → 数据类型名称用驼峰 `cloudData`，「高级设置→本地表名称」填 `cloud_data` 承接映射，端侧代码不用改 |
