# 气泡对话页面新增功能 — 0.42

## 一、需求1：加载状态提示 & 错误提示

- 复用已有 `@Local isLoading` 状态
- 发送时 AI 气泡显示占位文字 `AI正在回复中，请稍候...`
- 首条流数据到达 → 清除占位文字，追加真实内容
- 异常 → AI 气泡显示 `请求出错，请检查网络/API配置\n${errMsg}`
- 发送按钮 `.enabled(!this.isLoading)` 置灰防重复点击

## 二、需求2：多模态图片上传

### ChatMessage 结构
```typescript
@Trace imageUrl: string[]  // Base64 内联格式 data:image/jpeg;base64,...
```

### 功能实现
1. 输入框旁 📷 按钮 → `photoAccessHelper.PhotoViewPicker` 相册多选
2. 选中图片 → `fileIo` 读取 → `buffer.toString('base64')` → 存入 `pendingImages[]`
3. 预览区：60×60 缩略图 + × 删除按钮
4. 发送：图片打包进 `ChatMessage.imageUrl[]`，构造多模态 content 数组
5. 用户气泡：文字 + 图片缩略图；AI 气泡：仅文字

### 多模态请求体
```json
{
  "messages": [{
    "role": "user",
    "content": [
      {"type": "text", "text": "描述这张图片"},
      {"type": "image_url", "image_url": {"url": "data:image/jpeg;base64,..."}}
    ]
  }]
}
```
