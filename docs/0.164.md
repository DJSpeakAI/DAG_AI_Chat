# 0.164 华为账号登录（云同步第一步）

## 0.164.1（2026-10-03）

### 需求（用户原话要点）

1. 大功能「华为账号登录 + 云同步」，本次先做**华为账号登录**（云同步后续版本）
2. 登录按钮放在首页「进入对话画布」按钮**下方**
3. 登录成功后显示华为账号 ID 或名字（昵称）
4. 拥有登录功能，也要有**退出账号**功能
5. 新建 docs/0.164.md（本文件）
6. 版本号 v0.164.1

### 技术方案（Account Kit，官方文档查证）

基于 **Account Kit（华为账号服务）** 的 `@kit.AccountKit` → `authentication` 模块实现，
选择「华为账号登录」方式（`createAuthorizationWithHuaweiIDRequest`）：

| 项 | 结论 | 依据 |
|---|------|------|
| 登录方式 | 授权请求 + `scopes=['openid','profile']` | 个人开发者可用（一键登录仅限企业），无需申请任何账号权限 |
| 登录后显示 | `nickName`（未设置昵称时华为返回匿名手机号/邮箱）+ `openID` 兜底 | `AuthorizationWithHuaweiIDCredential` 纯客户端直接返回 nickName/avatarUri/openID/unionID，**无需服务端** |
| 退出账号 | `createCancelAuthorizationRequest()`（取消授权） | 官方取消授权 API，成功后清空本地登录态 |
| 前置配置 | module.json5 `metadata` 配 `client_id`（AGC 应用的 Client ID） | 「配置Client ID」官方文档 |
| 公钥指纹 | **无需配置** | 官方文档：compatibleSdkVersion>=20 不需要配置公钥指纹（本项目 6.1.1(24)） |
| unionID | 一并保存 | 同一开发者账号下唯一标识，后续云同步以 unionID 识别用户 |

## 0.164.2（2026-10-03）修复装机实测 1001502003

### 实测现象

0.164.1 装机后点击「华为账号登录」→ 提示「操作失败」（错误码 **1001502003**）。

### 根因（官方文档查证收口）

| 项 | 结论 | 依据 |
|---|------|------|
| 错误码含义 | 1001502003 = SIGN_IN_PARAMS_ERROR / PARAMETER_INVALID「输入参数值无效，接口传参异常等」 | 官方 account-error-code + AuthenticationErrorCode 枚举 |
| 根因 | `'openid'` 是**默认 scope 无需显式传**（官方注释原文：「'openid'为默认值可不传」）；原代码 `scopes=['openid','profile']` 组合**无任何官方示例支持**，触发服务端参数校验失败 | 官方 API 参考 executeRequest 示例注释 |
| 正确写法 | `scopes=['profile']`；openID/unionID 由 AuthorizationWithHuaweiIDCredential **默认返回**（字段含 openID/unionID/avatarUri/nickName），无需为拿 ID 显式申请 openid | 官方「获取头像昵称」示例只传 ['profile'] |
| 排除项 | forceAuthorization=true、state=generateRandomUUID() 均为官方示例标配，非问题源；permissions=['serviceauthcode'] 仅服务端场景需要，纯客户端不传 | 官方示例对照 |
