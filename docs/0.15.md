# 清除 V1 残留 — 0.15

## 一、问题

代码中仍有 2 处 V1 `AppStorage` 调用：

| 文件 | 行 | V1 代码 |
|------|---|---------|
| ChatPage.ets | 14 | `AppStorage.get<string>('currentBubbleId')` |
| BBTreeCanvas.ets | 86 | `AppStorage.setOrCreate('currentBubbleId', bubble.nodeId)` |

## 二、V2 方案

`AppStorageV2` 按类型管理，原始 `string` 没有类型锚点。需要包装类：

### ChatNode.ets — 新增 CurrentBubbleStore

```typescript
@ObservedV2
export class CurrentBubbleStore {
  @Trace bubbleId: string = '';
}
```

### BBTreeCanvas.ets — 双击时写入 store

```typescript
// 属性声明
currentBubbleStore: CurrentBubbleStore = AppStorageV2.connect(
  CurrentBubbleStore, 'current-bubble', () => new CurrentBubbleStore()
) as CurrentBubbleStore;

// 双击回调
.onAction(() => {
  if (this.isDragging) { return; }
  this.currentBubbleStore.bubbleId = bubble.nodeId;  // ✅ V2
  this.pathStack.pushPath({ name: 'ChatPage' });
})
```

### ChatPage.ets — @Computed 读取 store

```typescript
// 属性声明
currentBubbleStore: CurrentBubbleStore = AppStorageV2.connect(
  CurrentBubbleStore, 'current-bubble', () => new CurrentBubbleStore()
) as CurrentBubbleStore;

// 删除 @Local currentBubbleId 和 aboutToAppear
// 改用 @Computed 自动响应式
@Computed
get currentBubbleId(): string {
  return this.currentBubbleStore.bubbleId;
}
```

**删除的 V1 代码**：
- `@Local currentBubbleId: string = ''`
- `aboutToAppear()` 中的 `AppStorage.get<string>(...)`
