# 图片预览手势优化 — 0.120

归属版本：v0.1 内部迭代

## 需求

当前消息图片预览逻辑：点击图片进入放大预览，再次点击图片恢复原样；
存在问题：放大预览状态下，大拇指向右滑动会直接退出预览并跳回Canvas气泡画布页面，不符合操作预期。

修改交互：**图片放大预览状态下，右滑和点击图片，两种操作都关闭图片预览，图片恢复原始尺寸，停留在当前ChatPage对话页面，禁止触发NavPathStack页面导航返回，不直接跳转到Canvas页面**。

## 实现方案

1. 图片全屏预览弹窗增加手势拦截：预览弹窗打开时，捕获页面侧滑返回手势。
2. 交互规则：
   - 点击消息图片 → 打开放大图片预览
   - 预览状态：①点击放大图片；②手指右滑。**两种方式均可关闭预览，图片恢复原样**
   - 关闭预览后，仍然留在ChatPage对话页，**不执行页面回退、不跳转Canvas画布**
3. 保留原有大图能力：预览弹窗内双指缩放、上下拖动查看大图逻辑保持不变。
4. 手势拦截只在图片预览弹窗激活时生效；图片预览关闭后，页面原生侧滑返回逻辑恢复原样。

`components/ChatPage.ets` 图片预览相关代码块

2. 新增/修改代码添加注释，标记改动位置。
3. 鸿蒙ArkUI V2，NavPathStack导航模式。
