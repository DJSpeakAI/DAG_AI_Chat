任务：优化知识库卡片弹窗的等待计时、超时控制、异常捕获、后台策略与按钮状态，components/ChatPage.ets
需求汇总：
1. 前端秒表计时功能：
   发起AI提炼知识卡片请求时，启动前端计时器，弹窗标题展示：AI提炼中：XX秒。
- 请求发起瞬间从0开始计数，每秒+1；
- 请求成功完成、用户点击取消、报错、业务超时，计时器立刻停止并清零；
- APP切后台时暂停计时，切回前台继续累加计时；
- 不做动态点点点文字动画。

2. 业务超时阈值设置为180秒（3分钟）：
   计时器累计达到180s，自动调用StreamController.abort()终止SSE请求，停止计时；弹窗红色提示：请求超时：AI处理时间超出3分钟，请尝试裁剪图片、减少图片内文字内容后重试。

3. 页面切后台策略 onPageHide：
   弹窗页面切后台，直接调用StreamController.abort()终止SSE请求，停止计时，弹窗提示：提炼已暂停，应用切到后台，鸿蒙系统会限制后台网络，无法稳定接收结果。
   目的：避免后台长时间等待，被系统掐断长连接白白消耗输入token。

4. 异常捕获，全部替换为友好中文提示，禁止直接展示英文原始报错：
   一共区分3类错误，在弹窗标题下方展示红色提示文本：
   ① Operation timeout底层网络超时：后台网络超时：APP切后台后，系统限制网络，本次AI生成中断。请保持应用在前台重试。
   ② API服务返回业务错误：AI服务返回错误：{简要错误信息}，请检查API Key/模型配置。
   ③ 本地代码异常：本地处理异常：生成卡片失败，请重试。

5. UI按钮状态规则：
- 请求进行中：【保存入库】置灰不可点击；【取消】按钮可用；下方复习词条区域保持原样继续展示，不要改动。
- AI流式返回标题、定义内容，实时填充到弹窗对应的输入框。
- 请求成功结束：计时器停止，【保存入库】按钮启用可点击。
- 报错 / 业务超时：计时器停止，【保存入库】保持置灰不可点击，弹窗展示红色错误提示文字。
  修复现有BUG：超时报错状态下【保存入库】依然可点击的问题。

6. 【取消】按钮逻辑：
   点击【取消】，调用abort终止SSE流式请求，停止计时器，关闭弹窗。

7. 弹窗底部增加小字提示文案：
