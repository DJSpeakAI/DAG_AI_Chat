# 修复连线脱离气泡圆心问题 — 0.105

> 归属版本：v0.1 内部迭代

## 一、问题

0.104 缩放修复后，连线出现两个新问题：
1. 连线不从气泡圆心出发，从顶部偏出，位置偏移
2. 连线超出气泡，线段过长，延伸到画布外面

## 二、根因

连线计算的 4 个方法 `getEdgeStartX/Y`、`getEdgeEndX/Y`、`getEdgeLength` 各自独立计算，都返回**气泡圆心坐标**。

```
Column()           ← 线段从 (parentCX, parentCY) 开始
  .width(centerLen)← 宽度 = 圆心距（含 2×半径）
  .position({ x: parentCX, y: parentCY })
  .rotate({ angle })
```

线段从 **父圆心→子圆心**，穿过气泡内部，视觉上从顶部引出、超出边界。

## 三、修复

新增 4 个辅助方法获取父子圆心，然后 6 个 edge 方法统一：

```
向量      = 子圆心 − 父圆心
单位向量   = 向量 / 长度
起点      = 父圆心 + 单位向量 × 半径    ← 沿连线方向偏移 30px
终点      = 子圆心 − 单位向量 × 半径    ← 反向偏移 30px
线段长度   = 圆心距 − 2 × 半径
角度      = 不变
```

**只改 `BBTreeCanvas.ets`** 一个文件，所有 edge 计算方法重写。

## 四、改动

| 方法 | 旧行为 | 新行为 |
|------|--------|--------|
| `getEdgeStartX/Y` | 返回父圆心 | 返回父圆边沿（沿方向偏移半径） |
| `getEdgeEndX/Y` | 返回子圆心 | 返回子圆边沿（反向偏移半径） |
| `getEdgeLength` | 圆心距 | 圆心距 − 60px |
| `getEdgeAngle` | 不变 | 不变 |
| `getParentCX/Y`（新增） | — | 获取父圆心 |
| `getChildCX/Y`（新增） | — | 获取子圆心 |
