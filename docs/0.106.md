# 修复缩放后连线偏移 — 0.106

> 归属版本：v0.1 内部迭代

## 一、根因

气泡固定 60×60 像素，圆心 = 左上角 + 30px（屏幕像素）。

```
气泡实际圆心 = c2sX(bubble.x) + 30          ← 30 是屏幕像素，不随缩放变化
连线计算的圆心 = c2sX(bubble.x + 30)         ← 30 被缩放了！
                = bubble.x × scale + 30 × scale + offset
```

差异 = `30 × scale − 30 = 30 × (scale − 1)`

| scale | 偏移量 |
|-------|--------|
| 1.0 | 0px ✓ |
| 0.5 | −15px |
| 2.0 | +30px |

**缩放后连线认为圆心在错误位置，导致线段与气泡脱离。**

## 二、修复

将 `+ 30`（气泡半径）从 `c2sX()` 内部移到外部：

```typescript
// ❌ 之前
getChildCX = c2sX(bubble.x + cDragX + 30)  // 半径被缩放

// ✅ 之后
getChildCX = c2sX(bubble.x + cDragX) + 30  // 半径是固定屏幕像素
```

仅改 `getParentCX/Y`、`getChildCX/Y` 四个方法。
