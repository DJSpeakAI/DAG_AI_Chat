# 修复 ForEach 空项残留灰色短线 — 0.28

## 一、好消息

调试 Text 确认坐标完全正确：
```
[0] id:bubble_179 pid:null px:0 py:0 x:200 y:200    ← 根节点
[1] id:bubble_179 pid:bubble_179 px:200 py:200 x:290 y:300  ← 子节点，parentX=200 ✅
```

**连线已正确渲染！** `parentX`/`parentY` + `Column` + `.rotate()` 方案成功。仅剩一个小 bug。

## 二、Bug 原理

**现象**：左上角多一条多余灰色短线。

**根因**：ArkUI V2 的 `ForEach` **每一项必须返回一个组件**。当前连线 ForEach 中，根节点 `parentID === null` 时 `if` 条件为 false，**不返回任何组件**。

```typescript
ForEach(this.store.nodeList, (bubble: BubbleNode, index: number) => {
  if (bubble.parentID !== null) {
    Column()...  // 只有子节点返回 Column
  }
  // 根节点：什么都不返回 ← BUG
}, ...)
```

ForEach 内部的组件复用机制在 item 不返回组件时，**残留上一次渲染的旧实例**，导致左上角出现一条多余的灰色短线。

## 三、修复

`if` 条件不满足时返回 `Blank()` 占位，确保每一项都返回组件：

```typescript
ForEach(this.store.nodeList, (bubble: BubbleNode, index: number) => {
  if (bubble.parentID !== null) {
    Column()...
  } else {
    Blank()  // 占位，防止组件复用残留
  }
}, ...)
```

## 四、改动范围

**只改连线的 ForEach**，加一个 `else { Blank() }`。其余全部不动。
