# 回滚滚动位置记忆 → 保留 0.110 滚到底部 — 0.112

> 归属版本：v0.1 内部迭代

## 一、决策

方案 A（滚动位置记忆）不可靠：
- `Scroller.currentOffset()` 在 `aboutToDisappear` 抛异常 → 位置根本没存上
- `scrollTo({ yOffset })` 对 `List` 组件行为不确定
- try-catch 只是防崩溃，实际功能无效

**回滚到 0.110：仅进入时滚到底部，不记忆位置。**

## 二、回滚内容

| 文件 | 回滚到 |
|------|--------|
| `ChatModel.ets` | 删除 `scrollOffset` 字段、构造函数参数、序列化/反序列化 |
| `ChatPage.ets` | `aboutToAppear` → 仅 `scrollEdge(Edge.Bottom)`；`aboutToDisappear` → 仅取消 SSE |

## 三、回滚后效果

- ✅ 进入对话页面自动滚到底部（0.110 功能，已验证正常）
- ❌ 不记忆上次滚动位置（放弃，系统 API 不支持可靠实现）
