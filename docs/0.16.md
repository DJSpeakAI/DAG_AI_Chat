# 构造函数数组拷贝 — 0.16

## 一、问题

当前 `BubbleTree` 构造函数直接赋值数组引用：

```typescript
constructor(nodeList: BubbleNode[] = []) {
  this.nodeList = nodeList;  // ← 外部数组和内部指向同一引用
}
```

**风险**：外部代码修改原数组（`push`、`splice` 等），store 内部数据跟着变，但 `@Trace` 不触发 → UI 不刷新。

## 二、方案

```typescript
constructor(nodeList: BubbleNode[] = []) {
  this.nodeList = [...nodeList];  // 拷贝新数组，隔离外部引用
}
```

**效果**：store 持有独立数组副本，外部修改不影响内部数据，只有通过 store 修改才触发 `@Trace`。

## 三、同理：BubbleNode 的 messages

```typescript
constructor(nodeID: string, parentID: string | null, messages: ChatMessage[], x: number, y: number) {
  this.nodeID = nodeID;
  this.parentID = parentID;
  this.messages = [...messages];  // 同样拷贝隔离
  this.x = x;
  this.y = y;
}
```
