# 持久化失效根因分析 — 0.32

## 一、根因：save 和 load 从未被调用

### 证据

| 文件 | 位置 | 现状 | 问题 |
|------|------|------|------|
| **ChatPage.ets** | `addBubble()` L55-70 | 更新 `nodeList` 后直接 `pop()` | ❌ **没有调用 `saveBubbleTree`** |
| **BBTreeCanvas.ets** | 无 `aboutToAppear` | 不存在 | ❌ **没有调用 `loadBubbleTree`** |
| **BBTreeCanvas.ets** | `onActionEnd` 拖拽提交 | 更新坐标后结束 | ❌ **没有调用 `saveBubbleTree`** |
| **Index.ets** | `aboutToAppear` | `AppStorageV2.connect` 初始化默认数据 | ❌ 每次打开都用默认根节点覆盖 |

**结论**：`TreeFileUtil.ets` 代码本身逻辑正确，但**从未被接入调用链**。新增气泡不保存 → 关闭 APP → 重新打开 → `Index` 用默认数据初始化 → 气泡消失。

### TreeFileUtil.ets 自身审查

| 函数 | 审查结果 |
|------|---------|
| `treeToPlainObj` | ✅ 逐属性提取，含 messages 嵌套 |
| `plainObjToTree` | ✅ 数据校验 + 兜底默认值 |
| `saveBubbleTree` | ✅ TRUNC 防残留，try-catch |
| `loadBubbleTree` | ✅ 文件存在判断 + 空文件处理 + 异常捕获 |

**TreeFileUtil.ets 无需改动逻辑**，只需加调试日志。

## 二、修复方案（3 处接入 + 2 处日志）

### 改动 1：BBTreeCanvas.ets — 加 aboutToAppear 加载

```typescript
import { saveBubbleTree, loadBubbleTree } from '../utils/TreeFileUtil';

// 在 struct 内加：
aboutToAppear() {
  loadBubbleTree().then((tree) => {
    if (tree && tree.nodeList.length > 0) {
      this.store.nodeList = tree.nodeList;
    }
  });
}
```

### 改动 2：ChatPage.ets — addBubble 末尾加保存

```typescript
import { saveBubbleTree } from '../utils/TreeFileUtil';

// addBubble 内，this.store.nodeList = [...] 之后：
saveBubbleTree(this.store);
```

### 改动 3：BBTreeCanvas.ets — onActionEnd 拖拽提交后加保存

```typescript
import { saveBubbleTree } from '../utils/TreeFileUtil';

// onActionEnd 内，commit 坐标之后：
saveBubbleTree(this.store);
```

### 改动 4：TreeFileUtil.ets — 加调试日志

```typescript
// saveBubbleTree 成功后：
console.info(`[TreeFileUtil] save OK, nodes=${plain.nodeList.length}`);

// loadBubbleTree 成功后：
console.info(`[TreeFileUtil] load OK, nodes=${obj.nodeList.length}`);
```

## 三、调试验证步骤

1. 新增一个子气泡
