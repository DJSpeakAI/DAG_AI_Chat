# 修复：自动排版按钮只能点击一次 — 0.123fix1

归属版本：0.123 内部修复

## 问题

自动排版按钮首次点击正常，第二次点击无响应。

## 原因分析

`Row` 上设置了 `hitTestBehavior(HitTestMode.Transparent)`，该属性在 ArkUI 中可能导致子组件 `Text` 的 `onClick` 在首次触发后失效（透明命中模式下事件透传行为不稳定）。

## 修复方案

1. 移除 `Row` 上的 `hitTestBehavior(HitTestMode.Transparent)`
2. 改用 `.position()` 绝对定位按钮到右上角，避免 `Row` 全宽遮挡画布手势
3. 按钮使用固定坐标定位，不占用全宽，不影响下层画布的平移/缩放手势

## 改动文件

- `components/BBTreeCanvas.ets` — 自动排版按钮区域

## 约束

1. 其余代码完全不动
2. 排版算法、箭头绘制、气泡样式均不变
