# 埋点字典（用户行为监测）

> **给 AI 的说明**：本表是 DAG_AI_Chat 全部埋点事件的唯一权威对照表。用户问「某数据对应哪个按钮」时按 `事件 ID` 查本表。
> **新增埋点必须同步登记本表**（project_rule 铁律）。数据流向：TrackUtil → AGC 云函数 trackEvents → Cloud DB `events` 表。

## 查询方式

- AGC 控制台 → 云数据库 → 数据管理 → `events` 表（导出 Excel：`e`=事件 ID、`p`=参数 JSON、`t`=毫秒时间戳）
- 事件 ID `e` 对照下表 → 找到中文按钮与所在页面

## 数据语义（Cloud DB events 表）

| 字段 | 含义 |
|---|---|
| `e` | 事件 ID（见上表） |
| `p` | 参数 JSON 串（如 `{"rating":"hard"}`） |
| `t` | 事件发生时间戳（毫秒）——Excel 转换：=(t/1000+8*3600)/86400+70*365+19 设置为日期格式 |

## 统计口径提示

- 同一用户连点会重复计数（真实点击热度）
