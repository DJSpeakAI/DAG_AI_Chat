# 0.126 Bug 诊断 — 初始位置 + 新建气泡右下角

## Bug 1：Pan Y 限制过死，用户无法向上拖动

**现象**：Pan 手势 `Math.max(topSafePadding, ...)` 锁死 `canvasOffsetY ≥ 120`，用户无法将画布向上拖动。

**用户诉求**：用户应该可以自由上下左右拖动画布，`.clip(true)` 已做视觉裁剪，不需要数据层再锁死。

**修正**：
- **移除** Pan `onActionUpdate` 中的 Y 轴下限限制，恢复自由拖动
- **保留** `.clip(true)` 视觉裁剪
- **保留** `fitViewport` 中的 `Math.max(topSafePadding, calculatedY)` clamp（确保初始视图和【显示全部】时树在安全区内）

## Bug 2：新建气泡永远在右下角，autoLayout 未触发

**根因定位**：

`ChatPage.ets` L446-468 `addBubble()` 方法：

```typescript
const newBubble = new BubbleNode(
  generateNodeId(),
  this.currentBubbleId,
  [],
  this.currentBubbleStore.bubbleX + 80 + Math.floor(Math.random() * 40),  // ← 硬编码 x
  this.currentBubbleStore.bubbleY + 80 + Math.floor(Math.random() * 40),  // ← 硬编码 y
  ...
);
this.store.nodeList = [...this.store.nodeList, newBubble];
this.pathStack.pop();  // 返回 BBTreeCanvas
// ← autoLayout() 从未调用！
```

**问题链**：
1. 新节点位置硬编码为 `parent.x + 80, parent.y + 80` → 永远在父节点右下角
2. `autoLayout()` 定义在 `BBTreeCanvas.ets` 中，`ChatPage.ets` 无法调用
3. `pathStack.pop()` 返回 BBTreeCanvas 时，`aboutToAppear` 不会再次触发（组件已创建）
4. 结果：新节点保持右下角硬编码位置，均分算法从未执行

**修正方案**：

### 步骤 1：BubbleTree 新增 `needsRelayout` 标志

`ChatModel.ets` BubbleTree 类：
```typescript
@ObservedV2
export class BubbleTree {
  @Trace nodeList: BubbleNode[] = [];
  @Trace needsRelayout: boolean = false;  // ★ 新增：标记需要重新布局
  ...
}
```

### 步骤 2：addBubble() 设置标志

`ChatPage.ets` `addBubble()` 末尾，`pathStack.pop()` 前：
```typescript
this.store.needsRelayout = true;  // ★ 通知 BBTreeCanvas 重新布局
this.pathStack.pop();
```

### 步骤 3：BBTreeCanvas 添加 onShown 回调

NavDestination 添加 `.onShown()`，检查标志并触发 `autoLayout()` + `fitViewport()`：
```typescript
.onShown(() => {
  if (this.store.needsRelayout) {
    this.autoLayout();
    this.fitViewport();
    this.store.needsRelayout = false;
  }
})
```

**流程**：
1. 用户在 ChatPage 点击新建子气泡 → `addBubble()` 添加节点 + 设 `needsRelayout = true` → `pop()` 返回
2. BBTreeCanvas `onShown` 触发 → 检测到 `needsRelayout` → 执行 `autoLayout()`（均分居中）→ `fitViewport()`（适配视口）→ 清除标志
3. 用户看到新节点正确均分排布

| # | 文件 | 位置 | 改动 |
|---|------|------|------|
| 1 | BBTreeCanvas.ets | Pan `onActionUpdate` | **移除** Y 轴下限限制，恢复自由拖动 |
