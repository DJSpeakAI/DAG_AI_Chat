# 0.126 方案审查 — 问题与优化建议

## 方案概要

AI 生成的 0.126 方案包含 3 项改动：
1. build 结构分层（画布不覆盖标题栏）
2. layoutChildren 改回均分居中
3. fitViewport 重构（自动缩放 + 树整体居中）

---

## 审查结论：方案整体可行，但有 4 处需修正

### 问题 1：build 结构 — 多余的 120vp 空白标题区 ❌

**AI 方案**：
```
NavDestination() {
  Column() {
    Stack().height(120)       // ← 空白占位
    Stack().flexGrow(1)       // 画布
  }
}
.title('气泡树')
```

**问题**：`.title('气泡树')` 已经渲染了系统标题栏（含返回按钮）。再手动加一个 `Stack().height(120)` 会在标题栏下方多出 120vp 空白区域，浪费屏幕空间。

**修正方案**：用 `.clip(true)` 裁剪画布 Stack，阻止 `.position()` 绝对定位的子元素溢出到标题栏区域。无需手动占位：

```
NavDestination() {
  Stack() {
    Stack({ alignContent: Alignment.TopStart }) {
      // 连线 + 气泡
    }
    .clip(true)               // ★ 防止内容溢出到标题栏
    // Pan + Pinch 手势
    // 【显示全部】按钮
  }
}
.title('气泡树')
```

### 问题 2：fitViewport canvasOffsetX 缺少 `- 30` ❌

**AI 方案**：
```typescript
this.canvasOffsetX = screenWidth / 2 - treeCenterX * this.canvasScale;
```

**问题**：气泡 `.position({ x: c2sX(bubble.x) })` 定位的是气泡左上角，气泡中心在 `c2sX(bubble.x) + 30`。要让树几何中心对齐屏幕中心，必须减去 30：

```
treeCenterX * scale + offset + 30 = screenWidth / 2
→ offset = screenWidth / 2 - treeCenterX * scale - 30
```

当前 0.125 代码已有 `- 30`，AI 方案漏掉了，会导致树整体偏右 30vp。

**修正**：保留 `- 30`。

---

### 问题 3：fitViewport canvasOffsetY 同样缺少 `- 30` ❌

**AI 方案**：
```typescript
this.canvasOffsetY = topSafePadding + viewHeight / 2 - treeCenterY * this.canvasScale;
```

**问题**：同理，气泡左上角定位，垂直方向也需 `- 30`。

**修正**：
```typescript
this.canvasOffsetY = topSafePadding + viewHeight / 2 - treeCenterY * this.canvasScale - 30;
```

---

### 问题 4：fitViewport 缩放未约束下限 0.3 ⚠️

**AI 方案**：
```typescript
this.canvasScale = Math.min(scaleX, scaleY, 1.0);
```

**问题**：当树很大时 `scaleX/scaleY` 可能 < 0.3，突破 Pinch 手势的最小缩放阈值 0.3，导致行为不一致。

**修正**：
```typescript
this.canvasScale = Math.max(0.3, Math.min(scaleX, scaleY, 1.0));
```

## 修正后 fitViewport 完整代码

```typescript
fitViewport(): void {
  if (this.store.nodeList.length === 0) return;

  let minX = Infinity, maxX = -Infinity, minY = Infinity, maxY = -Infinity;
  for (const node of this.store.nodeList) {
    minX = Math.min(minX, node.x);
    maxX = Math.max(maxX, node.x);
    minY = Math.min(minY, node.y);
    maxY = Math.max(maxY, node.y);
  }

  const treeCenterX = (minX + maxX) / 2;
  const treeCenterY = (minY + maxY) / 2;

  const screenWidth = px2vp(display.getDefaultDisplaySync().width);
  const screenHeight = px2vp(display.getDefaultDisplaySync().height);
  const topSafePadding = 120;
  const viewHeight = screenHeight - topSafePadding;

  const treeW = maxX - minX + 60;
  const treeH = maxY - minY + 60;
  const scaleX = screenWidth / treeW;
  const scaleY = viewHeight / treeH;
  this.canvasScale = Math.max(0.3, Math.min(scaleX, scaleY, 1.0)); // ★ 约束下限 0.3

  // ★ 保留 - 30（气泡左上角定位补偿）
  this.canvasOffsetX = screenWidth / 2 - treeCenterX * this.canvasScale - 30;
  this.canvasOffsetY = topSafePadding + viewHeight / 2 - treeCenterY * this.canvasScale - 30;
}
```
