# 修复 test.ets — struct 不能用 constructor — 0.30

## Bug 分析

### Bug 1：SilentModifier struct 使用了 constructor

```typescript
@ComponentV2
struct SilentModifier {
  @Local bubble: Bubble = new Bubble(0);
  constructor(b: Bubble) {    // ❌ struct 不应有 constructor
    this.bubble = b;
  }
}
```

ArkUI V2 的 `@ComponentV2` struct **禁止自定义 constructor**。框架通过自己的机制初始化组件。自定义 constructor 会：
- 干扰框架的组件生命周期
- `this.bubble = b` 绕过 V2 响应式系统，赋值不生效
- 父组件 `SilentModifier({bubble: this.list[0]})` 传入的参数无法正确映射

### Bug 2：用 @Local 接收父组件传值

```typescript
@Local bubble: Bubble = new Bubble(0);  // ❌ @Local 是组件内部状态，不接收外部传值
```

`@Local` 是组件私有状态，父组件传入的值不会生效。应使用 `@Param` 接收父组件数据。

## 修复

```typescript
@ComponentV2
struct SilentModifier {
  @Param bubble: Bubble = new Bubble(0);  // ✅ @Param 接收父组件传值
  // ❌ 删除 constructor

  aboutToAppear() {
    this.bubble.x = 300;  // ✅ 修改 @Trace 属性，触发响应式
  }

  build() {
    Empty()
  }
}
```

### 改动清单

| 位置 | 旧 | 新 |
|------|-----|-----|
| `SilentModifier.bubble` | `@Local` + constructor 赋值 | `@Param`（框架自动传值） |
| `SilentModifier` constructor | `constructor(b: Bubble)` | **删除** |
| `Bubble` class | 不动 | 不动（class 可以有 constructor） |
| `DemoFindBug` | 不动 | 不动 |
