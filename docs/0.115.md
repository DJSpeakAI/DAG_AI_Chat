# 多行输入框自适应高度 + 换行按钮 — 0.115

归属版本：v0.1 内部迭代

## 需求

在 ChatPage 聊天输入框，实现多行文本输入功能：
1. 输入框支持回车换行；输入法右下角按钮，单行时显示「发送」，输入多行内容时自动变成「换行」。
2. 输入框高度自动随内容行数自适应扩张，最多到 5 行，超过 5 行内部出现滚动条，不再继续拉高。
3. 参考效果：豆包 App、鸿蒙系统备忘录同款交互。

## 现状问题

当前输入框输入多行文字时，输入法右下角始终是发送按钮，无法切换换行；输入框高度不会跟随文字行数自动变化。

## 根因分析（0.115 bug 修复）

**鸡生蛋问题：** `@Computed` 检测 `inputText.includes('\n')` 切换 `enterKeyType`，但 `EnterKeyType.Send` 模式下按回车 = 触发 `onSubmit`（发送消息），**不插入 `\n`**。因此 `inputText` 永远不含 `\n`，`enterKeyType` 永远是 `Send`，按钮永远显示"发送"。

## 修复方案

**始终使用 `EnterKeyType.NEW_LINE`**：回车键始终插入换行，输入法按钮始终显示"换行"。发送消息通过输入框旁的「发送」按钮触发。

这是微信、豆包等主流聊天 App 的标准做法：回车 = 换行，发送按钮 = 发送。

### 具体改动

1. `enterKeyType` 固定为 `EnterKeyType.NEW_LINE`，移除 `@Computed currentEnterKeyType`
2. 移除 `onSubmit` 事件（`NEW_LINE` 模式不触发 `onSubmit`）
3. `TextArea` + `minLines(1)` + `maxLines(5)` 保持不变
4. 「发送」按钮保持不变，是唯一的发送入口

## 交互规则

1. 回车键：始终插入换行（`\n`），输入法按钮显示"换行"
2. 发送消息：点击输入框旁「发送」按钮
3. 输入框：1~5 行自动增高；超过 5 行固定高度，内部滚动
4. 空白内容（纯空格/换行）禁止发送消息
5. 仅修改 ChatPage 输入区域，**不改动 BubbleTree、消息渲染、持久化、其他页面代码**

## 改动文件：仅 ChatPage.ets

1. 移除 `@Computed currentEnterKeyType` 属性
2. `TextArea` 的 `.enterKeyType(this.currentEnterKeyType)` → `.enterKeyType(EnterKeyType.NEW_LINE)`
3. 移除 `.onSubmit(...)` 事件
