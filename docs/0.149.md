# AI对话代码块语法高亮功能 — 0.116
> 归属版本：v0.1 内部迭代
## 一、需求背景
AI流式返回 Markdown 格式文本，文本中包含 ```lang 开头、```结尾的代码块。当前代码块全部为单色文字，没有语法区分，代码阅读体验较差。
采用 MVP最小可行方案：简易正则分词实现基础高亮，不引入任何第三方库、不做完整词法语法解析。优先实现可用能力，后续迭代再优化着色精度、扩展更多语言。

## 二、功能详细定义
1. Markdown代码块流式识别
    - 实时解析流式输出的MD文本，识别代码块起止标记： ```语言名 和 ```
    - 成功提取：语言标识 + 代码内容
    - 若代码块没有填写语言标识（仅 ```），标记为 plaintext，不做语法高亮，普通单色渲染
    - 流式兼容：AI还没输出结束标记时，也能临时渲染代码预览；收到结尾标记后完成完整处理
2. 代码块容器UI
    - 独立代码块容器，使用等宽字体 monospace，背景色区分普通正文
    - 代码块顶部：展示语言标签 + 复制按钮；点击复制按钮，复制全部代码文本，弹出toast提示复制成功
3. MVP简易语法高亮规则（仅正则匹配，不完整语法解析）
   首期支持语言：ArkTS、TypeScript、Python、Java、JSON
   着色规则（跟随系统深浅色主题自动切换配色）
    - 关键字：蓝色
    - 字符串：绿色
    - 注释：灰色
    - 数字：橙色
    - 普通代码文本：底色对应文字色
   > 约束：简易正则方案，嵌套场景可能出现着色错位，本版本视为可接受，后续迭代优化
4. 主题适配
   高亮全部配色跟随系统深浅色模式切换。深色/浅色模式下，代码块背景、文字高亮颜色自动更新。



## 四、验收标准
1. 流式解析AI返回内容，可以正确识别代码块起止标记，提取语言标识。
2. 支持ArkTS / TypeScript / Python / Java / JSON，关键字、字符串、注释、数字具备区分颜色；无语言标记代码块纯文本展示。
3. 代码块复制按钮可一键复制全部代码，弹出成功提示。
4. 代码使用等宽字体，容器背景和普通对话文本区分。
5. 切换系统深浅色模式，代码高亮配色自动适配。
6. 流式增量输出，代码边返回边渲染高亮；未结束的代码块支持临时预览。
7. 边界场景：无内容、超长代码做好基础性能兜底。

## 五、风险&约束
1. 本版本为MVP简易正则实现，不做完整语法解析，字符串内出现注释符号等嵌套场景会着色错乱，属于当前版本可接受范围。
2. 关键字列表手动维护，新增编程语言需要手动追加关键字数组。
3. 禁止引入任何第三方JS/语法高亮库，控制包体积。
4. 本次只保证功能跑通，精细视觉美化放到后续迭代。

### CodeBlockView 改动明细

1. `@Param lang`：语言标识（parseMarkdown 早已提取 lang 字段，直接传入）
2. 顶部按钮栏：最左新增**语言标签**（无标识显示 plaintext）+ **复制按钮**（⧉复制，一键复制全部代码 + toast「复制成功」）
3. `@Computed renderTokens`：tokenizeCode 结果；null（不支持/超长）降级为单段全文本 → 渲染层只有一条 Span 拼接路径
4. `tokenColor(kind)`：关键字蓝（#569CD6/#0000C0）、字符串绿（#98C379/#008000）、注释灰（#8A8A8A/#808080）、数字橙（#D19A66/#B35C00）、普通文本沿用原色（#D4D4D4/#333333）——深浅色两套跟随 isDark 自动切换
5. wrap/scroll 两个 Text 改为 `Text('', {controller})` 内 `ForEach` + `Span` 着色渲染

### 放大弹窗同步高亮（一致性补充）

`codeZoomLang` 状态 + `openCodeZoom(content, lang)` 加参 + `zoomTokens()`/`codeTokenColor()`（与气泡内同逻辑同配色）+ 标题行语言标签 + cz|w/cz|s 两个 Text 同样 Span 着色。

### 关键设计决策

- **token 顺序拼接与 content 完全一致** → 划词/全选/复制偏移与原文本不错位（0.156 划词五件套零破坏）
- **流式兼容**：parseMarkdown 对未闭合代码块天然收集已输出行（内层 while 扫到行尾自然结束）→ 未结束代码块临时渲染预览；@Computed 依赖 content，流式增量自动重算高亮
- **性能兜底**：代码超 30000 字符或 token 超 6000 上限 → 放弃高亮整体单色渲染（避免流式期间每帧重算拖垮 UI）
- **正则复用**：按语言缓存编译后的 RegExp（全局 Map），流式期间不反复编译
- **嵌套错位可接受**（需求既定约束）：字符串内注释符等着色错乱属 MVP 可接受范围
