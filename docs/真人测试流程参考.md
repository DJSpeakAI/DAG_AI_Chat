## 流程 01：手机首启全链路走查（2026-10-24 口述，0.305.1 实测，0.305.2 修复）

**实测设备**：手机畅享90Pro Max（180 测试账户线）
**环境前置**（用户特意构造）：
1. 华为账号 → 云空间 → 应用数据共享，把 DAG AI Chat 的共享**关掉**（模拟无云环境/新账号状态）
2. 更新 app 到最新版（覆盖安装）；从头测=设置→关于→法律条款→「撤回同意」回到门禁态（或卸载重装）

### 场景 1：老用户更新直入
| 项 | 内容 |
|---|---|
| 前置 | 已同意协议的老用户，覆盖更新 |
| 步骤 | 更新完点开 DAG |
| 实测 | 直接进 DAG 主界面；侧边栏版本号（V0.305.x）清晰可读 ✓ |
| 预期 | 不重弹协议门禁；版本号三处同步可核对 |

### 场景 2：门禁页·未勾选点「华为账号登录」
| 项 | 内容 |
|---|---|
| 前置 | 门禁态（未同意协议），勾选框未勾 |
| 步骤 | 直接点主按钮「华为账号登录」 |
| 实测 | 按钮抖三抖 + 提示（0.305.1 文案「请先勾选同意上述协议」——**用户指出 bug：协议在按钮下方，不叫"上述"**） |
| 预期（0.305.2+） | 抖三抖 + 「请先勾选并同意协议」；不发任何登录请求 |

### 场景 3：门禁页·未勾选点「暂不登录，先本地使用」★合规红线场景
| 项 | 内容 |
|---|---|
| 前置 | 门禁态，勾选框未勾 |
| 步骤 | 点「暂不登录，先本地使用」 |
| 实测（0.305.1） | **bug：直接放行**，协议被静默标记同意，落到首页正常态（进入气泡树+登录华为账号页）——用户定性「不打勾不同意隐私协议怎么可以使用，大 bug」 |
| 预期（0.305.2+） | 与登录按钮同款：抖三抖 + 「请先勾选并同意协议」，不放行 |

### 场景 4：未同意协议状态下的功能失守连环（0.305.1 实测 bug 链）
用户顺着场景 3 的漏洞继续走查，验证失守范围：
- 首页正常态点「进入气泡树」→ **能进主界面**（未同意协议照常使用 ✗）
- 未登录华为账号 → 云同步入口**能开启**（✗ 应被登录守卫拦截）
- 点性格测试（测试题目）入口 + 引导「前往开启」→ 链路完全不对（✗）
**预期（0.305.2+）**：场景 3 拦死后本链整体断根（进不了主界面）；测试台回归时仍应逐项验证：未登录开云同步=引导登录弹窗而非可开启；性格测试等 SP 功能走 SiyiGate 门卫

### 场景 5：勾选协议 → 「暂不登录，先本地使用」
| 项 | 内容 |
|---|---|
| 前置 | 门禁态，勾选框已勾 |
| 步骤 | 点「暂不登录，先本地使用」 |
| 实测（0.305.1） | 落首页正常态（品牌+进入气泡树+登录华为账号）→ 用户拍板：**这个中间页退役，同意后直进气泡树** |
| 预期（0.305.3 已实施） | 直接落气泡树主界面；首页正常态整段删除（登录入口走设置/边栏，版本号在门禁态与设置-关于可查）；从画布按返回=落品牌衬底，衬底上再按返回=退出 app |

### 场景 6：勾选协议 → 「华为账号登录」
| 项 | 内容 |

### 场景 7：不同意退出

## 流程 02：手机门禁态视觉+负反馈走查（2026-10-24 二测口述，0.305.3 实测，0.305.4 修复）

**环境注意（用户痛点）**：每次冷装 DAG 后，华为云空间里该应用的数据共享会自动恢复勾选——用户为模拟未云环境每次都要去关一次（设置 → 华为账号 → 云空间 → 应用数据共享 → DAG AI Chat 关）。测试台冷装用例的前置清理可参考此点。

### 场景 1：门禁首屏观感
| 项 | 内容 |
|---|---|
| 实测（0.305.3） | 整体视觉重心偏上；下块（协议勾选行/不同意退出/版本号）显得大且位置偏上 |
| 拍板（0.305.4 已实施） | 上部整块（品牌 → 暂不登录）下移（顶部弹性 1→1.6）；下块字号缩小一圈（协议行/不同意退出 13→12、版本号 12→11、行高 20→18）+底部弹性缓冲不贴底 |

### 场景 2：勾选态反馈（正向）
| 项 | 内容 |
|---|---|
| 步骤 | 点勾选框打勾 → 再取消勾选 |
| 实测 | 打勾后「华为账号登录」按钮变亮（品牌实底白字）；取消恢复描边透底——**用户认可「这个还是不错的」**，两态设计保留 |

### 场景 3：未勾选点两个按钮的负反馈（核心拍板）
| 项 | 内容 |
|---|---|
| 前置 | 勾选框未勾 |
| 步骤 | ①点「暂不登录，先本地使用」②点「华为账号登录」 |
| 实测（0.305.2~3） | 按钮各自抖动+红色提示文字「请先勾选并同意协议」 |
| 拍板（0.305.4 已实施） | **抖动设计保留但锚点统一迁到「我已阅读并同意」协议勾选行**（抖"要去勾的地方"比抖按钮更直观引导）；红色提示文字删除（抖动即提示）。未勾选时任何放行按钮点击=协议行抖两抖、零文字、零放行 |


| 版本 | 修复 |
|---|---|
| 0.305.2 | 场景 3 勾选守卫+抖动；场景 2 文案去「上述」 |
| 0.305.3 | 流程 01 场景 5 首页正常态退役，同意后直进气泡树（用户拍板；老用户冷启同样直达画布） |
| 0.305.4 | 流程 02 全部拍板项：视觉重心下移+下块缩小、抖动锚点迁协议行、提示文字退役 |

### 0.305.3 连带变更（测试台用例须同步核对）
- 冷启（已同意用户）=直达气泡树（原「落首页正常态」路径不复存在）
- 首页正常态三件套删除：进入气泡树按钮/华为账号登录区/首页版本号——版本号核对改走门禁态或设置-关于
- 常规登录失败/退出失败提示从首页文本位改 toast
- 手机端登录入口：设置 → 云同步（原首页登录卡片退役）
