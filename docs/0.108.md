# 本地持久化存储 — 0.108

> 归属版本：v0.1 内部迭代

## 一、问题

`BubbleTree`（气泡树 + 聊天记录）使用 `AppStorageV2`（纯内存），每次 app 重启/更新部署后数据全部丢失。

`ApiConfig` 已使用 `PersistenceV2`（持久化到磁盘），重启后正常恢复。

## 二、现状

| 数据 | 存储方式 | 重启后 |
|------|---------|--------|
| `BubbleTree`（气泡+消息） | `AppStorageV2` | ❌ 丢失 |
| `ApiConfig`（API 配置） | `PersistenceV2` | ✅ 保留 |
| `CurrentBubble`（当前选中） | `AppStorageV2` | ❌ 丢失（可接受） |
| `ThemeStore`（深浅色） | `AppStorageV2` | ❌ 丢失（跟随系统，可接受） |

## 三、修复方案

将 `BubbleTree` 从 `AppStorageV2` 改为 `PersistenceV2`：

```typescript
// ❌ 之前（纯内存）
AppStorageV2.connect(BubbleTree, 'bubble-tree', () => new BubbleTree())

// ✅ 之后（持久化到磁盘）
PersistenceV2.connect(BubbleTree, 'bubble-tree', () => new BubbleTree())
```

`PersistenceV2` 自动在 `@Trace` 属性变化时写入磁盘，重启时自动恢复。

### 不改动的数据

- `CurrentBubble`：保持 `AppStorageV2`（当前选中气泡是瞬态状态，重启后默认未选中）
- `ThemeStore`：保持 `AppStorageV2`（跟随系统主题，`EntryAbility` 自动读取）

## 四、改动文件

| 文件 | 改动 |
|------|------|
| `pages/Index.ets` | `AppStorageV2` → `PersistenceV2`（BubbleTree 初始化） |
| `components/BBTreeCanvas.ets` | 添加 `PersistenceV2` 导入；`AppStorageV2` → `PersistenceV2` |
| `components/ChatPage.ets` | `AppStorageV2` → `PersistenceV2` |
| `common/ChatModel.ets` | 更新注释说明 |

## 五、数据结构验证

所有类已正确装饰 `@ObservedV2` + `@Trace`，`PersistenceV2` 可直接序列化：

```
BubbleTree (@ObservedV2)
  └─ @Trace nodeList: BubbleNode[]
       └─ BubbleNode (@ObservedV2)
            ├─ @Trace messages: ChatMessage[]
            │    └─ ChatMessage (@ObservedV2)
            │         ├─ @Trace content: string
            │         ├─ @Trace role: 'user' | 'assistant'
            │         └─ @Trace imageUrl: string[]
            ├─ @Trace x, y, parentX, parentY: number
            └─ @Trace nodeID, parentID: string
```
