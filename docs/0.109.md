# 修复本地持久化 — 0.109

> 归属版本：v0.1 内部迭代

## 一、问题

`PersistenceV2` 无法序列化嵌套自定义对象数组（`BubbleNode[]` → `ChatMessage[]`）。
`ApiConfig`（纯 string 字段）持久化正常，`BubbleTree`（嵌套数组）重启后丢失。

## 二、根因分析

```
BubbleTree
  └─ @Trace nodeList: BubbleNode[]     ← 自定义对象数组
       └─ @Trace messages: ChatMessage[]  ← 再嵌套
            └─ @Trace imageUrl: string[]

PersistenceV2 仅可靠持久化简单类型（string/number/boolean）
→ 嵌套 @ObservedV2 对象数组序列化失败
```

## 三、修复方案

**用 `PersistenceV2` 存一个 JSON 字符串**，手动序列化/反序列化 `BubbleTree`：

```
BubbleTree（AppStorageV2 内存）
    ↓ serialize
PersistData.@Trace json: string（PersistenceV2 持久化）
    ↓ deserialize
BubbleTree（AppStorageV2 内存）
```

### 3.1 ChatModel.ets — 新增 PersistData + 序列化函数

```typescript
@ObservedV2
export class PersistData {
  @Trace bubbleTreeJson: string = '';
}

export function serializeBubbleTree(tree: BubbleTree): string { ... }
export function deserializeBubbleTree(json: string): BubbleTree | null { ... }
```

### 3.2 Index.ets — 启动时加载

```typescript
aboutToAppear() {
  // PersistenceV2 持久化 JSON 字符串
  const persist = PersistenceV2.connect(PersistData, 'persist-data', ...) as PersistData;
  // 尝试从 JSON 恢复
  const loaded = deserializeBubbleTree(persist.bubbleTreeJson);
  // 放入 AppStorageV2（内存）
  AppStorageV2.connect(BubbleTree, 'bubble-tree', () => loaded ?? defaultTree());
}
```

### 3.3 BBTreeCanvas.ets / ChatPage.ets — 改回 AppStorageV2 + 保存

```typescript
// 改回 AppStorageV2（内存）
store: BubbleTree = AppStorageV2.connect(BubbleTree, 'bubble-tree', ...) as BubbleTree;
// PersistenceV2 JSON 包装
persistData: PersistData = PersistenceV2.connect(PersistData, 'persist-data', ...) as PersistData;

// 数据变更时保存
saveToPersist() {
  this.persistData.bubbleTreeJson = serializeBubbleTree(this.store);
}
```

### 3.4 保存时机

| 位置 | 事件 |
|------|------|
| ChatPage.sendMessage | 发送消息后 |
| ChatPage onDone/onError | AI 回复完成/出错后 |
| ChatPage.addBubble | 添加子气泡后 |
| BBTreeCanvas dragEnd | 拖拽结束后 |
| BBTreeCanvas delete | 删除气泡后 |

## 四、改动文件

| 文件 | 改动 |
|------|------|
| `common/ChatModel.ets` | 新增 `PersistData` 类 + `serialize/deserialize` 函数 |
| `pages/Index.ets` | `PersistenceV2` → `AppStorageV2` for BubbleTree；加载 JSON |
| `components/BBTreeCanvas.ets` | `PersistenceV2` → `AppStorageV2`；添加 `saveToPersist()` |
| `components/ChatPage.ets` | `PersistenceV2` → `AppStorageV2`；添加 `saveToPersist()` |

## 五、数据流

```
启动：PersistData.json → deserialize → AppStorageV2(BubbleTree)
变更：AppStorageV2(BubbleTree) → serialize → PersistData.json → PersistenceV2 磁盘
```
