## 改动 1：autoLayout() 重写为递归布局

**原问题**：全局层级平铺，同一深度所有节点统一以 root.x 居中，子节点不在父节点正下方。

**新算法**：递归遍历每个父节点，子节点在父节点正下方居中横向排列。

```typescript
autoLayout(): void {
  const root = this.store.nodeList.find(n => n.parentID === null);
  if (!root) return;

  const nonDragged = this.store.nodeList.filter(n => !n.isUserDragged);
  if (nonDragged.length === 0) {
    console.info('[0.123] 所有节点已被手动拖拽，跳过自动排版');
    return;
  }

  const horizontalSpacing = 120;
  const verticalSpacing = 160;

  // 构建父→子映射
  const childrenMap = new Map<string, BubbleNode[]>();
  for (const node of this.store.nodeList) {
    if (node.parentID !== null) {
      const children = childrenMap.get(node.parentID) || [];
      children.push(node);
      childrenMap.set(node.parentID, children);
    }
  }

  // ★ 递归布局：子节点在父节点正下方居中排列（0.123fix7）
  const layoutChildren = (parent: BubbleNode, depth: number): void => {
    const children = childrenMap.get(parent.nodeID);
    if (!children || children.length === 0) return;

    // 按现有 x 排序，保持左右顺序
    children.sort((a, b) => a.x - b.x);

    // 以 parent.x 为中心居中排布
    const totalWidth = (children.length - 1) * horizontalSpacing;
    const startX = parent.x - totalWidth / 2;

    for (let i = 0; i < children.length; i++) {
      const child = children[i];
      if (!child.isUserDragged) { // ★ 仅排版未拖拽节点
        child.x = startX + i * horizontalSpacing;
        child.y = (depth + 1) * verticalSpacing;
      }
      // 递归布局下一层（拖拽节点也递归，让其后代以其当前位置为基准）
      layoutChildren(child, depth + 1);
    }
  };

  // 根节点：未拖拽则 y 归零
  if (!root.isUserDragged) {
    root.y = 0;
  }
  layoutChildren(root, 0);

  // 更新所有子节点的 parentX/parentY（原逻辑保留）
  for (const node of this.store.nodeList) {
    if (node.parentID !== null) {
      const parent = this.store.nodeList.find(n => n.nodeID === node.parentID);
      if (parent) {
        node.parentX = parent.x;
        node.parentY = parent.y;
      }
    }
  }

  // 持久化
  this.persistData.bubbleTreeJson = serializeBubbleTree(this.store);

  // 视口自适应
  this.fitViewport();
}
```

## 改动 2：fitViewport() 屏宽适配

顶部新增 import：
```typescript
import { display } from '@kit.ArkUI';
```

`fitViewport()` 中替换硬编码：
```typescript
// 原：const screenWidth = 360;
const screenWidth = px2vp(display.getDefaultDisplaySync().width); // ★ 实际屏宽（0.123fix7）
```
