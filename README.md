DAG AI Chat — 气泡树多分支 AI 对话工具
版本：0.16 (MVP 持续迭代)
鸿蒙 HarmonyOS ArkUI V2 原生应用，主打DAG有向无环图多分支AI对话，打破传统单线聊天限制，支持任意对话节点自由分叉，并行开展多思路探索，深度适配深度学习、数理推演、代码调试、知识梳理场景。接入火山方舟大模型API，集成多模态图片解析、屏幕圈注、沉浸式学习、个性化对话氛围等特色能力，兼顾实用性与体验感。
一、核心特性
- 🌳 DAG气泡树多分支对话（核心特色）：任意对话节点自由分叉，多对话分支完全独立隔离，完整留存每一条思考脉络，告别传统单线对话局限，支持多思路并行推演、对比验证。
- 📚 单词库+知识卡片多场景学习（核心特色）：集成划词翻译、生词自动收录、本地知识卡片提炼功能，支持文本/图片双场景生成知识卡片，搭配随机复习机制，实现即时学习、沉淀复盘一体化。
- 📸 一键屏幕圈注提炼（核心特色）：支持全局屏幕圈选标注、截图快速入知识库，无需上传图片，一键截取疑难知识点、公式、错题，快速调用AI多模态提炼总结，学习效率大幅提升。
- ✨ 专属称谓+鼓励式对话氛围（核心特色）：支持自定义专属称呼，内置温柔鼓励式对话氛围，告别机械冰冷的AI回复，打造沉浸式、有温度的专属学习陪伴体验。
- 📊 可视化画布：支持节点拖拽、双指缩放、自动排版、分支高亮，兼容平铺/选项卡双模式，直观管理整棵对话思考树。
- 🧠 全场景AI能力：流式打字机对话、多模态图片解析、LaTeX数学公式渲染、代码语法高亮、全局划词操作。
- 🔊 原生TTS语音：AI回复分段朗读、单词专属发音，全局单例复用，发音流畅稳定，适配单词跟读、内容听读场景。
- 💾 可靠本地持久化：基于PersistenceV2多维度隔离存储，对话树、学习数据、配置信息本地留存，全程离线可用，数据安全不丢失。
- 📱 鸿蒙原生适配：纯ArkUI V2原生开发，兼容手机、平板、二合一设备，系统深浅色主题自适应。
  二、商业化与适配人群

  五、核心数据模型（精简）
  所有数据模型严格遵循 @ObservedV2 + @Trace 鸿蒙V2响应式规范，性能稳定、响应实时
- ChatMessage：单条对话消息，包含角色、文本、图片、token统计、播客模式标记
- BubbleNode：核心气泡节点，含父子级关联、消息列表、画布坐标、自定义标题、分支链路摘要
- BubbleTree：对话树总容器，统一管理全局所有气泡节点与分支
- ApiConfig：统一管理对话、TTS的接口地址、密钥、模型、音色全套配置
  六、核心功能亮点
1. 独创 DAG 气泡树多分支思考系统
   支持任意对话节点自由分叉，多分支对话相互隔离、互不干扰，搭配画布自动排版、分支高亮、拖拽缩放能力，完整记录多维思考脉络，适合猜想验证、多方案对比、深度推演。
2. 全链路沉浸式学习体系
   整合单词库+知识卡片双学习模块，支持划词翻译生词入库、文本/图片提炼知识卡片、复习区随机复盘；搭配一键屏幕圈注功能，随时截取错题、公式、疑难知识点，快速AI解析沉淀，实现「学习-提炼-复盘」闭环。
3. 极致流畅智能对话体验
   SSE流式打字机回复，原生支持Markdown、代码表格、LaTeX数学公式渲染；内置多模型适配，优先兼容GLM/DeepSeek极速推理模型；配备180s超时兜底、后台自动中断、全中文报错提示，交互稳定流畅。
4. 个性化温度化对话氛围
   支持自定义用户专属称谓，内置温柔鼓励式回复机制，摒弃机械AI话术，打造专属、有温度、适配长期学习陪伴的对话氛围。
5. 完善的体验优化与适配能力
   AI回复实时计时展示、按钮状态智能联动、TTS全局单例复用、深浅色主题自适应，全场景细节打磨，兼顾功能实用性与使用舒适度。
   七、持久化规范
   采用多Key隔离持久化方案，气泡树数据、API配置、AI偏好、知识库、单词库独立存储，支持旧版本数据自动迁移，全程兼容迭代，避免数据丢失。
   八、快速启动
1. DevEco Studio打开项目，适配HarmonyOS NEXT SDK环境
2. 进入设置页，配置火山方舟API密钥与接口地址
3. 优选极速模型：GLM-5.3-Flash / DeepSeek-V4.1-Flash，保障响应速度
4. 测试接口连通性，即可开启多分支智能对话与沉浸式学习
